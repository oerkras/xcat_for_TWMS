## 2. 产品实现（现行）

### 2.1 开关与配置

| 项 | 值 |
|---|---|
| 面板 | 首页卡「攻击加速」：`[启用]` + `间隔 [ms]`（无单独 ActionSpeed 滑条） |
| ini | `user.ini [core] attackAccel` · `simpleCombatAttackIntervalMs` · coreIni **38** |
| 控制面 | `PayloadControl.attackAccel` → `attack_accel::SetDesired` |
| 挂载 | `xcat_probe`：`Init` + `StartWorker`；`payload_control` 下发 |

间隔默认 **333ms**，下限 **5ms**（`kSimpleCombatAttackIntervalMinMs` / `kAttackAccelIntervalFloorMs` / hold 地板同步）。过短易踢/空砍，自负。

### 2.2 Worker 行为（启用后 ~16ms）

| 写入 | 偏移 | 值 | 作用 |
|---|---|---|---|
| 清忙锁 | `LocalUser+0x118` | `-1` | 跳过「等动作播完才能再出刀」 |
| 绝对攻速 | `SecondaryStat+0x1BC` | **140** | Prepare 路径绝对覆盖 GetActionSpeed |
| 过期 t | `SecondaryStat+0x1C4` | `GetTickCount()+1h` 量级 | 配 `CheckByTime`，避免立刻过期 |

- SS 解析：`world::IsPlayReady()` → `GetWorldManager()` → **`WM+0xF0`**（与 invuln 同锚）。
- LU 解析：`player_combat::QueryCombatCtx` → `localUser`。
- 关开关 / worker 停：若本会话写过速度，则把 `+1BC/+1C4` **清 0**（可能盖掉真实服端绝对速度 buff）。
- 日志：`bin/XCat_data/logs/attack_accel.log`（例：`busy=-1 ss=… speed=140 exp=…`）。

### 2.3 频率真源（不在 attack_accel 里）

自动出刀节奏由 **`simpleCombatAttackIntervalMs`** + `attack_input_port::TryFirePrimary` 门控（含 hold / pendingUp）。  
**ActionSpeed 与清忙锁不改该数字门控**；它们只放宽引擎侧忙锁/Prepare 缩放。

出刀路径（现行）：`OnFuncKey` · A 键槽优先（`GetDataByKeyCode(Key.A)`）→ 回落 FuncKey `5/52`。

### 2.4 UI 说明

- **无** ActionSpeed 独立选项：启用即写死 **140**（Prepare clamp 上限）。
- 「智能间隔」在「打怪设置」卡，属 simple_combat，不是 attack_accel 字段。

## 3. 逆向结论（仍有效 · 2026-08-03 复核）

### 3.1 出刀链

```text
OnFuncKey → TryDoing* → SetAttackAction
  ├─ busy: [+0x118] 非空闲则挡
  ├─ PrepareActionLayer(speed)  // LocalUser 用 TS ActionSpeed 覆盖名义 100
  └─ 成功: [+0x118] = actionIdx
```

### 3.2 双速

| 系统 | 输入 | 解锁 `+0x118`？ | 本功能是否写 |
|---|---|---|---|
| **A · 动画/忙锁** | `TS+80/+84`、**`+1BC`** | **是** | 写 **`+1BC=140`**（不写 +80/+84） |
| **B · 伤害延迟** | `+0x15C`、`TS+0xBC` → `GetDamageDelay` | **否** | **不写** |

`+1BC != 0` 时绝对覆盖 GetActionSpeed 合成值（阈 0，种子已验）。  
Prepare 内 **`Math.Max(70)` / `Math.Min(140)`**（2026-08-03 新 IDB 种子复验仍为 70/140）。

### 3.3 Slot14 与 `layer+0x14`

自然路径：`[layer+0x14]` 递减 → 帧推进 → 结束时 `[+0x118]=-1`。  
**产品已用周期清忙锁绕过「等 layer 扣完」**，故中途强改 `layer+0x14` 对再出刀闸门冗余。

## 5. 刻意不做（产品决策）

| 候选 | 决策 | 理由 |
|---|---|---|
| 周期写 `layer+0x14→0` / 强推帧 | **不做** | 清忙锁已放开再出刀；该字段主要驱动动画帧推进。在现架构下对 DPS **近似纯视觉**，还易加剧不同步/whiff |
| Booster / 武器档写入 | **不做** | B 系统不解忙锁；伤害延迟非本开关目标 |
| 技能服端 CD 绕过 | **不可能（客户端）** | 通用 CD 服端权威 |
| ImGui 攻速滑条 70–140 | **未做** | 启用即上限 140；需要再加 |

后续若还要抠频率：优先 **间隔甜点**、**hold/pendingUp**（自研路径），不是再动 A 系统字段。
