## 0. 一句话

经典版「技能多发」= 面板勾选清单 → payload 按 `gapMs`（安全串发可抬地板）串发一波：

- **技能**：默认 `DoActiveSkill`；可选优先 `SendSkillUseRequest`（失败回退 DoActive → Prepare）
- **普通攻击**：始终 `attack_input_port::TryFirePrimary` → `OnFuncKey` 正路组包（**不**走 Create(50)）

出刀引擎（`TryCast`）已接 `simple_combat.Fire`（多发开着只走清单串发）；面板「测试一波」仍可单独验收。

## 1. 与枫星差异（勿混）

| 维度 | 枫星（对照） | TWMS 经典版（本仓） |
|------|-------------|-------------------|
| 进程 | `msw.exe` / Artale + Lua | `Maplestory_Classic.exe` / Il2Cpp |
| 技能出刀 | `UseOnClientImmediate` → Play → `UseOnServer` | **`DoActiveSkill`**（可选 `SendSkillUseRequest`；失败回退 Prepare） |
| 普攻 | `CharacterAttackManager:Attack` | **`OnFuncKey`**（`TryFirePrimary`） |
| 串发时钟 | Lua `_CharacterTimer` / `_Timer` | worker due 队列 + 主线程泵 |
| 勾选 | `state/multiskill_select.tsv` | **同路径同形** |
| 开关 | `multiSkill*`（含扩族 / 职业 OPT / SafeStagger） | `multiSkill` / `multiSkillGapMs` / `multiSkillSafeStagger` / `multiSkillSendUseRequest` |
| gap 相对服端 | attSrv=80，默认 120，非攻 ~480 | clamp **1–500**，默认 120；**不照搬** attSrv/SkillFastUse |
| 扩族 / 剑豪等 DPS | 硬编码 Worlds ID | **不做** |
| 列表 | Lua 技能书 + catalog TSV | `skill_port::ListLearnedSkills` → `learned_skills.tsv`；显示名叠 `dataservice/skill_names.tsv` |
| 调用方 | `simple_combat.FireAttackKey` | `simple_combat.Fire` + cast-request 测试入口 |
| 伪造攻包 | 非路径 | **禁止**；rpc50 已踢（2026-08-04 BIN） |

### 1.1 管线对照

```text
枫星：select.tsv → SnapshotCastIds(expand/OPT) → Lua Timer 串发
         → skill: UseOnClientImmediate | NA: CAM.Attack

TWMS：select.tsv → PendingCast @ now+i*gap → Tick
         → skill: DoActiveSkill [| SendUse] | NA: OnFuncKey
```

两仓可共享的是**排程语义**（清单 → gap → busy → 换靶取消），不是施法 API / 技能 ID / AC 常量。

## 3. 职责边界

### 做

- 总开关 + gap + 安全串发 + 可选技能发包直发；勾选清单读写
- `TryCast`：首技立刻、后续按 gap 排队；busy 窗吞刀；未学会 / 非攻击候选 / **仍在 CD** skip
- 到期 `Tick` 再检一次 CD（排程后可能已进冷却）；日志 `reason=cooldown rem=`
- 最近一波统计（scheduled / skip / span / selCount）
- `CancelPendingBurstForRetarget`（`simple_combat` 换靶）
- 面板真读写 + 搜索勾选 + 清空 + 刷新已学列表 + 测试一波
- NormalAttack 列表置顶可勾；出刀仅 OnFuncKey

### 不做

- 连招扩族、职业 DPS 优化、假键鼠、伪造 Attack 包、改 GA `.text`
- 完整 `simple_combat` 选怪主循环（本模块只提供出刀 API）
- 把 `attack_rpc` 实验探针接回多发热路径

## 5. 配置契约

```ini
[core]
multiSkill=0|1
multiSkillGapMs=120                 ; clamp 1–500；默认 120
multiSkillSafeStagger=1             ; 1=攻击技间隔地板≥120
multiSkillSendUseRequest=0          ; 1=技能优先 SendSkillUseRequest（失败回退 DoActive）；不影响普攻
```

勾选文件：`XCat_data/state/multiskill_select.tsv`（一行一个 `NormalAttack` 或数值 skillId）。

测试请求：`XCat_data/state/multiskill_cast_request`（存在即消费并 `TryCast` 一波）。

已学列表缓存：`XCat_data/state/learned_skills.tsv`（`code\tname\tlevel`）。  
显示名：**offline-first** `dataservice/skill_names.tsv`；表外再回退 Il2Cpp `SkillEntry.Name`。

## 8. 实机验收清单（一波多发）

> 分析闭环；执行后把结果回填本节状态。默认产品开关不变。

### 8.1 基线（`sendUse=0`）

```text
前置
  · 构建 xcat.dll + xcat.exe；注入进图
  · 技能多发：启用；安全串发开；发包直发关
  · 勾选 1～2 个攻击技 + NormalAttack；gap≥120（或安全串发地板）
  · 攻击加速可开；简单战斗间隔≥50ms
  · 建议先站怪旁「测试一波」，再挂简单战斗

期望日志（x.jsonl / MultiSkill / Attack）
  · TryCast ok scheduled≥1
  · cast id=<skillId> ok=1 … sendUse=0
  · cast NormalAttack ok=1 path=OnFuncKey
  · 禁止出现 path=rpc50 / AttackRpc forge / TryFireNormalDirect

期望游戏侧
  · 可见技能施放与/或普攻挥砍；怪有命中反馈（lastHitted / 掉血）
  · KickSniff 无 Connected→Disconnected
  · SecAttack peakKey ≪ 2000（pct 远低于 100%）

失败判据
  · 断线 / pendingError 跳变且与多发时刻对齐
  · 仅 scheduled 无 cast ok、或持续 notReady 且无任何施放
```

### 8.2 对照（可选 · `sendUse=1` · 低风险）

```text
  · 同一清单；仅开「技能发包直发」；gap 保持≥120；先「测试一波」单波
  · 期望：cast id=… sendUse=1；失败应见回退 DoActive 日志，而非断线
  · 若断线：关回 sendUse=0，记入「有条件可行」否决证据；勿提高频率硬试
```

### 8.3 明确不做的验收

- 不验收 rpc50 / 实验攻包探针与多发同开
- 不验收枫星扩族 / 职业 OPT
- 不以 type20 满窗为目标压 gap
