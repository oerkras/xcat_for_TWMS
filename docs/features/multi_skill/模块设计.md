## 0. 一句话

经典版「技能多发」= 面板勾选已学主动技能 → payload 按 `gapMs`（安全串发地板）串发一波 `DoActiveSkillPrepare`。  
出刀引擎（`TryCast`）已接 `simple_combat.Fire`（多发开着只走清单串发）；面板「测试一波」仍可单独验收。

## 1. 与枫星差异（勿混）

| 维度 | 枫星（对照） | TWMS 经典版（本仓） |
|------|-------------|-------------------|
| 进程 | `msw.exe` / Artale + Lua | `Maplestory_Classic.exe` / Il2Cpp |
| 出刀 | `UseOnClientImmediate` + `_Timer` | **`DoActiveSkillPrepare`**（主线程泵；worker 按 due 排程） |
| 勾选 | `state/multiskill_select.tsv` | **同路径同形** |
| 开关 | `PayloadControl.multiSkill*`（含扩族/职业优化） | **仅** `multiSkill` / `multiSkillGapMs` / `multiSkillSafeStagger` |
| 扩族 / 剑豪等 DPS | 硬编码 Worlds ID | **首版不做** |
| 列表 | Lua 技能书 + catalog TSV | `skill_port::ListLearnedSkills` → `state/learned_skills.tsv`；显示名叠 `dataservice/skill_names.tsv` |
| 调用方 | `simple_combat.FireAttackKey` | 同语义预留；另有 cast-request 测试入口 |

## 2. 职责边界

### 做

- 总开关 + gap + 安全串发；勾选清单读写
- `TryCast`：首技立刻、后续按 gap 排队；busy 窗吞刀；未学会 skip
- 最近一波统计（scheduled / skip / span / selCount）
- `CancelPendingBurstForRetarget` 预留给换靶
- 面板真读写 + 搜索勾选 + 清空 + 刷新已学列表 + 测试一波

### 不做（首版）

- 连招扩族、职业 DPS 优化、假键鼠、伪造 Attack 包、改 GA `.text`
- 完整 `simple_combat` 选怪主循环（本模块只提供出刀 API）
- 普攻 `NormalAttack`：列表固定置顶可勾；出刀走 `attack_input_port::TryFirePrimary`（非整备 Prepare）

```text

  → user.ini [core] multiSkill*
  → state/multiskill_select.tsv
```

## 4. 配置契约

```ini
[core]
multiSkill=0|1
multiSkillGapMs=120          ; clamp 40–500；默认 120
multiSkillSafeStagger=1      ; 1=间隔地板≥120
```

勾选文件：`XCat_data/state/multiskill_select.tsv`（一行一个数值 skillId；空清单回填不强制普攻出刀）。

测试请求：`XCat_data/state/multiskill_cast_request`（存在即消费并 `TryCast` 一波）。

已学列表缓存：`XCat_data/state/learned_skills.tsv`（`code\tname\tlevel`）。  
显示名：**offline-first** `dataservice/skill_names.tsv`（与 BUFF 页同一离线 String 表）；表外再回退 Il2Cpp `SkillEntry.Name`。

### 6.1 攻包窗 type20（安全旁证）

多发会走进 `DoActiveSkill` → `CollectAttackSkill`，出刀攻包走 `IsAttackPacket` 白名单 → `CollectAttackPacket`。  
本地硬窗约 **60s / 2000**（`ClientHacksType=20`）；正常 gap **远低于**踩线密度。  
只读采样：`security_attack_port` → `x.jsonl` tag=`SecAttack`（worker 每 15s）。  

详文：[`../security/攻包计数窗与type20.md`](../security/攻包计数窗与type20.md)。
