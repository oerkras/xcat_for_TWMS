## 1. 职责边界

| 做 | 不做 |
|---|---|
| 登录 UI：世界 → 频道 → 角色（**托管 UI 直接调用**，非鼠标点击 / 非裸包） | E9 / 改 GA `.text` |
| Worker 只调度；FindAll / 点击走 `main_thread_pump` | Worker 线程 FindAll / 直读托管堆敏感字段（GC fatal / 竞态） |
| 进频：**仅** `OnClickButtonGoWorld` 一次 | `TriggerEnterChannel` / `SendSelectWorld` 叠包；自动重发 Go |
| 选频：`PickOpenChannelId` — **非成人、未满**池内 **随机** | ~~`PickLeast` 最少人~~（已退役） |
| 选角：Select / Confirm 分步；**离开选角 UI / play ready 才 Done** | 同帧 Select+Confirm 假 ok；Job ok 即 Done |
| 选频/idle 喂 `NotifyWorldChannelSnapshot` + `NotifyChannelFillTable`（含 worldId；换分区可覆盖） | CCU 内自建 FindAll |

运行中开自动进时 `SetLoginFreeze(true)`；**真 Done / Failed** 后才解冻。

默认面板：`autoEnter=1`、分区 **1 雪吉拉**、槽 **1**。

## 2. 调用语义

- **不是**模拟鼠标 / 原始发包。
- 经 `main_thread_pump` 在 Unity 主线程调托管方法（`MethodInfo` / 哈希解析，非 E9）。
- 日志 `direct=0` = 走泵。

链路：

```
OnClickWorldItem → SelectChannel → OnClickButtonGoWorld（一次）
  → SelectCharacter → OnClickButtonSelect
```

## 3. 阶段机

```
WaitWorldList → PickWorld → WaitChannelUi → PickChannel
  → WaitChannelArmed → WaitCharSelect → PickChar
  → WaitCharArmed → ConfirmChar → WaitLeaveChar → Done
                                              ↘ Failed
```

| 阶段 | 要点 |
|---|---|
| WaitChannelUi | 等目标分区 + 频道列表非空 + 点击后 settle（冷启 **300ms** / softFast **50ms**） |
| **PickChannel** | **`PickOpenChannelId`**：未满池随机；顺带 CCU 总人数 + 每频填表 |
| WaitChannelArmed | 等 UI 选中 id 武装后再 Go |
| WaitCharSelect | 有 `charUi` 即认选角；离频道后不重发 Go；avatars 就绪后 settle 再 Pick |
| PickChar / Confirm / WaitLeave | 分步确认；离开选角或 play ready → Done |

## 4. 选频实现：`PickOpenChannelId`（当前）

源码：`x/features/auto_enter/auto_enter.cpp` · `PickOpenChannelId` / `ChannelPickSeed`。

### 4.1 候选池

扫 `WorldItem` 频道列表，入池条件：

| 条件 | 规则 |
|---|---|
| `nChannelID` | `1..64` |
| 成人频 | `bAdult != 0` → **跳过** |
| 满员 | `cap > 0 && users >= cap` → **跳过** |
| 人数异常 | `users < 0` → **跳过** |

不再「优先 1..20 最少人」；**全表未满合法频**均可入池（含 21+）。

### 4.2 随机

```
seed = ChannelPickSeed(candN)
     = TickCount ⊕ PID ⊕ QPC ⊕ (candN * 黄金比常量)
pick = seed % candN
```

日志：

```
PickOpen → id=K users=U pool=I/N (seed=0x…)
```

`pool=I/N`：本次抽中为池中第 I 个（1-based），池大小 N。

### 4.3 审计日志（仍打 1..20）

选频前仍打印首屏人数（便于人眼核对），**不参与挑频**：

```
  ch1-10: 1=… 2=… …
  ch11-20: 11=… …
```

后缀：`A`=成人、`F`=满员、`?`=缺失；无后缀=可入选。

### 4.4 顺带喂数

| 调用 | 用途 |
|---|---|
| `ccu::NotifyWorldChannelSnapshot` | 分区在线人数和 → 底栏 CCU |
| `ccu::NotifyChannelFillTable` | 每频 users/cap/adult → `channel_hop` 未满优先 |

### 4.5 与旧策略对照

| | 旧 `PickLeast`（已退役） | 现 `PickOpen` |
|---|---|---|
| 范围 | 先 1..20，再全表兜底 | 全表 1..64 未满 |
| 择优 | `users` 最小（同分取更小 id） | **均匀随机** |
| 日志 | `PickLeast → id=… users=…` | `PickOpen → id=… pool=… seed=…` |
| 动机 | 挤进最空频 | 打散进频、减少扎堆 |

发布包 **0.1.91～0.1.98** 仍是 `PickLeast`；**当前工作区**已切 `PickOpen`。

## 8. 风险

- 空角色 / 槽位越界 → Failed。  
- 服端慢回 SelectWorldResult → **只等不重发 Go**。  
- 全频满员 / 仅成人 → `PickOpen → none` → Failed。  
- 随机可能抽到偏满但仍未满的频（符合设计，非最少人）。  
- CCU / channel_hop 填表依赖本模块走到选频；见 ccu / channel_hop 文档。

## 10. softFast（软重连快轨）

仅当 `RequestRestart(why)` 且 `why == "soft_login"` 时置 `gSoftFastTrack`；Done / Failed / 正常冷启清零。闭环细节见 [`../soft_login/模块设计.md`](../soft_login/模块设计.md)。

### 10.1 settle 对照

| 参数 | 冷启 | softFast |
|---|---:|---:|
| Connected settle | 800ms | **100ms** |
| 点分区后（WaitChannelUi） | 300ms | **50ms** |
| SelectChannel 后武装→Go | 250ms | **0** |
| 选角 UI ready settle | 200ms | **80ms**（曾 0；BIN 19:00 soft 二次 Confirm） |
| 离频道 hold | 800ms | **0** |
| Wait-char Tick sleep | 80ms | **16ms** |

### 10.2 sticky 频道（仅 softFast）

- `gStickyChannelId`：进图 Done / GoWorld 成功 / `channel_hop` SettleOk → `NoteStickyChannel` 写入。
- **官方 UI 换频**：`channel_hop` Idle+playReady 约每 2s 轻量读 WM`+0x6C/+0x68`，变化则 `stickyCh … (native_wm)`（不跑全量 ReadInfo）。
- **进登录前**：`pre_login_clear` 把 known 推进 sticky；soft hold 期间不清 known。
- soft `RequestRestart`：再 `soft_restart_sync` 一次 hop known，避免换频后仍粘**进图旧频**。
- softFast 选频：`PickSticky` 优先；**满员/成人/不在 open 池 → 候选池随机**（不就近、不偏人少；禁止硬粘满频；进图 Done 刷新 sticky）。
- softFast：频道 UI **已武装到 sticky** → 跳过 `SelectChannel`，下一拍直接 `GoWorld`。
- GoWorld 后 softFast 同 Tick 再 `RefreshSnap`，服端已回包则少睡一轮。

### 10.3 禁止捷径（IDA）

GoWorld（RVA `0xA986F0`）读 Channel UI `+0x80`（id）/`+0x78`（obj）→ OutPacket **opcode 4**。  
禁止：`TriggerEnterChannel` / `SendSelectWorld`（叠包）/ soft 后跳过 `PickWorld` 直进图。

### 10.4 Done ≠ playReady

`IsDone()` = 阶段机已离选角 UI（latched Done）。软重连成功仍以 pump `IsPlayReady` 为准；soft 侧仅当采样确认 **仍 !inMap** 满 50s 才再 `RequestRestart`（单轮最多 **5** 次）；已回图则只等 alive/playReady，禁止再启。外圈 soft cycle 最多 **10** 轮后才交守护（见 soft_login §2.3）。

|---|---:|---|
