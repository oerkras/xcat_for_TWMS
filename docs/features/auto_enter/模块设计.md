# auto_enter Feature 模块设计（TWMS Classic）

> **状态**：✅ 已挂入；选区→选频→选角→Done 全链路 BIN 实锤（含选角 settle / 假 Done 修复）  
> **范围**：面板指定分区 → 最少人频道 → 角色槽 → 确认进游戏  
> **源码根**：`x/features/auto_enter/`  
> **产品**：经典版 TWMS · **不是**枫星  
> **关联**：选频喂 CCU → [`../ccu/模块设计.md`](../ccu/模块设计.md)；选角字段 IDA → [`选角与SelectedIndex锚点.md`](选角与SelectedIndex锚点.md)

---

## 1. 职责边界

| 做 | 不做 |
|---|---|
| 登录 UI：世界 → 频道 → 角色（**托管 UI 直接调用**，非鼠标点击 / 非裸包） | E9 / 改 GA `.text` |
| Worker 只调度；FindAll / 点击走 `main_thread_pump` | Worker 线程 FindAll / 直读托管堆敏感字段（GC fatal / 竞态） |
| 进频：**仅** `OnClickButtonGoWorld` 一次 | `TriggerEnterChannel` / `SendSelectWorld` 叠包；自动重发 Go |
| 选角：先 Select（必要时）再 Confirm；**离开选角 UI / play ready 才 Done** | 同帧 Select+Confirm 假 ok；Job ok 即 Done |
| 选频前 `NotifyWorldChannelSnapshot`（选定分区 `ci` 和） | 扫其它分区；CCU 被动 Probe |

运行中开自动进时 `SetLoginFreeze(true)`，减轻登录阶段主线程泵与其它 FindAll 抢跑；**真 Done / Failed** 后才解冻。

---

## 2. 调用语义

- **不是**模拟鼠标 / 原始发包。
- 经 `main_thread_pump` 在 Unity 主线程调托管方法（`MethodInfo` 合法，非 E9）。
- 日志 `direct=0` = 走泵；`direct=1` = worker 裸调（仅诊断，生产路径应走泵）。

链路：

```
OnClickWorldItem → SelectChannel → OnClickButtonGoWorld（一次）
  → SelectCharacter（可跳过） → OnClickButtonSelect
```

---

## 3. 阶段机

```
WaitWorldList → PickWorld → WaitChannelUi → PickChannel
  → WaitChannelArmed → WaitCharSelect → PickChar
  → WaitCharArmed → ConfirmChar → WaitLeaveChar → Done
                                              ↘ Failed
```

| 阶段 | 要点 |
|---|---|
| WaitChannelUi | 等 `SetWorldItem` 写入目标分区 + 频道列表非空 + 点击后 ≥600ms |
| PickChannel | `PickLeast`（优先 id 1..20 未满员）；顺带 CCU 喂数 |
| WaitChannelArmed | 等 UI `+0x80` 武装目标频道后再 Go |
| WaitCharSelect | **有 `charUi` 即认选角页**（可忽略残留 `channelUi`）；离频道后**不**自动重发 Go；`avatars≥1` 后 settle **700ms** 再 Pick |
| PickChar | 解析 `charSlot`→index；若主线程快照 `charSelectedIndex == index` → **跳过 Select**，直接 ConfirmChar；否则 `SelectCharacter` |
| WaitCharArmed | Select 后等 **400ms** 再确认（避免同帧假 ok） |
| ConfirmChar | `OnClickButtonSelect`；最多 4 次，间隔 1500ms |
| WaitLeaveChar | **`charUi` 消失** 或 `IsPlayReady()` → Done；否则按选中态决定重 Confirm / 回 PickChar |
| Done / Failed | `SetLoginFreeze(false)`；Done 后 latch 到面板关 `autoEnter` |

### 3.1 为何拆 Select / Confirm

BIN（15:25 / 15:36）：`avatars` 刚变 1 时同帧 Select+Click → Job `ok=1` 但人仍停在选角/频道 UI（假 Done）。  
对策：settle + 分 Job + **以离开选角为准**，不以 Job 返回值为进图证明。

### 3.2 为何可跳过 Select

进选角页时游戏常已高亮第一个 / 上次角色。再 `SelectCharacter(同 index)` 会重播选中动画（视觉「选两次」）。  
官方 `SelectCharacter` 自身也会 `cmp [this+168h], index`（见锚点文档）；我们读同一字段对齐该语义。

未知选中态（`charSelectedIndex == -1`）→ **保守仍走 Select**。

|---|---|

| `charSelectedIndex` | `ReadI32(charUi, +0x168)`；合法范围 `0..31`，否则 `-1` |

## 5. 面板 / IPC

`user.ini [core]`：`autoEnter`、`worldId` / 世界名、`charSlot` → `SetDesired`。

- `charSlot`：1-based 槽位；内部转 0-based index。  
- 世界名展示：面板侧按 `worldId → TSV`，避免 INI 脏粘连 / CJK atlas 缺字（`?`）。

## 6. 日志与验收

`XCat_data/logs/auto_enter.log` + `x.jsonl` tag=`AutoEnter`。

### 6.1 选区→进频（既有）

- `PickWorld id=…` → `ch1-10:` / `ch11-20:` 全表人数 → `top3 least:` → `PickLeast → id=…` → `GoWorld … (single click, no Trigger)`
- 人数行后缀：`A`=成人跳过、`F`=满员跳过、`?`=缺失；无后缀=可入选。

### 6.2 选角（当前期望）

```
char UI ready avatars=N
PickChar settle …
PickChar already selected index=K slot=S (skip Select, confirm only)   # 或 PickChar Select … wasSelected=
ConfirmChar click attempt=1 index=K
left char UI after confirm — Done    # 或 play ready while char UI linger — Done
Done — latched until autoEnter off
```

假 Done 回归信号：`Job kind=… ok=1` / 过早 `Done`，但随后长时间仍在 char/channel UI。

## 7. 风险

- 空角色 / 槽位越界 → Failed。  
- 服端慢回 SelectWorldResult 时频道页会停一会——**只等不重发 Go**。  
- Confirm 空转：已选中但按钮未就绪 → 有限次重试；仍失败 → Failed。  
- `+0x168` 若客户端大改布局需重跑 IDA（见锚点文档）。  
- CCU 依赖本模块走到 `PickLeast`；见 ccu 文档。  
- 旁路：登录阶段 Fly Arm / WorldPort 狂扫曾导致蜂鸣风暴与压力——已在 fly / world_port 侧收敛；与本模块解冻时机相关。
