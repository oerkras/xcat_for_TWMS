# auction_town_bypass Feature 模块设计（Classic TWMS）

> **状态**：✅ 已挂入（**零 `.text` 数据面** · BIN 实锤 · **防漂移元数据解析**）  
> **源码根**：`x/features/auction_town_bypass/` · IPC：`x/ipc/payload_control.*` · 契约：`common/xcat_payload_control.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **产品**：经典版 TWMS · **不是**枫星  
> **安全**：禁止 E9 / 改 GA `.text` / INLINE HOOK；**不**占硬件断点槽  
> **防漂移**：运行时**不**绑函数裸 RVA；对象经 `world_port`；字段偏移经 **hash FindClass + `il2cpp_class_get_field_from_name` + `il2cpp_field_get_offset`**（dump 常量仅 fallback）

## 1. 产品目标

| 项 | 内容 |
|---|---|
| 行为 | 开启后，在**野外图**点游戏状态栏拍卖按钮，客户端仍发迁移包，可进拍卖行 UI |
| 静默 | 不改按钮逻辑；用户仍点原生拍卖按钮 |
| 范围 | **仅客户端门控**；服端常拒/断线（见 §6）；与守护叠加会干净重拉 |
| 默认 | **开**（`[core] auctionTownBypass=1`）；挂机/守护时建议关 |
| 非目标 | 服务端放行、伪造拍卖业务包、改状态栏 UI |

## 2. 根因（IDA · 为何「野外不能开拍」）

入口链（状态栏按钮 ID **17** / CMS 名 `CnNpt`）：

```
UIStatusBar.OnClickButton(17)
  → User_CheckRedAccountRestriction
  → WorldManager.SendMigrateToGlobalMarketRequest   // RVA 0xDDD620（2026-08-04；旧 0xDD8610；文档锚点）
       → CanSendExclRequest
       → MapDataInfo.IsUnableToMigrate               // Option & 0x10
       → MapDataInfo.IsTown                          // 0 → 弹「所在區域無法執行該動作!」
       → OutPacket opcode 0x002E → SceneState.GlobalMarket=5
```

| 证据 | 含义 |
|---|---|
| 状态栏对 migrate 是 **直调 `call`** | MethodInfo 替换无效（同 `drop_alert` 教训） |
| migrate 读链：`Field → MapData → Info → IsTown` | 必须写 **SceneField 上的 MapData**，不能只写 `WM._currentMapData` |
| `IsUnableToMigrate`（RVA `0x148A1C0`）种子实算阈值 **0** | ≡ `(Option & 0x10) != 0` |
| 商城 `SendMigrateToShopRequest`（op `0x002D`）无 IsTown 检查 | 拍卖特有城镇门 |
| CTS opcode | `word_…310C`=`0x2550` + `0xFFFFDADE` → **`0x002E`**（08-04 实算） |

> 弹窗文案 `所在區域無法執行該動作!` 不在 GA 明文池（混淆 / StringPool）；失败支在 IsTown / Unable 闸后。

## 3. 现行方案（零 `.text` 数据面 + 防漂移）

功能开且 `IsPlayReady` 时：

1. 取 `WM`（`ports::world`，禁止模块内再 FindAll）
2. **一次**解析门控偏移（见 §3.2），写入 `gOff`
3. 解析 Info：  
   - **主**：`WM+wmField → +fieldMapData → +mapDataInfo`  
   - **辅**：`WM+wmMapData → +mapDataInfo`（与主不同才双写）
4. 备份后写：  
   - `Info+infoIsTown = 1`  
   - `Info+infoOption` **仅清** bit `0x10`（`IsUnableToMigrate`）
5. **调度（v3.1）**：未稳住 / 换图 → 50ms 快拍；已是 `IsTown=1` 且 bit 清 → **不写**，1s 慢校验  
   - 不能「仅点击才写」：状态栏对 migrate 是直调，无点击回调；禁 `.text`/HWBP
6. 关开关 / 切图 / Stop：Worker 写回  
   - IsTown 整字节还原  
   - Option：**只还原 bit0x10**（不整 DWORD 盖写）

```
WM
 ├─ +wmField Field ──► +fieldMapData MapData ──► +mapDataInfo Info ──► IsTown / Option
 └─ +wmMapData MapData ─┘（BIN：野外同图时常 same=1）
```

**线程**：`SetEnabled` 只改 `gDesired`；`gBak` 堆写回 **仅 Worker `Tick` / 退出**（避免 IPC 竞态）。

**不做**：GA `.text` 补丁、HWBP、INLINE HOOK、改 `world_port` 写接口。

### 3.1 演进纪要（勿回退）

| 版 | 做法 | BIN |
|---|---|---|
| v0 | 只写 `WM+0x88→Info.IsTown` | 野外仍弹区域限制 |
| v1 | 双路径 + migrate 内两处 `.text` | 可开拍；**裸 RVA，不符合防漂移优先** |
| v2 | 双路径 IsTown + 清 Option&0x10；**零 `.text`**；硬编码偏移 | `mapId=40001` 可开拍 |
| **v3（现行）** | v2 + **hash/字段元数据解析偏移**；常量仅 fallback | 08-04 remount：布局未漂；migrate RVA `0xDDD620` |

### 3.2 防漂移范式（remount checklist）

| 步骤 | 动作 |
|---|---|
| 1 | 新 `dump.cs` 更新 TypeDef / 字段 **hash**（类名与字段名） |
| 2 | 运行时：`FindClass("", classHash)` + `il2cpp_class_get_field_from_name` + `il2cpp_field_get_offset` |
| 3 | WM 类走既有 `il2cpp_shape::ResolveWorldManagerKlass()`（hash→shape） |
| 4 | 任一项 miss → 该字段用 dump 验证常量；日志 `path=meta\|meta-partial\|fallback` |
| 5 | **禁止**再绑 migrate 函数裸 RVA；RVA 只写文档 |

## 6. 副作用与边界

| 项 | 说明 |
|---|---|
| 开着时 | 其它读 `IsTown` / `Option&0x10` 的本地逻辑也会当成「可迁移城镇」 |
| 关开关 | 最多约 500ms（Worker off 拍）才写回字段 |
| 服务端 | 野外发 `0x002E` 常被拒或直接断 TCP；可见 `GlobalMarketTerminated`(op `0x018E`) |
| **与守护叠加** | 断线 → `kick_sniff` `disconnectSeq++` → 挂机「守护模式」5s **干净重拉**（用户体感像被杀死）。**不是** NGS/改内存被杀 |
| `world_port` | **只读**；本模块自行写 Info，不扩展 port 写 API |

### 6.1 BIN · 守护重拉时间线（2026-08-03 · `95C577CA…5fc37f`）

| t | 证据 |
|---|---|

| 12:41:58 | `Connected→Disconnected` / `lost_session`；ring 无 ForceDisconnect 包；`verdict=lean_local_or_soft` |

同会话更早窗曾出现 hist hint **`GlobalMarketTerminated`**（op `0x018E`），与拍卖场景收口一致。

## 7. 验收

1. **关着默认**；显式开 → 野外点原生拍卖 → 客户端可发包；日志 `zero .text` + `offsets path=meta`  
2. 若服端断线且守护开着 → 预期干净重拉（非本模块 bug；可关守护或关本开关）  
3. 关功能 → 野外再点应恢复区域限制弹窗  
4. 无 `text patches` / 无 GA `.text` 改写  
5. 既有 feature（drop_alert / combat 等）无回归
