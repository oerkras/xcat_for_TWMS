# auction_town_bypass Feature 模块设计与实现（Classic TWMS）

> **状态**：✅ 已挂入（**零 `.text` 数据面** · BIN 实锤 · **防漂移元数据解析** · v3.1 慢校验）  
> **源码根**：`x/features/auction_town_bypass/` · IPC：`x/ipc/payload_control.*` · 契约：`common/xcat_payload_control.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **产品**：经典版 TWMS · **不是**枫星  
> **安全**：禁止 E9 / 改 GA `.text` / INLINE HOOK；**不**占硬件断点槽  
> **防漂移**：运行时**不**绑函数裸 RVA；对象经 `world_port`；字段偏移经 **hash FindClass + `il2cpp_class_get_field_from_name` + `il2cpp_field_get_offset`**（dump 常量仅 fallback）

## 1. 产品目标

| 项 | 内容 |
|---|---|
| 行为 | 开启后，在**野外图**点游戏状态栏拍卖按钮，客户端仍发迁移包，可进拍卖行 UI |
| 静默 | 不改按钮逻辑；用户仍点原生拍卖按钮 |
| 范围 | **仅客户端门控**；服端常拒/断线（见 §8）；与守护叠加会干净重拉 |
| 默认 | **开**（`[core] auctionTownBypass=1`）；挂机/守护时建议关 |
| 非目标 | 服务端放行、伪造拍卖业务包、改状态栏 UI、点击瞬间才写（无回调且禁 hook） |

## 2. 根因（IDA · 为何「野外不能开拍」）

入口链（状态栏按钮 ID **17** / CMS 名 `CnNpt`）：

```
UIStatusBar.OnClickButton(17)
  → User_CheckRedAccountRestriction
  → WorldManager.SendMigrateToGlobalMarketRequest   // RVA 0xDDD620（2026-08-04；旧 0xDD8610；文档锚点）
       → CanSendExclRequest
       → MapDataInfo.IsUnableToMigrate               // Option & 0x10
       → MapDataInfo.IsTown                          // 0 → 弹「所在區域無法執行該動作!」
       → OutPacket opcode 0x002E → SceneState.GlobalMarket=5
```

| 证据 | 含义 |
|---|---|
| 状态栏对 migrate 是 **直调 `call`** | MethodInfo 替换无效（同 `drop_alert` 教训） |
| migrate 读链：`Field → MapData → Info → IsTown` | 必须写 **SceneField 上的 MapData**，不能只写 `WM._currentMapData` |
| `IsUnableToMigrate`（RVA `0x148A1C0`）种子实算阈值 **0** | ≡ `(Option & 0x10) != 0` |
| 商城 `SendMigrateToShopRequest`（op `0x002D`）无 IsTown 检查 | 拍卖特有城镇门 |
| CTS opcode | `word_…310C`=`0x2550` + `0xFFFFDADE` → **`0x002E`**（08-04 实算） |

> 弹窗文案 `所在區域無法執行該動作!` 不在 GA 明文池（混淆 / StringPool）；失败支在 IsTown / Unable 闸后。

## 3. 现行方案（零 `.text` 数据面 + 防漂移）

功能开且 `IsPlayReady` 时：

1. 取 `WM`（`ports::world`，禁止模块内再 FindAll）
2. **一次**解析门控偏移（见 §4.2），写入 `gOff`
3. 解析 Info：  
   - **主**：`WM+wmField → +fieldMapData → +mapDataInfo`  
   - **辅**：`WM+wmMapData → +mapDataInfo`（与主不同才双写）
4. 备份后写：  
   - `Info+infoIsTown = 1`  
   - `Info+infoOption` **仅清** bit `0x10`（`IsUnableToMigrate`）
5. **调度（v3.1）**：未稳住 / 换图 → 50ms 快拍；已是 `IsTown=1` 且 bit 清 → **不写**，1s 慢校验  
   - 不能「仅点击才写」：状态栏对 migrate 是直调，无点击回调；禁 `.text`/HWBP
6. 关开关 / 切图 / Stop：Worker 写回  
   - IsTown 整字节还原  
   - Option：**只还原 bit0x10**（不整 DWORD 盖写）

```
WM
 ├─ +wmField Field ──► +fieldMapData MapData ──► +mapDataInfo Info ──► IsTown / Option
 └─ +wmMapData MapData ─┘（BIN：野外同图时常 same=1）
```

**线程**：`SetEnabled` 只改 `gDesired`；`gBak` 堆写回 **仅 Worker `Tick` / 退出**（避免 IPC 竞态）。

**不做**：GA `.text` 补丁、HWBP、INLINE HOOK、改 `world_port` 写接口、off-pump 托管调用。

### 5.2 运行时状态

全部在 `auction_town_bypass.cpp` 匿名命名空间；堆写只发生在 worker。

| 符号 | 类型 | 含义 |
|---|---|---|
| `gDesired` | `atomic<bool>` | 控制面开关；静态默认 **false**，只由 `SetEnabled` 置位 |
| `gStop` / `gWorker` | 原子 | worker 生命周期 |
| `gHolding` | `bool`（仅 worker） | 当前 Info 已稳住 → Sleep 1s |
| `gOff` | `GateOff` | 一次解析的偏移；`tried` 后不再重解 |
| `gBak[2]` | `InfoBackup` | Field Info / WM Info 各一份；`savedIsTown` + `savedUnableBit` |
| `gForceHits` | 原子 | 成功 check 次数（含零写 hold） |
| `gWriteHits` | 原子 | **真正写内存**次数 |
| `gNativeIsTown` | `atomic<int>` | `-1` 未知 / `0` 野外 / `1` 主城（绕过开启时用备份原值） |

`InfoBackup`：换 Info 指针先 `RestoreOne` 再备份新对象；Option 只记/还原 bit `0x10`。

### 5.3 函数表

| 函数 | 线程 | 行为 |
|---|---|---|
| `Init` | boot | **只打日志**；**禁止** `gDesired.store(false)`（见 §6.1） |
| `StartWorker` | boot | 建线程；已有则跳过 |
| `StopWorker` | boot/detach | `gStop` + join 3s + `RestoreAllBackups` |
| `SetEnabled` | IPC / Apply | `exchange`；值变才打 `SetEnabled %d`；**不**碰 `gBak` |
| `Tick` | worker | `gDesired==0` → 还原 + 采 IsTown；否则 `ForceGatesOnCurrentMap` |
| `Worker` | 自有线程 | 等 `GameAssembly`；循环 `Tick` + Sleep（见 §5.4） |
| `EnsureGateOffsets` | worker（首次） | hash + `field_get_offset`；一次 |
| `ForceInfoGates` | worker | 已是 `IsTown==1` 且 bit 清 → 零写返回；否则写并 `gWriteHits++` |
| `ForceGatesOnCurrentMap` | worker | `!IsPlayReady` / 无 WM → 还原、`gHolding=false`；成功则 `gHolding=true` |
| `PublishNativeIsTownSample` | worker | 绕过开且 bak 对齐当前 Info → 发备份原值；否则读活字段；对不齐发 `-1`（防把强制 1 当主城） |
| `QueryNativeIsTown` | 任意 | 只读原子；给 status SHM |

### 5.4 Worker 调度

```
Sleep =
  gDesired==0          → 500ms   (kTickMsOff)
  gDesired && !holding → 50ms    (kTickMsApply，换图/未稳住)
  gDesired && holding  → 1000ms  (kTickMsHold，已正确则 ForceInfoGates 零写)
日志 data-plane 最少间隔 15s (kLogMs)
```

`data-plane` 行里的 `IsTown A->B`：**A=备份原值，B=当前活值**。稳住期也会印 `0->1`；是否在写内存看 **`writes` 是否上涨**，不看这句文案。

不能「只在点拍卖按钮时写」：状态栏直调 migrate，没有可挂的点击回调；E9/HWBP 禁止。v3.1 是不破底线的最懒调度。

### 5.5a 拍卖 15/24h 探针（一次 · 不破坏战斗）

08-20 客户端在迁拍卖上加了「角色 ≥15 级且建角满 24h」预检（相对商城多两条 StringPool 失败文案）。**不要**用本模块 worker 常驻改 `CharacterStat.level`——那是战斗/UI 真源。

实验 TAB「拍卖原生按钮（一次）」：`[core] auctionGateProbeSeq` 脉冲 → 主泵 `FindAll(UIStatusBar)` → 官方 `OnClickButton(17)`（含红号检查后直调 `SendMigrateToGlobalMarketRequest`）。**不写** `CharacterStat.level` / 建角 DateTime。源码 `x/features/auction_gate_probe/`。15/24h 仍在官方 migrate 体内；服端 `0x002E` 权威不变。

### 5.5 控制面下发

```
实验页勾选
  → persistDrop() 写 user.ini [core] auctionTownBypass + 新 writeTickMs
  → payload worker PayloadControl_Poll
       若 gHaveApplied && writeTick 未变 → return（不灌）
       若 login-freeze 或 !IsPlayReady → 只武装 softLogin，不 latch，return
       否则 ApplyControl → SetEnabled(auctionTownBypass)
PLAY boot 全部 Init/StartWorker 之后
  → PayloadControl_ForceApply：gHaveApplied=false 再 Read+Apply 一次
```

UI：`DrawBetaTab` 静态默认 `auctionTownBypass=true`；有 `user.ini` 则以磁盘为准。勾选变化才 `persistDrop`（已勾且 tick 未变时点不到「再下发」——故 boot 必须自己灌对，不能靠用户再点）。

### 6.2 性能（后台占用）

本模块不做 FindAll、不碰 MainPump、不改 `.text`。成本 = 后台指针追链 + 偶尔 1～2 字节写。

| 包 | 会话 | checks | writes | 结论 |
|---|---|---|---|---|
| `0b66c7`（v3 50ms 强写） | ~10min | `hits≈11333` | 每次 tick 都写 | 勤，但仍远低于 MultiSkill/Combat |
| `196d51`（v3.1） | ~2min | 25 | **2** | 快写一次后 hold |
| `b2a253`（同会话续） | ~3.5min 含换图 | 173 | **10** | writes 只跟换图/Bootstrap 抖 |

拍卖卡顿（D217）根因是 `invuln` 在 `GlobalMarket` 狂 FindAll，**不是**本模块 50ms 轮询。

## 8. 副作用与边界

| 项 | 说明 |
|---|---|
| 开着时 | 其它读 `IsTown` / `Option&0x10` 的**本地**逻辑也会当成「可迁移城镇」 |
| `QueryNativeIsTown` | status / 标题等可读；**auto_supply 挂机图判定必须走 `map_info.tsv`**，禁止读本接口 |
| 关开关 | 最多约 500ms（Worker off 拍）才写回字段 |
| 服务端 | 野外发 `0x002E` 常被拒或直接断 TCP；可见 `GlobalMarketTerminated`(op `0x018E`) |
| **与守护叠加** | 断线 → `kick_sniff` `disconnectSeq++` → 挂机「守护模式」5s **干净重拉**（用户体感像被杀死）。**不是** NGS/改内存被杀 |
| `world_port` | **只读**；本模块自行写 Info，不扩展 port 写 API |

## 9. 验收

1. **默认开**（新档 / 无 ini 键）；显式关则野外应弹区域限制  
2. 进图后**不必**再点实验页；日志在 `Init`/`worker start` 后很快出现 `SetEnabled 1` + `data-plane`（可有 `force-apply after play-boot`）  
3. 野外点原生拍卖 → 客户端发 `0x002E`；日志 `zero .text` + `off=meta|meta-partial`  
4. 稳住期 `writes` 几乎不涨；换图才增加  
5. 若服端断线且守护开着 → 预期干净重拉（非本模块 bug；可关守护或关本开关）  
6. 关功能 → 野外再点应恢复区域限制弹窗  
7. 无 `text patches` / 无 GA `.text` 改写  
8. 既有 feature（drop_alert / combat / auto_supply 挂机图）无回归
