# char_boot Feature 模块设计（Classic TWMS）

> **状态**：📐 规格打磨 · **未落码** · v1 只做法师 1 转  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **本模块**：独立 feature，不是补给的一种行程，不是赶路预设，不是 F5 的任务模式。  
> **预定代码**：`x/features/char_boot/` · `common/xcat_char_boot.*` · 面板独立 TAB（`workspace_tabs.cpp` `WorkspaceTab::CharBoot`）  
> **对照**：本仓 `auto_supply` 的编排手法（HardPause / 落台 / travel 终态 / manualSeq）。枫星只借「编排器不出刀」。  
> **对话**：v1 **复制**开店的 Talk+点选，**不**重构 `shop_port`。

---

## 0. 一句话

点「开始」：岛上农场刷到出发条件 → 楓之港桑克斯坐船 → 魔法森林室外 → 树顶脚本门进图书馆 → 汉斯转法师 → 出馆 → 赶到用户指定的**转职后挂机图**，把 F5 交给那边。  
打怪、赶路、加点、加技能、补给回图用现成模块。本 feature 只编排、互斥、等终态。

## 1. 模块边界（硬）

这是一个**新模块**。落码时按独立 feature 挂，不要把状态机塞进 `auto_supply.cpp` / `travel.cpp` / `simple_combat.cpp`。

| 层 | 路径 | 职责 |
|---|---|---|
| worker + SM | `x/features/char_boot/char_boot.{h,cpp}` | 切态、HardPause、RequestGoto、Talk、等 map/vitals |
| 配置契约 | `common/xcat_char_boot.h` | `[char_boot]` / `[char_boot_status]` 读写 |
| 面板 | `workspace_tabs.cpp` **独立 TAB** `CharBoot` | 开始/停止、两张图、策略、建角勾选、只读态 |
| 启动 | `x/probe/xcat_probe.cpp` · `x/probe/CMakeLists.txt` · `common/CMakeLists.txt` | `Init`/`StartWorker` 在 `auto_supply` **之后**（要调它的 Record）；`StopAllFeatureWorkers` 里 **先** `char_boot::StopWorker` 再停补给 |

**调用、不吞并**：

| 现成模块 | 本 feature 怎么用 |
|---|---|
| `simple_combat` | Farm / 挂机图出刀都靠它；行程里用 HardPause 位 `CharBoot` 停刀 |
| `travel` | 同盘 Goto；Busy 时禁止世界地图抢走 |
| `shop_port` Talk | 泵上 TalkToNpc；点选逻辑**复制**一份到本模块 |
| `auto_stat` / `auto_skill` | 旁路等终态，不发包 |
| `auto_supply` | 互斥 Busy；**成功到达挂机图后**单向调用 `RecordHangupFarmMap`（§6.8） |
| `auto_lie` / `encounter` / `invuln` / `sellbag` | 冻态 / 预检 / Fail |

禁止：把起号做成补给 `manualKind`、做成 travel 宏、做成 F5 内置任务。禁止本模块改 `[auto_supply]` 的开关和买药规则。

## 2. 范围

### 2.1 v1 做

| 项 | 行为 |
|---|---|
| 一键起号（法师） | 单次行程；`job` 锁死 `200` |
| 自动创建角色（可选） | 勾选后，**选角页**账号无角色时建一个；默认进 **1 槽**（`core.charSlot`，1-based）。名字随机小写字母，重名再随机。见 §3.1 |
| 出发策略 | **单选**：等级 ≥ N，或金币 ≥ M。只决定 **要不要离开岛上农场** |
| 硬门 | `job==0` 且 `level>=8`；智力 20 为 **可关假设**（§4.1） |
| 坐船 | `60000` / NPC `22000` → `mapId==104000000` |
| 进厅 | `RequestGoto(101000000)` 禁止直跳图书馆；`FirePortalByName("jobin00")` → `101000003` |
| 转职 | `TalkToNpc(1032001)` → `job==200` |
| 加点 | 不调 SendAp；等 `auto_stat` |
| 加技能 | 不调 SendSp。**8–9 级转完不加技能**（`PhaseOf` 从 10 级才加 1 转书） |
| 转职后挂机图 | 用户自定义 `hangupMap`；出馆后 `RequestGoto`；到站清 Pause，F5 在该图出刀 |

两张图 **不是同一个键**：

| 键 | 盘 | 何时用 |
|---|---|---|
| `farmMap` | 枫之岛 | 转职前刷级 |
| `hangupMap` | 维多（与魔法森林室外同盘可达） | 转职后挂机 |

共用一个字段 = 要么岛上刷完去不了维多，要么转完补给试图走回嫩寶。

### 2.2 v1 不做

| 项 | 理由 |
|---|---|
| 剑/弓/盗/海盗 | 进厅边类型不同 |
| 捏脸 / 选外观 | 用客户端 `InitNewCharEquip` 默认初心者外观；法师是岛上转的，创建时不选法师脸 |
| 删角 / 占第 2 槽 | 槽 1 已有角色就跳过创建，走现有选角；禁止删角，禁止空号时连建两个 |
| 买短杖 / 补蓝 / 自动开补给 | `auto_supply` |
| 改 travel 自动摆渡 | 船留在本编排 |
| 手搓 opcode 64/66 | 走 `TalkToNpc` + UI |
| 手搓登录 opcode 9/10 | 走 `SendCheckDuplicateIDPacket` / `OnClickButtonYesAvatar` |
| 抽公共 NpcScriptWalker | 会碰自动开店 |
| 断线后续跑 | Fail；避免汉斯对话半截重入 |
| 运行时强开 F5 | `payload_control` 每拍按 ini 打掉 |
| fill+Doing 进 `jobin00` | 封禁面 |
| 岛上 `farmMap` 填维多 | travel 过不了船 |
| `hangupMap` 填岛 / 奥西利亚 | 同盘 BFS 不可达 |
| 改 `PhaseOf` | 旁路契约，不为本 feature 开口 |
| 为 Stop 给 `FirePortalByName` 加 abort | 贴门最长约 14s，返回后再 Fail |

## 3. 分层（硬）

```
char_boot worker     切状态、HardPause、RequestGoto、Talk、等 mapId/vitals
simple_combat        只在岛上 Farm 出刀（HardPause 关闭时）；挂机图到站后也靠它
travel               同盘贴门；Busy 期间禁止世界地图抢走 Goto
shop TalkToNpc       泵上；preferTemplateId
char_boot 点选       复制开店：Say/YesNo 点 Ok；List 才按关键词
auto_stat / auto_skill   旁路；编排不发包
autopot / auto_lie / encounter / invuln   用户原开关；测谎时冻态
```

禁止：`ImpactSetVelocity`、出刀 `OnFuncKey`、`SendAp`、`SendSp`、手组 64/66。禁止在局内 worker 里调 `OnClickButtonNew` / 查重 / 建角 CALL。

### 3.1 登录建角（可选，挂 `auto_enter`，不进局内 SM）

创建角色发生在 **选角页（`UILoginNew`）**，不是岛上农场。现规格里 char_boot 的 Arm 假设已经进图。把建角塞进 `GotoFarm` 之前的局内拍 = 调登录 UI 的空指针。

| 层 | 谁做 |
|---|---|
| 勾选 / ini | `[char_boot] autoCreateChar`；控件在「一键起号」TAB |
| 执行 | `auto_enter` 在 `WaitCharSelect` / `PickChar`：**`GetAvatarCount()==0` 才建** |
| 槽 | 复用 `[core] charSlot`，默认 **1**（`index = charSlot-1`）。**不要**在 char_boot 再做一套槽号 |
| 进图之后 | 仍是现有 char_boot 岛上 SM，与建角无关 |

`auto_enter` 今天在 `avatars still 0` 会永远停在 `WaitCharSelect`。本选项就是填这个洞，不是新登录 SM。

**前置**：自动进游戏必须开着，否则到不了选角页。勾了建角但没开自动进 → 面板黄字，不要假装会建。

**何时建 / 不建**：

| 选角页状态 | 行为 |
|---|---|
| `GetAvatarCount()==0` 且 `IsSlotEnable(0)` 且 `SlotCount>=1` | 点 New → 随机名查重 → 确认外观 → 等 `count>=1` → 再走现有 `SelectCharacter(0)` |
| `count>=1` | **跳过创建**，按 `charSlot` 进已有角色。禁止因为勾了选项就再占一个槽 |
| `count==0` 但 `charSlot!=1` | Fail：空账号建成也只有 1 槽，对不上用户要的槽 |
| 槽满（`count >= SlotCount`） | Fail，不删角 |
| 已在游戏内（`playReady`） | 本选项无操作；局内起号照旧 |

**名字**：

- 8 个小写 `a-z`（ASCII）。不要中文、不要数字、不要可配置前缀。
- 查重失败（仍停在取名面板 / 超时未见外观面板）→ 换一个名字再发，最多 **20** 次，然后 Fail `name_taken`。
- 长度：产品默认 8。运行时读 `UIInputField+0x194`（`m_CharacterLimit`）；若 `0 < limit < 8` 则改用 `limit`（下限 4）。`limit==0` 当无上限，仍用 8。
- 禁止手搓 C2S opcode 9/10；走托管 `SendCheckDuplicateIDPacket` / `OnClickButtonYesAvatar`，必须 MainPump。`il2cpp_string_new` 同样只许泵上。

**外观**：`SetCheckedName` 成功后客户端自己 `InitNewCharEquip`。不要点 Left/Right 换装。初心者进岛，转职仍是汉斯。

**进程**：worker 在 payload（`xcat.dll`），约 100ms 一拍。面板在 `xcat.exe`，只写 `[char_boot]` / 读 `[char_boot_status]`。不要把状态机放到 GUI 进程。

**图号**：比较、跳态、农场带一律用 `ports::world::GetMapId()` **整型**。`RequestGoto` 传十进制无前导零（`"40000"`），交给 travel `ResolveTarget`。禁止拿 travel 的 9 位补零字符串跟 `GetMapId()` 做 `==`。

**旋翼所有权**：

- `travel::IsActive()` 为真时禁止 `FirePortalByName`。进厅 / 出馆前必须 `RequestStop` 并等到 Idle。
- HardPause 上升沿会 `BeginLieSafeLand`。**Pause 之后、任何 `RequestGoto` / Talk / Fire 之前**必须走 §6.2 的 `WaitSafeLand`。
- `FirePortalByName` 阻塞（单次贴门上限 14s）。EnterLib / ExitLib 在墙内重试，不把第一次 `NOT_STOOD` 当死。

## 4. 条件：两层，不要揉

「金币到了去转职 / 等级到了去转职」= **Farm 离岛谓词**（`UserTrigger`）。汉斯不收钱。人已经站在港、维多、图书馆，不再因 `mesoMin` 把人拽回蜗牛图。

**船费 150 是必收**，与 `UserTrigger` 不是同一层：岛上不够就留下刷；人已经在 `60000` 但 `meso<150` → Fail `ship_fare`（港上刷不到蜗牛，禁止干等、禁止拽回农场）。

### 4.1 硬门 `OfficialReady`

| 条件 | 真源 | 性质 |
|---|---|---|
| `job==0` | `CharacterStat.job @+0x3A` | 铁。已是 200 则跳 WaitSpend → 出馆/挂机图 |
| `level>=8` | `Vitals.level @+0x38` | 铁。法师 1 转下限 |
| `base INT>=20` | `ReadBaseApStats().intel @+0x40` | **假设**。配置 `requireInt20`，**默认开**；汉斯 BIN 若 INT 4 能转则改默认关 |

`OfficialReady = (job==0) && (level>=8) && (!requireInt20 || intel>=20)`

智力必须用基础四维，不用装备加算。

Farm 里：`requireInt20 && level>=8 && intel<20`：

- 加点开着 → 留下刷，status「等待智力」；`farmTimeoutMin` 仍走
- 加点关着 → Fail「智力不足 20，请开自动加点 0/0/5/0，或关掉智力门槛」

Arm 时若已经 `level>=8 && intel<20 && requireInt20 && 加点关` → 直接 Fail。

### 4.2 出发策略 `UserTrigger`（单选）

| `departKind` | 触发 | 默认 | 钳制 |
|---|---|---|---|
| Level | `level >= levelMin` | 8 | 写入钳在 8..200 |
| Meso | `meso >= mesoMin` | **1000** | 下限 **1**、上限 **2e9**（禁止 0） |

金币：`ReadMoney()` / `Vitals.meso @+0x58`。读失败（`-1`）视为未触发，继续刷。

```
UserTrigger   = Level ? (level>=levelMin) : (meso>=mesoMin && meso>=0)
shipFareOk    = (meso>=150 && meso>=0)      // 桑克斯必收 150；读失败(-1) 不当够
readyToLeave  = OfficialReady && UserTrigger && shipFareOk
```

`kShipFareMeso = 150` 常量，不是配置。任务 1040「推荐函免费」**不走**：不做推荐函检测，也不把港上 Talk 当成可免单。等级策略在 8 级但金币 <150：留下刷，status「船费 150」。

`mesoMin` 默认 1000 仍是「何时离岛」的用户选择，**不要**为了船费把默认改成 150。`mesoMin=1` 时离岛仍被 `shipFareOk` 托到 150。

面板两个 radio，只显示当前策略的数字。金币 + 农场仍是 `40000–40002`：黄字「嫩寶几乎不掉钱」。

### 4.3 加点 / 加技能（旁路，不改用户 ini）

| 检查 | Arm |
|---|---|
| 加技能开且 `job1` 非 0 非 200 | Fail「加技能不是法师」 |
| 加技能开且 `job1==0` | Fail「未选 1 转技能书」 |
| 加技能关 | 允许；转完不加技能不算失败 |
| 加点配比 | **不改**。只提示建议 `0/0/5/0` |

`auto_skill::PhaseOf` 只在 **10–29 级**加 1 转书。法师 8 转后 WaitSpend **不等技能**。char_boot 不改 `PhaseOf`。

## 5. 地理与锚点（DUMP / IDA）

产品 = 经典版。图号来自 `map_names` / `map_life` / `travel_graph.seed.tsv`。

### 5.0 位数陷阱（写进规格，禁止再混）

| 图号 | 名 | 盘 |
|---|---|---|
| `1010000` | 楓葉村 | **枫之岛**（七位数） |
| `60000` | 楓之港 | 枫之岛 |
| `104000000` | 維多利亞港 | **维多** |
| `101000000` | 魔法森林（室外） | 维多 · **城镇**（`% 1000000==0`），不能当挂机图 |
| `101000003` | 魔法森林图书馆 | 维多 · **不能当挂机图** |
| `101010000` | 魔法森林北郊（默认挂机图，见 §5.3） | 维多野图 |

枫之岛判定：**`mapId < 100000000`**。`1010000` 是岛上的村，**不是**维多。

### 5.1 岛与起号农场 `farmMap`

| 图 | 名 | 角色 |
|---|---|---|
| `40000/1/2` | 嫩寶狩獵場 | 默认起号农场带；`returnMap=60000` |
| `60000` | **楓之港** | 坐船。不是楓葉村 |
| `22000` 桑克斯 | `(3360, -222)` | 船 NPC |
| `20002` 比格斯 | `(585, 522)` | 禁止点（必须 `preferTemplateId=22000`） |

配置为 `40000/1/2` 之一时，三张都算「在农场」；其它 `farmMap` 精确匹配。

船成功：**只认** `GetMapId()==104000000`。客户端无 `20009` 航船图。

**v1 `farmMap` Arm 预检**：

| 码 | 条件 |
|---|---|
| `farm_cross_plate` | `farmMap >= 100000000` |
| `farm_is_harbor` | `farmMap == 60000` |
| `farm_is_town` | `auto_supply::IsTownMapIdHeuristic(farmMap)`（**不要**用原生 `QueryNativeIsTown`） |
| `farm_unreachable` | 当前也在岛上，但 `PathHopCount(当前, farmMap) < 0` |

### 5.2 维多 → 图书馆

**禁止** `RequestGoto(101000003)`：种子只有出门 `jobout00`，没有进厅 tm 边。

| 步 | 目标 | 机制 |
|---|---|---|
| 赶到 | `101000000` 魔法森林室外 | 同盘 BFS（港→海岸→三叉路→弓箭手村→南郊→魔法森林） |
| 进厅 | 门名 `jobin00` | `FirePortalByName` StickUp |
| WZ | `pt=7` `enterMagiclibrar` | dump `(334, -3987)`；AbsPos **更大 Y = 更高**，树顶 |

汉斯：`101000003` / 模板 `1032001` / `(-7, -77)`。室外没有汉斯。

`GotoEllinia` 墙钟 **600s**。树顶门单次贴门 **14s**，120s 墙给多次重试。

### 5.3 转职后挂机图 `hangupMap`

用户自定义。默认 **`101010000`**（魔法森林北郊；`map_names` + `map_info.town=0` 已核对）。种子：`101000000/top00` 一跳可达。面板仍保留「填入当前图」。

**Arm 预检**（相对 `101000000` 做图论，人不必已经在维多）：

| 码 | 条件 |
|---|---|
| `hangup_empty` | `hangupMap <= 0` |
| `hangup_is_lib` | `hangupMap == 101000003` |
| `hangup_is_town` | `IsTownMapIdHeuristic(hangupMap)`（含 `101000000` / `104000000`） |
| `hangup_unreachable` | `PathHopCount("101000000", hangupMap) < 0`（岛、奥西利亚、缺边都走这条） |

`PathHopCount == 0`（填成魔法森林室外）会被城镇启发式先拦住。

出馆：种子 **有** `101000003/jobout00` pt=1 tm=`101000000`，再 `101000000/top00` → `101010000`。从图书馆 `RequestGoto(hangupMap)` 图论通。

`GotoHangup` 直接 `RequestGoto`。仅当 `Unreachable` 且仍在 `101000003` 才 `FirePortalByName("jobout00")` 再重试。不要默认走树顶那套 Fire。

`101010000`：`map_info.town=0`，`returnMap=101000000`。默认挂机图不是城镇。死亡回魔法森林室外，再 Goto。

到站后必须 `auto_supply::RecordHangupFarmMap("char_boot_hangup")`，再 `PeekLastFarmMap` 对上 `hangupMap`。对不上 → Fail `hangup_record_miss`（被城镇跳过或 CurrentMapId 还不是目标）。不要假装交接成功。

为什么必须显式写、不能靠 F5：`RecordHangupFarmMap` 只在 `simple_combat::SetEnabled(true)` **上升沿**记一次（`simple_combat_on`），换图不会更新。起号时 F5 早已在岛上打开，记的是 `40000`；到维多挂机图 F5 不会再 rising-edge。不显式覆盖，补给第一趟「回挂机图」会跨盘走回嫩寶。这是单向交接，不是把起号做成补给子行程。

转职已成功、GotoHangup 尚未到站就 Fail：**不要**改 `lastFarmMap`（当前图多半是馆/城/路过）。下次再点开始走跳态 1–4。通知写清「职业已转，补给挂机图仍是岛上」。

## 6. 状态机

### 6.1 总图

```
Idle → Arm → 跳态(§6.3)
     → GotoFarm → Farm ⇄ GotoFarm
     → GotoHarbor → BoardShip
     → GotoEllinia → EnterLib
     → JobTalk → WaitJob → WaitSpend
     → GotoHangup → (Unreachable 且在馆则 ExitLib) → Done → Idle
     ↘ Abort/Fail → Idle
```

`ExitLib` 仅当 `GotoHangup` 报 Unreachable 且人还在 `101000003`。已经在挂机图则跳过。

**行程快照**：Arm 成功那一拍把 `farmMap` / `hangupMap` / `departKind` / `levelMin` / `mesoMin` / `requireInt20` / `farmTimeoutMin` 拷进行程。途中改面板 **不影响**本趟（Stop 除外）。不要边赶路边追着 ini 改目标。

**频道快照**：Arm 时 `channel_hop::LastKnownChannel1Based()`。两边都 `>0` 且中途变了 → Fail `scene_interrupt`。任一侧为 0（未知）不判。不要在卸图窗里把「读不到」当成换频。

不变量：

- 任一时刻最多一个 char_boot 行程。
- 岛上 Farm：HardPause **关**。其它运行态（除 Idle/Done）：HardPause **开**。Done 清 Pause。
- **冻态**（不切态、不 Talk、不新 Goto；墙钟暂停）：`auto_lie::IsBusy()`，或 `!IsPlayReady()`。
- 换频（快照有效时）、回城卷、世界地图抢走 travel：Fail，不重规划。
- 初心者即使已经站在 `hangupMap`，仍走跳态去图书馆转职。挂机图不是「已经在这儿就跳过汉斯」。

`IsBusy()` = `state != Idle`（含 Arm / Done 那 2 秒）。

### 6.2 各态

| 态 | 成功 | 失败 | Pause | 墙钟 |
|---|---|---|---|---|
| Arm | 预检过、跳态完成 | §7.2 | 预检完再按目标态设 | — |
| GotoFarm | `MapStable(农场带)` | 硬失败 / 无敌关 / CombatOn | 开 | 180s |
| Farm | `readyToLeave` 且仍在农场带 | 智力门槛且加点关 / F5 被关 / 无敌关 | **关** | `farmTimeoutMin`（0=无）；仅本态走表，冻态不计 |
| GotoHarbor | `MapStable(60000)` | 硬失败 / 无敌关 / CombatOn | 开 | 180s |
| BoardShip | `map==104000000`（playReady 可稍后） | Talk 8 次无换图 / 90s | 开 | 90s |
| GotoEllinia | `MapStable(101000000)` | 硬失败 / 无敌关 / CombatOn | 开 | **600s** |
| EnterLib | `map==101000003` | 见 §6.6 分码 | 开 | 120s |
| JobTalk | 对话在推进 | 8 次无 job 变化 / 90s | 开 | 90s |
| WaitJob | `job==200` | 15s 仍为 0 | 开 | 15s |
| WaitSpend | §6.7 | 不因加点失败 | 开 | 20s |
| ExitLib | `map==101000000` | 同 §6.6 分码（门名 `jobout00`） | 开 | 60s |
| GotoHangup | `MapStable(hangupMap)` | 硬失败 / 无敌关 / CombatOn | 开 | **600s** |
| Done | 2s 提示 | — | **清** | 2s |

`MapStable(target)`：目标图 + `!travel::IsActive()` + `IsPlayReady()` 连续 ≥ **400ms**。

Goto 协议（岛内 180s / 维多 600s）：

1. `WaitSafeLand`：`IsSafeLandActive()` 则等；travel 活跃则等；未挂台则 `RequestSafeLand`；`NativeCooldownRemainingMs()>0` 则等。飞控读不到：放行。
2. `!IsFarmingActive()` 再 `RequestGoto`。
3. Idle + 硬失败（Unreachable / FakeFireStop / BadTarget / FireStuck）→ Fail。
4. Idle + `AlreadyThere` 或已在目标 → 转等 `MapStable`（**不要**学补给忽略 AlreadyThere）。
5. Idle + 图不对 + 距上次 goto>400ms → 再 `RequestGoto`。
6. `FailKind::CombatOn` → Fail「打怪未暂停」。
7. 无敌被关 → Fail `invuln_off`。

GotoHangup 途中死亡：留在本态，再 `RequestGoto(hangupMap)`，直到 `MapStable` 或 600s。维多回城点通常仍同盘。

BoardShip / JobTalk / EnterLib / ExitLib / GotoHangup 前：travel Idle，再 `WaitSafeLand`。有 `UIUtilDialogEx` 则先盲点 Ok 直到关掉（最多 8 次）；仍开着 → Fail `dialog_stuck`。禁止对话框还在时贴门。

Farm 每拍离开农场带（含死亡回港）→ `GotoFarm`。

### 6.3 跳态（Arm 之后一次）

按 **从上到下第一条命中**。金币策略 **不**参与本表。

| # | 条件 | 落入 |
|---|---|---|
| 1 | `job==200` 且 `map==hangupMap` | 先 §6.8 Record+Peek；若 AP=0 且（`level<10` 或加技能关）→ Done；否则 WaitSpend 再 Done |
| 2 | `job==200` 且枫之岛 | Fail「已是法师但还在岛上」 |
| 3 | `job==200` 且 `map==101000003` | WaitSpend → GotoHangup（Unreachable 才 ExitLib） |
| 4 | `job==200` 且维多 | WaitSpend → GotoHangup |
| 5 | `job` 不是 0 也不是 200 | Fail「只做法师初心者」 |
| 6 | `map==101000003` 且 OfficialReady | JobTalk |
| 7 | `map==101000003` 且非 OfficialReady | Fail「在汉斯处未达硬门」 |
| 8 | `map==101000000` 且 OfficialReady | EnterLib |
| 9 | `map>=100000000` 且 OfficialReady | GotoEllinia |
| 10 | `map>=100000000` 且非 OfficialReady | Fail「已在维多未达硬门」 |
| 11 | `map==60000` 且 OfficialReady 且 `shipFareOk` | BoardShip |
| 11b | `map==60000` 且 OfficialReady 且 `meso>=0 && meso<150` | Fail `ship_fare` |
| 12 | 枫之岛且 `readyToLeave` | **GotoHarbor**（港+硬门已被第 11 行接走） |
| 13 | 枫之岛且非 `readyToLeave` | 已在农场带则 Farm，否则 GotoFarm |

第 11 行：人已经在港且硬门满足，**不**再等 `UserTrigger.mesoMin`（不拽回农场）。船费仍要够。

第 11b：港上 `meso>=0 && meso<150` 直接 Fail。禁止留在 `60000` 空转，禁止 `GotoFarm` 为凑船费。`meso<0`（读失败）本拍不入 BoardShip、不走 11b，等下一拍。

BoardShip **入态**检查 `shipFareOk`。入态后桑克斯扣 150、图还没变成 `104000000` 时 meso 会低于 150——内环 **禁止**再拿 `meso<150` 自杀。

第 9 行：初心者站在 `hangupMap` 也要去图书馆，禁止「已经在挂机图就 Done」。

转职已成功、GotoHangup 中途 Fail：再点开始走第 1–4 行，**不会**再跟汉斯对话。

### 6.4 Farm

- Arm **要求** `[core] simpleCombat` 已开。禁止只调 `SetEnabled(true)`。
- 不改用户 F5 ini。Done/Fail 也不关 F5。
- 运行中 F5 被关 → Fail `combat_off`。无敌被关 → Fail `invuln_off`。
- 离开去港：`SetHardPause(CharBoot,true)` → `WaitSafeLand` → `!IsFarmingActive()` → `RequestGoto(60000)`。
- 400ms 读 vitals；5s 节流日志 `farm lv= int= meso= ready=`。
- `farmTimeoutMin`：只在 Farm 态、非冻态累加。遇人停手不 Fail，超时照走。

### 6.5 对话（v1 行为）

复制开店，不抽公共层。点选逻辑放 `char_boot.cpp` 匿名命名空间，**不**新建 walker 文件。`preferTemplateId` 走现成 `TryTalkNearestNpc`。已有对话框开着：先点选，禁止叠一次 Talk。

| Type | 行为 |
|---|---|
| Say (0) | `OnClickBtOk` |
| YesNo (1) | 同 Say，盲点 Ok。**不**读正文 |
| List (4) | 文案命中关键词才 `SelectMenu+Ok`。无命中 **Rejected**，禁止点第 0 项 |
| 其它 | Fail `BadType` |

节流：点选 ≥400ms；Talk 重试 ≥3500ms。船看 map，转职看 job。

List 预置词（BIN 可改表）：

| 谁 | 命中 |
|---|---|
| 桑克斯 | `維多利亞` `维多` `乘船` `搭船` `前往` `150` `楓幣` |
| 汉斯 | `魔法師` `法师` `轉職` `转职` `成為` `成为` |

Talk 8 次无结束谓词 → Fail。List Rejected → Fail，日志带菜单摘录。**禁止**抄开店「无关键词点第 0 项」。`!playReady` 冻点选、冻新 Talk，不计入 8 次。

远距：先 Talk。连续 2 次 `no target npc` 或对上模板但 map 不变超过 2 轮 → Fail `talk_far`。刀 2 BIN 若必现，再加同图 heli 贴 `(3360,-222)`，禁止填进刀 2 主路径。

#### BoardShip 内环

```
WaitSafeLand；travel Idle
入态时若 meso>=0 且 meso<150 → Fail ship_fare
loop:
  map==104000000 → 成功
  冻态 → continue
  有对话框 → 按上表点
  否则 TalkToNpc(22000)
  Talk 满 8 次且从未换图 → Fail
  90s → Fail
```

入态后不再用 meso 当失败条件（扣费早于换图）。

卸图掉 playReady 是预期。测谎解开后：对话框还在就继续点；图已是维多港则成功；对话框没了图没变则再 Talk。

### 6.6 EnterLib / ExitLib（失败码必须分开）

**EnterLib**：`RequestStop` → Idle → `WaitSafeLand` → 循环 `FindPortalByName("jobin00")` → `FirePortalByName`。同图还有 `in04/enterERShip`，禁止当进厅门。

**ExitLib**（仅 GotoHangup Unreachable 回退）：同样流程，门名 **`jobout00`**，成功谓词 `map==101000000`。这是种子里的 **pt=1 普通门**，不是脚本门。

| 码 | EnterLib | ExitLib |
|---|---|---|
| `NO_PORTAL` | 枚举不到 `jobin00` | 枚举不到 `jobout00` |
| `STICK_FAIL` | 120s 内多次贴不上树顶 | 60s 内多次贴不上出门 |
| `FIRED_NO_WARP` | 已 FIRED，8s 仍是 `101000000` | 已 FIRED，8s 仍是 `101000003` |

单次 `NOT_STOOD`：**重试**，间隔 ≥400ms。禁止 fill+Doing。`FirePortalByName` 阻塞期间 Stop：返回后再 Fail `user_stop`。

### 6.7 WaitSpend

- 已在 `hangupMap` 且 AP=0 且（`level<10` 或加技能关）→ **跳过本态**（跳态第 1 行：Record 后 Done，不要为等 2s 停刀）。
- 加点关或 AP=0 连续 2s → 加点侧完成。
- `level<10`：**不等 SP**。日志 `WaitSpend skip_skill lv=`。
- `level>=10` 且加技能开：SP 连续 5s 不变或 15s 墙。
- 总墙 20s 后进入 ExitLib / GotoHangup，不 Fail。

### 6.8 GotoHangup

WaitSpend 之后：

1. `MapStable(hangupMap)` → 走下面「到站交接」。
2. 否则 `RequestGoto(hangupMap)`，墙 600s（当前图可以是图书馆；种子有 `jobout00`）。
3. Idle + `Unreachable` 且仍在 `101000003` → `ExitLib` 后再 Goto。
4. 其它硬失败 → Fail。

**任何进入 Done 的路径都要先做交接**（含「已经是法师、已经站在挂机图」）。F5 上升沿不会再来一次。

到站（`MapStable`）**先于**清 Pause：

1. `auto_supply::RecordHangupFarmMap("char_boot_hangup")`
2. `PeekLastFarmMap` **按整型比较**必须等于行程快照 `hangupMap`，否则 Fail `hangup_record_miss`（禁止字符串直接 `==`，travel 可能写补零 key）
3. 切 Done

日志必须有：`GotoHangup map=<hangupMap>`、`RecordHangupFarmMap <id> (char_boot_hangup)`。

### 6.9 Done

- HardPause **清** → F5 保持 → 在挂机图出刀（这才是挂机图存在的理由）。
- 通知 Success：「转职完成（法师），已到挂机图。8 级技能点要到 10 级才会加。」
- 2s 后 Idle。不要 Done 后继续 Pause。

## 7. 失败、互斥、看门狗

### 7.1 Fail

1. `travel::RequestStop()`
2. `SetHardPause(CharBoot, false)`
3. 日志 `CharBoot fail why= state= map= lv= job= int= meso=`
4. 通知 Warning
5. Idle；面板保留 `lastWhy`

不杀进程、不改加点/技能 ini、不关无敌、不关 F5。Fail **默认不改**补给 `lastFarmMap`。只有 §6.8 Peek 成功之后挂机图才交出去（之后即使立刻 Stop 也不撤回）。

已转职再 Fail：职业保留，下次走跳态 1–4。通知若 `job==200` 且没交过挂机图：加一句「补给回图仍是岛上，请再点开始」。

停止按钮 = Fail `user_stop`。Done 期间点停止：直接 Idle。

### 7.2 Arm 预检（任一失败即停）

- 未 playReady
- 无敌关
- 自动打怪未开（认 ini 的 `simpleCombat`，不认 `IsFarmingActive`）
- `job` 不是 0 或 200
- 加技能职业冲突（§4.3）
- `requireInt20 && level>=8 && intel<20 && 加点关`
- `farmMap` 钳制（§5.1）
- `hangupMap` 钳制（§5.3）
- `auto_supply::IsBusy()`
- `sellbag::IsBusy()`
- 已 Busy（按钮应为停止，不应再 Arm）

### 7.3 HardPause

`HardPauseHolder::CharBoot = 1u << 5`。

**必须同期**写入 `simple_combat.cpp`：`kSafeLandHoldersMask`、`SafeLandBeginWhy` / `EndWhy`（`char_boot_pause_on/off`）。只加工枚举位 = 停刀不落台。

Busy 期间互斥（payload 同进程，`IsBusy()` 在 `.cpp` include，避免头文件环）：

| 谁 | 做什么 |
|---|---|
| `auto_supply` 开趟 | 查 `char_boot::IsBusy()`，拒开 |
| `worldmap_marker_travel` | Busy 时忽略 Spot（Notice「起号进行中」）。现码连补给都不拦，必须自己拦 |
| 开店 / sellbag | Arm 已拒；行程中手开店 → Fail `shop_busy` |

### 7.4 看门狗（每拍，所有运行态）

| 事件 | 动作 |
|---|---|
| 测谎 / `!playReady` | **冻态**，墙钟暂停。**不** Fail |
| 遇人停手 | Farm 刷不动；可接受。不 Fail |
| 换频（Arm 快照与当前都 `>0` 且不同）/ 回城卷导致非预期图 | Fail `scene_interrupt` |
| 世界地图仍抢走 travel（Goto 目标不是本态目标） | Fail `travel_stolen` |
| 无敌被关（含 Farm） | Fail `invuln_off` |
| Farm 中 F5 被关 | Fail `combat_off` |

禁止「playReady 连续 10s 假 → Fail」。

### 7.5 死亡

| 当时 | 预期 |
|---|---|
| Farm，嫩寶图，回 `60000` | GotoFarm |
| GotoHarbor，回 `60000` | 成功，进 BoardShip |
| BoardShip | 仍在 `60000` 则继续 Talk |
| GotoHangup | 再 Goto，直到到站或 600s |
| GotoEllinia / EnterLib / JobTalk | 非目标图 → `scene_interrupt` 或硬失败。再点开始走跳态 |

## 12. 验收

1. F5 关着点开始 → Fail，不跑  
2. 死在嫩寶图 → 出现在港 → 自动 GotoFarm，不在港刷  
3. 等级 8、INT 达标 → 才 GotoHarbor  
4. 金币策略、meso 不够 → 8 级仍留农场  
5. 已在 `60000` 且 OfficialReady 且 meso≥150 → 直接上船，不回农场、不等 `mesoMin`  
5b. 已在 `60000` 且 OfficialReady 但 meso<150 → Fail `ship_fare`，不回农场空转  
6. 已是法师且已在 hangupMap、AP=0 → Record 后 Done，不对话、不出馆、不停刀 2s；`lastFarmMap` 仍要写成挂机图  
7. 初心者已在 hangupMap 且 OfficialReady → 仍去图书馆转职，不直接 Done  
8. 已是法师且在图书馆 → 出馆后 GotoHangup，不跟汉斯再转一次  
9. 补给 Busy → 拒绝开始  
10. 8 级转职成功 → 日志 `skip_skill`，不因 SP 不动而 Fail  
11. `jobin00` / `jobout00` 三种失败码可从日志分开  
12. `farmMap=101000000` → Arm `farm_cross_plate`  
13. `hangupMap=101000000` 或 `101000003` → Arm `hangup_is_town` / `hangup_is_lib`  
14. `hangupMap=40000` → Arm `hangup_unreachable`  
15. 坐船卸图期间不得出现 `not_play_ready` Fail  
16. Done 后 `GetMapId()==hangupMap`，且补给 `lastFarmMap` 整型等于该图号  
17. 转职成功但 GotoHangup Fail → `lastFarmMap` 仍是岛上图号；再点开始不再对话  
18. 「填入当前图」在未进图时不把 hangupMap 写成 0  
19. 行程中改 hangupMap 面板值，本趟仍去 Arm 时的快照目标  
20. `autoCreateChar=0` 且空号 → 仍停在选角（现行为），不起号  
21. `autoCreateChar=1` 且空号 → 建成后进 1 槽；已有角色不新建  
22. 查重失败换名，20 次仍重名 → Fail `name_taken`，不进游戏  
23. 工作区第三排有 TAB「一键起号」；首页、挂机时段、自动卖装、超级赶路里都没有起号开始/停止  

**NOT RUN**（规格阶段）：坐船、树顶门、出门 `jobout00`、汉斯对话、智力门槛、Talk 远距、默认 `101010000` 是否在种子里、自动建角（查重回包 / 名长上限 prefab / 空号实机）。
