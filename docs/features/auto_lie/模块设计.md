## 1. 题型映射

| 用户说法 | Classic UI | 应答路径 |
|---|---|---|
| 知识题 | `UIAntiMacroTextCaptcha` | 题图落盘 → `LieAiPump` OCR → 填 `inputField` → `OnOk` |
| 鼠标轨迹题 | `UIAntiMacroNonFinite` | `MapWinCursorBatch` 建屏幕计划 → 物理 `ClipCursor`+`SetCursorPos`；原生采样后自行 `SendAnswer` |

**不做**：Artale MapleQuiz / 像素四选一、内部填 `mousePosList`、构造 CS 测谎包、INLINE HOOK、题库 SHA1 / recorder / overlay；也不做 CharacterName / Notice / Bomb 等其它 AntiMacro UI（见 §1.2）。

### 1.1 测谎从哪来（玩家道具 = 服端弹窗）

被测方看到的 UI 同源：`IsOpenAntiMacro` → TextCaptcha / NonFinite 等。来源包括：

| 来源 | 说明 |
|---|---|
| 服端脚本 / 风控 / GM | 直接开 AntiMacro UI |
| 玩家道具 **測謊機** `2190000`（Consume） | 对他号战斗态使用 → 对方弹同一套 UI |

道具侧（离线表）：

| 项 | 值 |
|---|---|
| ID / 名 | `2190000` / **測謊機**（口头「測謊儀」同物） |
| WZ 基线价 | `shop_prices.tsv` → **9500**（catalog；≠ 实店必卖价） |
| String desc | 侦测不当方式；只能对打怪中角色使用（**未写**商店名） |
| 售卖 | 官方口径「各大城镇杂货/道具店」；本仓 **无** `SetShopDlg` Commodity 货架表（见 `dumps/offline_tables/SOURCE.md`） |
| 维多利亚杂货 NPC（`map_life`） | 港 **米娜**、弓箭手村 **露娜**、魔法森林 **妖精 蓮**、勇士之村 **格里高利/索非亞** 等 |

**auto_lie 只接被测应答**；发起「选人 → 用 2190000」的发包链 **未实现**（opcode NOT RUN，见 P0a）。

## 2. 架构总览

```text

  └─ pause：simple_combat + fly（测谎打开期间）
```

## 3. 控制契约（`PayloadControl` / `user.ini [core]`）

`kPayloadControlCoreIniVersion = **10**`。

| 字段 | 类型 | 语义 |
|---|---|---|
| `autoLie` | bool | 总开关 → `auto_lie::SetEnabled` |
| `autoLieDryRun` | bool | 干跑：LLM 答完**不**调用 `OnOk` |
| `autoLieAlarmTestSeq` | u32 | 递增触发报警测试（~12s 异步 Beep） |
| `autoLieMouseSmokeSeq` | u32 | 递增触发光标烟测（~3s，仅游戏前台锁光标） |
| `writeTickMs` | u64 | 变更时钟；payload `Poll` 差分 Apply |

### 3.1 seq 消费（防吞击 / 防重复）

落盘戳（相对 `XCat_data/`）：

- `state/lie_ai/last_alarm_seq.txt`
- `state/lie_ai/last_mouse_smoke_seq.txt`

规则（`x/ipc/payload_control.cpp`）：

1. `seq == 0` → 忽略  
2. `seq ==` 戳内值 → 已消费，不触发  
3. 否则写戳并 `StartAlarmTest` / `StartMouseSmoke`  

因此：**注入前点过按钮**会在首次 `Poll` 触发；**同值不会**重复响。无戳 + 磁盘残留非 0 seq 时，注入后会响一次（可接受）。

## 4. 目录与文件泵

根目录：`bin/XCat_data/`（payload `GetBinDir()` 与 launcher `prefsBinDir` 对齐）。

| 路径 | 用途 |
|---|---|
| `state/lie_ai/req/` | 待答：`lie_*.{txt,jpg|png}` |
| `state/lie_ai/req/done/` | 泵成功后移入 |
| `state/lie_ai/req/failed/` | 泵失败后移入 |
| `state/lie_ai/ans/` | `lie_*.ans`（须 `ok=1` + `answer=`） |
| `state/lie_ai/status.txt` | 运行态 / 就绪报告（面板读） |
| `state/lie_events/` | 题图归档副本 |
| `state/lie_ai/last_*_seq.txt` | 基建 seq 消费戳 |

### 4.1 req `.txt` 题面

```text
kind=textcaptcha|captcha|fixture_echo|…
q=…
o1=
o2=
o3=
o4=
```

| `kind` | 泵行为 |
|---|---|
| `textcaptcha` / `captcha` | `LlmOcrCaptcha`（视觉模型） |
| `fixture_echo` | 本地回声 `answer=FIXTURE`，**不调 LLM**；`lie_ai.enabled=0` 时仍可消费 |
| 其它（四选一） | `LlmAnswerQuiz`（本仓实机主路径不用） |

### 4.2 ans 格式

```text
ok=1
kind=…
index=1
answer=…
```

payload 仅在 `ok=1` 且 `answer` 非空时进入提交阶段。

## 5. `status.txt` 字段

payload 约 1s 写一次；**关 `autoLie` 时仍刷基建字段**。

| 字段 | 含义 |
|---|---|
| `enabled` / `dryRun` / `busy` | 开关与忙态 |
| `phase` | 见下表 |
| `pendingId` | 当前知识题 id |
| `mouseUi` / `mouseFollow` | NonFinite UI / 正在跟随 |
| `dirsOk` | 目录可写探测 |
| `il2cpp` / `gaBase` / `klass*` / `inputSetText` / `getTransform` / `encodePng` | `ProbeBindReady` 分项 |
| `quizOk` | gaBase + Util + TextCaptcha + InputField.set_text（**不要求** EncodeToPNG） |
| `mouseOk` | gaBase + Util + NonFinite + get_transform |
| `bindOk` | `quizOk && mouseOk` |
| `infraOk` | `dirsOk && bindOk` |
| `infraFull` | `infraOk && encodePng` |
| `alarmTest` / `mouseSmoke` | 基建测试进行中 |
| `lastError` / `writeTickMs` | 诊断 |

### 5.1 `phase`

| 值 | 含义 |
|---|---|
| `idle` | 待命 |
| `dump` | 正在落题图 |
| `wait_llm` | 等 ans（超时 25s → `timeout`） |
| `submit` | 已收到 ans，延迟 1.5~4s 后 OnOk |
| `done` | 已提交或干跑跳过 OnOk |
| `timeout` | LLM 超时（UI 未关则继续报警） |
| `mouse` | NonFinite UI |
| `alarm_test` | 报警基建 |
| `mouse_smoke` | 光标烟测 |

`ClearPending` **保留** `mouse` / `alarm_test` / `mouse_smoke`，避免被清 pending 冲掉。

## 6. 知识题流水线（`auto_lie.cpp`）

常量（实现真源）：

| 常量 | 值 |
|---|---|
| 轮询 UI | 400 ms |
| 轮询 ans | 500 ms |
| LLM 等待 | 25000 ms |
| 提交延迟 | 1500~4000 ms |
| dump 重试间隔 | 1500 ms |
| 实机报警节流 | 3000 ms（异步 Beep） |

流程：

1. `IsTextCaptchaOpen` → `SetExternalPause(true)`（站桩）+ 报警  
2. `DumpTextCaptchaImage`：优先 `Info.jpegData` → `.jpg`；否则 `RawImage` → `EncodeToPNG` → `.png`（本仓 Unity **无** `EncodeToJPG`）  
3. 写 `req/<id>.{jpg|png}` + `.txt`（`kind=textcaptcha`）+ `lie_events` 归档  
4. 等 `ans/<id>.ans`；坏 ans 不提交  
5. 延迟后：`dryRun` → 记 `done` 不 OnOk；否则 `SubmitTextCaptchaAnswer`  
6. UI 关闭 → 清 pending；无跟随则解除 pause

## 7. 轨迹题（`anti_macro_follower`）

1. NonFinite 打开后，准备窗即可 `MapWinCursorBatch`（一次主线程）建屏幕点列  
2. 求解帧起按 `mousePosList.Count` 取点，`ClipCursor` + `SetCursorPos`  
3. 失焦：释放光标、**保留计划**；回前台续跟  
4. 不向服端伪造轨迹；原生 Update 采样 → 客户端自带 `SendAnswer`

## 8. 离线基建（实现要点）

详见 [`基建与离线验收.md`](基建与离线验收.md)。摘要：

| API / 入口 | 行为 |
|---|---|
| `anti_macro_port::ProbeBindReady` | 逐项 FindClass / helpers，不依赖测谎 UI |
| `StartAlarmTest` | ~12s，`BeepAlarmAsync`（不堵 worker） |
| `StartMouseSmoke` | ~3s；**仅** `IsGameForeground` 时锁光标 |
| `LieAiPump_EnqueueFixture(bin, echoOnly)` | 写夹具；`echoOnly=true` → `fixture_echo`；否则 `textcaptcha` + **真 PNG**（见下） |
| 面板「本地泵 / LLM泵 / 测试报警 / 光标烟测」 | `workspace_tabs.cpp` 主页 |
| `scripts/lie_ai_infra_smoke.ps1` | 写 echo 夹具并等 ans（需 `xcat.exe` 在跑） |

**夹具 PNG（`kFixturePng` in `lie_ai_pump.cpp`）**：嵌入 **160×48**、图面文字 `FIXTURE` 的合法 PNG（≈1672B）。曾用手写残缺 IDAT 的伪图，Qwen 报 `HTTP 400 image format is illegal`；必须以可完整 inflate 的 PNG 为准（勿再塞「仅 IHDR 像样」的字节串）。

就绪灯：`infraFull` →「就绪」；仅 `infraOk` →「就绪(无PNG)」；否则「未就绪」。旁侧 `q? png? dir?`。

## 10. 验收

### 离线（服端未开）

见 [`基建与离线验收.md`](基建与离线验收.md)。摘要（BIN 已采证）：

| 项 | 证据 |
|---|---|
| 本地泵 | `launcher.jsonl` `LieAI` → `echo=1` → `answer=FIXTURE`；`req/done/` |
| LLM泵 | 同 tag → `echo=0` → `answer=FIXTURE`（修好夹具后，约 05:06:38）；失败时看 `req/failed/` + `HTTP 400` |
| 基建就绪 | `status.txt`：`infraOk=1` / `infraFull=1` / `quizOk` / `mouseOk` / `encodePng` |
| 报警 / 烟测 | payload `AutoLie`：`alarm test started/finished`、`mouse smoke started/finished` |

### 上线（服端开测谎后）

1. 勾选自动测谎 → 日志 `AutoLie enabled=1`；面板 phase / 就绪灯  
2. TextCaptcha：`req` 落图 → ans →（非 dryRun）OnOk；无泵 25s → `timeout`  
3. NonFinite：计划建立后跟随；失焦可恢复；不卡主线程逐点映射  
4. 测谎期间站桩暂停；UI 关后恢复  
5. 干跑通过后再关 `autoLieDryRun` 实提交  
6. （可选）他号对自号使用 `2190000`，确认与服端弹窗走同一应答链  

当前：**实机 TextCaptcha / NonFinite = NOT RUN**（服端未开 / 未用道具互测采证）。
