# auto_lie 基建与离线验收（Classic TWMS）

> **产品**：新楓之谷：經典版（TWMS）· **不是**枫星 / 不是 Artale  
> **背景**：服端测谎机制短期内未开，无法实机 TextCaptcha / NonFinite。本文档覆盖**不依赖服端 UI**的基建与验收。  
> **对照**：Artale 的 `autoLieAlarmTestSeq` 模式已移植；Lua/ruid/题库 **不搬**。  
> **实现总览 / 道具 2190000**：见 [`模块设计.md`](模块设计.md) §1 / §8–§10。

## 1. 基建清单（已落地）

| 能力 | 入口 | 实现要点 | 依赖服端测谎？ |
|---|---|---|---|
| 目录自建 | payload `RefreshInfra` / 夹具 | `req`/`ans`/`done`/`failed`/`lie_events` | 否 |
| 就绪报告 | `ProbeBindReady` → `status.txt` | `infraOk`≠强制 `encodePng`；见模块设计 §5 | 需注入，不需 UI |

| 报警 | `autoLieAlarmTestSeq` + 戳文件 | ~12s 异步 Beep；`phase=alarm_test` | 需注入 |
| 光标烟测 | `autoLieMouseSmokeSeq` + 戳文件 | ~3s；仅前台 `ClipCursor` | 需注入 |
| 干跑 | `autoLieDryRun` | 答完不 `OnOk` | 开题后联调 |

完整字段、常量、API、流水线见 [`模块设计.md`](模块设计.md)。

契约：`kPayloadControlCoreIniVersion = 10`。  
seq 戳：`state/lie_ai/last_alarm_seq.txt`、`last_mouse_smoke_seq.txt`（相对戳有增量即触发；同值不重复）。

### 1.1 夹具 PNG 坑（已修）

| 现象 | 原因 | 处置 |
|---|---|---|
| LLM泵 `HTTP 400: The image format is illegal and cannot be opened` | 嵌入字节串仅 IHDR「像」64×32，**IDAT zlib 残缺**；本地 PIL 可能仍能开，Qwen 拒 | `lie_ai_pump.cpp` `kFixturePng` 改为可完整 inflate 的真 PNG（现约 1672B，含文字 FIXTURE） |
| 本地泵仍绿 | `fixture_echo` **不读图、不调 LLM** | 与 LLM 通路正交；修图后两者都应绿 |

预览落盘（可选）：`state/lie_ai/llm_pump_fixture.png` / `_gen_valid.png`（与嵌入字节同源时便于肉眼核对）。

## 2. status.txt 字段（payload 写）

```
enabled=  dryRun=  busy=  phase=
infraOk=  infraFull=  dirsOk=
quizOk=  mouseOk=  bindOk=  encodePng=
il2cpp=  gaBase=  klassUtil=  klassText=  klassNonFinite=
inputSetText=  getTransform=
alarmTest=  mouseSmoke=
pendingId=  mouseUi=  mouseFollow=  lastError=  writeTickMs=
```

| 字段 | 含义 |
|---|---|
| `infraOk` | `dirsOk && quizOk && mouseOk`（**不含** `encodePng`；jpegData 通路仍可答知识题） |
| `infraFull` | `infraOk && encodePng`（含 PNG 兜底） |
| `phase` | `idle\|dump\|wait_llm\|submit\|done\|timeout\|mouse\|alarm_test\|mouse_smoke` |

关自动测谎时仍刷基建字段；`ClearPending` **不会**冲掉 `alarm_test` / `mouse_smoke` / `mouse`。

## 3. 离线验收步骤（服端未开）

### A. 仅启动器（可不注入）

1. 打开 `xcat.exe` 主页  
2. 点 **本地泵** → toast + `ans` 含 `ok=1` / `answer=FIXTURE`  
3. **LLM泵** → ans；失败看 toast / `bin/logs/launcher.jsonl` tag=`LieAI`  

脚本：`powershell -File scripts/lie_ai_infra_smoke.ps1`（需 `xcat.exe` 在跑）。

### B. 已注入游戏（仍无测谎 UI）

1. 旁侧就绪灯：绿「就绪」=`infraFull`；「就绪(无PNG)」=`infraOk` 但无 `encodePng`  
2. 旁侧 `q1 png? dir1`  
3. **测试报警**：`phase=alarm_test` + Beep ~12s（可关自动测谎）  
4. **光标烟测**：把游戏切到前台，约 3s 小方框；失焦不锁桌面  
5. 「测谎干跑」：开题后先验不 OnOk  

### C. 服端开题后（上线 · 当前 NOT RUN）

见 [`模块设计.md`](模块设计.md) §10。
