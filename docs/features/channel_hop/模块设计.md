# channel_hop Feature 模块设计（Classic TWMS）

> **状态**：✅ 已挂入 `xcat.dll`（契约 + UI + **直调发包**；结算：离图/InterStage → 软成功；Waiting 硬断即 Fail；成功后 30s 冷却）  
> **源码根**：`x/features/channel_hop/` · IPC：`x/ipc/payload_control.*` · 契约：`common/xcat_payload_control.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）· UI：`xcat_app/workspace_tabs.cpp`  
> **对照**：枫星 `manualRejoinSeq` / Overlay「随机换频」（**SceneManager.Reload + 命名管道，不可复用**）  
> **产品**：经典版 TWMS · **不是**枫星  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) — **禁止 E9 / 改 `GameAssembly.dll` `.text`**。  
> **锚点世代**：2026-08-03 remount（代码真源：`channel_hop.cpp`）

## 职责

- 挂机卡「随机换频」按钮与 **F10** → bump `[core] manualRejoinSeq`
- payload 边沿触发后：**不开任何换频菜单** → 读 `WorldManager` 当前频/频道数 → **优先未满频**随机 → `Field.SendTransferChannelRequest`
- 测谎 busy / 非玩法就绪 / 冷却：延后 pending，不丢 seq
- 遇人自动换频由独立 [`../encounter/模块设计.md`](../encounter/模块设计.md) 调用本模块；本模块不内嵌遇人状态机

## 与枫星差异（勿混）

| | 枫星 | TWMS Classic |
|---|---|---|
| 下发 | 优先命名管道 `kIpcManualRejoin`，失败才 bump seq | **仅** `user.ini [core] manualRejoinSeq` |
| 执行 | `SceneManager.Reload` → UGC 随机分频 | **直调** `Field.SendTransferChannelRequest`（无 UI） |
| 模块 | 挂在庞大的 `auto_relogin` | 独立 `channel_hop` |

## 数据流

```
xcat_app 按钮/F10
  → WritePayloadControl(manualRejoinSeq++)
  → ApplyManualRejoinSeq（磁盘 stamp + 进程内 CAS 去重）
  → channel_hop::RequestManualRejoin
  → Selecting：读 WM 频道信息并随机
  → Confirming：Field.SendTransferChannelRequest(target)
  → Waiting / Notify
```

遇人路径：`encounter::RequestHop` → 同 `RequestManualRejoin`（seq 基址 `0xE1000000`），**不**经 UI stamp。

## 逆向锚点

| 项 | TW 实锤（与代码同步） |
|---|---|
| 当前频道 | 内部 **0-based** `nIdx`；UI `ch.N` = `nIdx+1`。优先 **`WM+0x6C` 前进** → `+0x68` 前进 → `gKnownChannelIdx`；冷启动先 6c 再 68 |
| 频道数 | `WorldManager._adultChannel` **`+0x78`** `List<bool>._size@+0x18`；后备 CCU `worldChannelCount` |
| 发包 | `Field.SendTransferChannelRequest(int nIdx)` RVA **`0xBB5200`**（旧 `0xBB6490`，2026-08-03 remount）· **参数 0-based** · 实例 `GetMapScene()` |
| 独占门控 | `WorldManager.CanSendExclRequest` RVA **`0xDD7C10`** · `type=500`（`0x59CA6471+dword@DB94`）· 调用 `r8=r9=0`。读/写 **`WM+0xA8`**（`+0xA0/+0xA4/+0xAC` 旁邻）。BIN：未过则 **无 `op=44`**，settle「满人」是误诊 |
| 警戒 | 短 `IsAlertMode` RVA **`0x12405C0`**（读 `LocalUser+0x114`；与 [`drop_alert_bypass`](../drop_alert_bypass/模块设计.md) 同锚）。**勿用** CFF 兄弟 `0x1242770`（读 `+0xC8`，曾误钉） |
| 硬断 | KickSniff `LastSessionState`：正常迁频 `Connected→Connecting`；异常 `→Disconnected`（BIN seq=18） |

**明确不做**：`UIGameMenu.OnClickButton`、打开 `UIChannelShift`、`SetChannel`、点 `btChange`。

## FSM

| 状态 | 动作 |
|---|---|
| Idle | 等 pending；门控通过后 Selecting；defer 时通知一次「排队中」 |
| Selecting | 主线程读 WM 频道信息；选频池 **prefer(登录未满) → neutral(无表) → avoid(满/成人/本轮拒收)**；跳过 `WM._adultChannel` 成人频；日志 `pick-pool` |
| Confirming | 若 `IsAlertMode` 则等待（不烧 attempt，最长 20s）；若 `!CanSendExcl(500)` / `WM+0xA8` busy 同样等待（最长 20s）；解除后 `SendTransferChannelRequest`（日志带 A8 前后快照） |
| Waiting | 离图软成功；**KickSniff 见 Disconnecting/Disconnected 或 Login → 立刻 Fail**；未离图仍警戒 → 回 Confirming 同目标；否则满人换其它频（并把该频 `MarkChannelRejected`） |

门控：`IsPlayReady` · **进图冷却 4s**（自进图/落地起**持续记时**，非点 F10 才起算）· 非 CashShop/Login · `!auto_lie` · 冷却（**成功后 30s** / 失败后 3s）。警戒 / excl 均在 Confirming 等（Idle 不 defer，以便先停手）。

开始 hop：`simple_combat::SetExternalPause(true)`；结束时若 `encounter::HoldsCombatPause()` 则**不**抢清 pause。对外 `CooldownRemainingMs()` 供遇人对齐（遇人宽限 `kPostHopGraceMs=32s`）。

满人回退：`kMaxFireAttempts=3`；拒收频写入 CCU 填表 Avoid。成功缓存 `knownIdx`；Login 清缓存与 `gLastRaw68/6c`。toast `ch.(idx+1)`。

**未满优先真源**：进图后无实时每频人数（不开 UIChannelShift）。依赖 auto_enter `PickLeast` 喂入的 `ChannelItem` 填表（`nUserNo`/`ChannelCapacity`/`bAdult`）；无表时退化为原随机（仍跳过成人频）。表会随挂机变旧——拒收回退仍兜底。

## 验收

1. 点按钮 / F10 **不应弹出**游戏换频菜单  
2. 日志 `ChannelHop begin …` → `pick …` → `transfer fired` → `settle ok`  
3. 目标频进不去：日志 `retry … next=`，最多再试到 3 次  
4. 连点第二次不应被 Fail 吞掉  
5. 测谎/冷却/警戒 defer 应有「排队中」通知  
6. 战斗警戒中 F10：应 `waiting alert` / 停手，**不应**连烧 3 个频后 Fail；脱战后一次成功  
7. excl busy：应 `waiting excl` / `excl busy A8=…`，**不应**空烧 attempt；清后应见 `send.log op=44` + `leave play`  
8. 成功后 30s 内再 F10：应 defer「冷却中」  
9. transfer 后会话硬断：应立刻 `fail … 会话已断开`，不挂 Waiting  
10. 图里挂机很久再 F10：**不应**误报「进图冷却」（仅刚进图/刚落地 4s 内）
