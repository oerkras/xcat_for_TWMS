# timed_keys Feature 模块设计（Classic TWMS）

> **状态**：✅ P1 已挂入；发键真源 **`unity_kbd`（InputSystem KeyboardState）** via `input::InjectKeyHold`（旧 OnKey 泵已弃，主线程嵌套会死锁）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **对照来源**：`xcat_for_fengxing` 的 `timed_keys`（**只复用槽位契约 / Tick 状态机 / 磁盘 IPC / 面板交互，不搬 `MOD.MODInput` / 偏移 / Lua**）  
> **源码根**：`common/xcat_timed_keys.*` · `x/features/timed_keys/` · `x/features/ports/input_port.*` · `x/ipc/payload_timed_keys.*`  
> **契约**：`user.ini [timed_keys]`（独立段，对齐对照仓；**不塞进** `[core]`）  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) — **禁止 E9 / 改 `GameAssembly.dll` `.text`**；发键走进程内 API，**禁止 `SendInput` / `keybd_event` 作主路径**

---

## 0. 一句话

经典版「定时按键」= 面板勾选 7 个固定快捷槽（`7/8/9/0/-/=/Z`）后，payload 按各自间隔向游戏 **进程内注入一次按键脉冲**，触发玩家键位映射上的技能 / 物品 / 基础动作。  
对照枫星的队列 + 抖动 + 连败熔断；实现面换成经典版 **`unity_kbd` 键脉冲**（与拟人走路 / 超级赶路 StickUp 同路）。

## 1. 与枫星差异（勿混）

| 维度 | 枫星（对照） | TWMS 经典版（本仓） |
|------|-------------|-------------------|
| 进程 | `msw.exe` / Artale + MOD | `Maplestory_Classic.exe` / Il2Cpp CMS 系 |
| 发键 | `MOD.MODInput.SetKeyInfo` Hold 脉冲 | **`input::InjectKeyHold` → unity_kbd**（KeyboardState 事件）；备选若 BIN 失败再评估 `OnFuncKey` |
| 键码 | Win32 `VK_*` → MOD KeyCode 映射表 | Win32 `VK_*`（配置层）→ Unity `Key`（Digit7=47 … Digit0=50, Minus=13, Equals=14, Z=40） |
| 配置 | `common/xcat_timed_keys.*` → `user.ini [timed_keys]` | **同形移植**（结构体 / CAS / 默认槽） |
| Tick | `service_thread` + `PayloadTimedKeys_Poll` | 独立 worker（对齐 `autopot`/`pet_feed`）+ `payload_timed_keys` 轮询 |
| 门控 | `IsClientPlayPathLanded` + `auto_lie` busy | **`ports::world::IsPlayReady` + vitals**；测谎/符文首版可空实现 |
| 反宏 | 游戏侧不同 | 经典版有 `KeyMacroAnalyzer`+RawInput — **更忌假键鼠** |
| UI | `DrawNativeTimedKeysTab` 真读写 | 本仓 `DrawTimedKeysTab` 仍是 static 占位 → 改为真读写 |

## 2. 职责边界

### 做

- 7 槽：键标签固定、`enabled` + `intervalSec(1…3600)`；勾选即启、全关即关（`masterEnabled` 派生）
- `user.ini [timed_keys]` 落盘；payload 按 `writeTickMs` 轮询热更新（**不用 SHM 命令位**，对齐对照仓注释）
- 启用边沿立刻入队一次，之后按槽自身 `intervalMs ± 0.5s` 抖动重复
- 多槽同时到期时约 **150ms** 串行出队（不摊薄各槽间隔）
- 发键失败指数退避；连败 ≥8 → halt + CAS 回写取消勾选
- 进图落地门控；输入框聚焦时跳过（`InputManager.IsFocusedInputField`）
- 日志 `logs/x.log` 或独立 `timedkeys.log`（标签 `TimedKeys`）

### 不做（非目标 · 首版）

- 自定义改键（槽位 VK 可在结构体留字段，UI 首版不开放）
- BUFF 管理器 / 技能多发（另 Tab）
- `SendInput` / PostMessage 假键作主路径
- 与 `simple_combat` 抢出刀（战斗出招另走攻击 API；定时键只点快捷栏）
- 枫星 `auto_lie` / `auto_rune` busy 同步（经典版无对等时，接口留空 no-op）
- 改 GA `.text` / inline hook 伪造输入设备

## 3. 经典版发键锚点（Phase 0 已采证）

真源：CMS 明文 `Dumps/cms_cw/dump.cs`（语义）+ TW 哈希 `Dumps/runtime/out/dump.cs`（RVA）+ `DumpRestoredData` 令牌 + IDB `GameAssembly.dll.i64`（imagebase `0x7FFB16B40000`）。  
**CMS RVA ≠ TW**；下面只列 **TW**。

### 3.1 现行：`unity_kbd` via `InjectKeyHold`

真源与拟人走路 / 超级赶路 StickUp 相同：[`unity_kbd_port`](../../x/features/ports/unity_kbd_port.h) 往 InputSystem Keyboard 灌 `KeyboardState` 事件。

| 步骤 | 说明 |
|------|------|
| VK→Key | `input::VkToUnityKey` |
| 脉冲 | worker：`SetKeyHeldOnMain(true)` + `Repush` 循环 → Sleep → `SetKeyHeldOnMain(false)`（对齐 travel `CallUpKey`） |
| 守位 | PreProcessEvent 钩子按 **gMask 全位** 补回（含技能键，不限箭头） |
| 禁止 | 主线程里再 `InjectKeyHold`（嵌套 `InvokeAndWait` → KEY_FAIL / 卡游戏）；禁止 `SendInput` |

Unity `Key`（配置层仍存 Win32 VK）：

| 槽标签 | Win32 VK（默认） | Unity `Key` |
|--------|------------------|-------------|
| 7 | `'7'` | `Digit7 = 47` |
| 8 | `'8'` | `Digit8 = 48` |
| 9 | `'9'` | `Digit9 = 49` |
| 0 | `'0'` | `Digit0 = 50` |
| - | `VK_OEM_MINUS` | `Minus = 13` |
| = | `VK_OEM_PLUS` | `Equals = 14` |
| Z | `'Z'` | `Z = 40` |

持有 **180±60ms**（对齐对照仓 `HoldMsForSlot`）；时长 Sleep 在 **worker**，主线程只做状态入队。

### 3.2 备选：直接走快捷映射

| 符号 | TW | 说明 |
|------|-----|------|
| `FuncKeyMappedManager` | — | Singleton |
| `GetDataByKeyCode(Key)` | 与 attack 同源钉值 | VK/Key → `FuncKey{Type,Value}` |
| `OnFuncKey` / `UseFuncKeyMapped` | — | 若 unity_kbd 对某技能键 BIN 无效再评估 |

**选型**：现行 unity_kbd；BIN 失败再开 `OnFuncKey` 任务。

### 3.3 反宏约束（设计硬条件）

见 [`../security/MscSecurity能力面.md`](../security/MscSecurity能力面.md)：

- `KeyMacroAnalyzer` 吃 **RawInput**；`SendInput` / 异句柄 → 高风险
- 进程内 unity_kbd **不经** RawInput → 为首选
- 仍需：间隔抖动、串行出队，降低模式匹配误杀

## 4. 配置契约（对齐对照仓）

落盘：`bin/XCat_data/state/user.ini` 段 `[timed_keys]`。  
实现：`common/xcat_timed_keys.{h,cpp}`（可几乎原样移植对照仓；本仓已有 `xcat_config_ini`）。

```ini
[timed_keys]
version=1
writeTickMs=...
masterEnabled=0|1
slot.1.vk=55          ; '7'
slot.1.enabled=0|1
slot.1.intervalMs=60000
; … slot.7 …
```

| 常量 | 值 |
|------|-----|
| `kTimedKeySlotCount` | 7 |
| 间隔 | 1…3600 秒（UI 秒；盘上 `intervalMs`） |
| 默认间隔 | 7/8/9/0 → 60s；-/= → 420s；Z → 1s（与对照仓一致，可改） |
| Magic | `'XCTT'` / version 1（若保留 bin 兼容；MVP 可只写 ini） |

CAS：`WriteTimedKeysCas(expectedTick)` — halt 回写与 UI 保存冲突时重试，避免盖掉用户改的间隔。

**刻意不用** Maplecat 式 SHM `kCmdSetTimedKeys*`，避免与载荷主循环竞态（对照仓注释原文意图保留）。

## 5. 运行时状态机（对齐对照仓 Tick）

```text
ApplyConfig(cfg)
  → 槽启用上升沿 / master 上升沿：Enqueue(slot, "enable")
  → 禁用 / 换 VK：出队 + ForceRelease

Tick(now)
  → TickReleases（到期 KeyUp）
  → !landed → 清落地边沿；return
  → 输入框聚焦 / 模态 → skip fire（仍 FlushPersist）
  → 到期槽 RR 入队；Dequeue（受 g_nextFireAt 150ms 间隔）
  → Fire：worker unity_kbd Down/hold/Up（InjectKeyHold）
  → 失败：槽级指数退避；≥8 → halt + persistNeeded
  → FlushPersistNeeded（CAS 关勾选）
```

关键常量（移植）：

| 名 | 值 | 含义 |
|----|-----|------|
| `kQueueSpacingMs` | 150 | 同拍多键串行 |
| `kJitterMs` | ±500 | 间隔抖动 |
| `kRetryDelayMs`…`kRetryBackoffCapMs` | 500…8000 | 失败退避 |
| `kMaxConsecutiveFails` | 8 | 熔断 |
| Hold | 180±60 ms | Down→Up |

Worker：独立线程 ~50–100ms 醒一次（对齐 `autopot`）；**发键与 KeyUp 必须进主线程泵**。

## 9. 关键风险与缓释

| 风险 | 缓释 |
|------|------|
| CMS/TW RVA 漂移 | 只信 TW dump + 方法序；运行时丢绑节流 |
| CFF 壳直调 | 与 autopot 同：入口可调；探针验副作用 |
| 反宏模式匹配 | 禁 SendInput；抖动 + 串行；间隔勿亚秒连打（Z 默认 1s 已偏激进，实机可调大） |
| 主线程外调 Il2Cpp | 一律主线程泵 |
| UI / halt 写盘竞态 | `writeTick` CAS + UI 认盘上 disabled |
| 聊天框误触技能 | `IsFocusedInputField` 门控 |
| 与 simple_combat 冲突 | 发键前 `AcquireExternalPause`（轻暂停：松 A、保留 lock/FSM，不 `GoIdle`）；绝对闸仍归 auto_lie/encounter |
