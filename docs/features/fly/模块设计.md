## 1. 产品链路（现行唯一）

```text
面板「飞行」/ F6
  → SetArmed(true)
  → fly_fh_ban::SetArmedBan(true)   // CollisionDetect / Float 拦截 LocalUser，清 CurFh
  → （不旁路 ApplyImpact）

worker（Sleep 8ms）
  → 跟随：客户区光标动了 → 一次主线程 job：
        ScreenToWorldPoint + ImpactImpulseToward(world)
  → 左键边沿：ScreenToWorld → HopTo → ImpactImpulseToward
  → ImpactRoute：flyMode 0=NockBack / 1=SetImpactNext（面板调试 TAB）

引擎
  → impactNext{Valid,Vx,Vy}
  → WorkUpdateActive → ApplyImpact
  → Ap.V 更新 + MoveElem Attr=2（BIN：a=2! / tel>0）
```

| 项 | 现行 |
|----|------|
| 驱动 | **Impact only** |
| Attr | **`a=2`** |
| 穿层 | **fh-ban**（武装期不重挂台） |
| 无敌 | hop **要求** `invuln::IsEnabled()`（不偷偷 SetDesired） |
| hop CD | 默认 **120ms**，下限 **40ms**，上限 2000；面板可调 |
| worker | `Sleep(8)`；`IsCongested()` 时跳过跟飞 |
| 跟飞主线程 | STW+Impact **合并单 job**（防双 `InvokeAndWait` 卡帧） |

## 2. 交互

1. **面板「飞行」** 或 **F6** → 武装 / 卸武装（`state/fly_armed` 会话态，不持久化）
2. **跟随**：armed + 前台 + 无 Ctrl/Shift + CD 到 → 跟鼠标 Impact；客户区像素 ≥3px 才新 STW；静止约 200ms 软重钉上次世界点（`Bh`）
3. **左键**：armed + 前台 + 无 Ctrl/Shift + LMB 边沿 → 一跳 Impact
4. 换图 / 重新 PlayReady：清跟踪，立刻允许首跳
5. 卸武装：`fh-ban` OFF；清跟随跟踪

IPC：`PayloadControl_PublishFly` / `core.flyMode` / `core.flyHopCdMs`

## 5. 与 F5 打怪的关系

- F6 = 鼠标世界点 **开环**跟飞：`ImpactImpulseToward`（只按位置误差算速度）+ `BanSource::Fly` fh-ban。
  能这么用是因为光标目标点固定，重力把人拉下来后误差方向天然朝上，200ms 重钉一次即可悬停。
- F5 Impact 贴怪 = **闭环旋翼**：`QueryFlightState` 读速度 → 横向 P 控 / 纵向意图速度 + 重力前馈
  → `ImpactSetVelocity`（绕开 `ImpactImpulseToward` 每轴 80 的速度地板）+ `BanSource::CombatImpact`
  fh-ban，空中出刀。实测物理（`+Y 向上`、重力每 30ms 步 `-60`、Y 是叠加语义、上升**无**引擎封顶）
  详见 [`../simple_combat/模块设计.md`](../simple_combat/模块设计.md) §4.0，动竖直律前必读。
  ⚠️ 曾写在这里的「合速钳在 `[-670,+110]`」是错的，已撤回——那是旋翼自己的限幅，不是引擎特性。
- 两源 **OR**，互不踩灭；API `fly_fh_ban::SetSourceArmed`。
- **别把 F6 那套开环搬去打怪**：目标是会动的怪、且出刀期间不能停推，开环点射必掉图。
  详见 [`../simple_combat/模块设计.md`](../simple_combat/模块设计.md) §4.0。

## 6. BIN 验收清单

1. `init drive=impact`；武装：`drive=impact … fhBan=1`（无 `applyBypass`）
2. 跟飞：`impact toward` + `follow hold drive=impact_setnext`（或 nockback）
3. MpFlush 空中包：`a=2!` / `tel>0`；关注 `maxErr` / `over` / 软踢时刻
4. 过低 CD（&lt;40）面板会夹到 40；跟飞中不应刷 `follow drive pump timeout`
5. 卸 F6 后不应再打 Impact toward
