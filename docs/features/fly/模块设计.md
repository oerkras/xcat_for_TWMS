## v1.7.0 · 速度积分器（踢人根因修复）

### 根因
v1.6.4 以前，飞行位置直接由鼠标位移写入，速度再由 `mouseDelta / dt` **反推**。
结果上报的 MoveElem **自相矛盾**——`movepath_flush.log` FLUSH#38 实录：

| Elem | xy | v | el | 按 v 推 Δ | 实际 Δ |
|---|---|---|---|---|---|
| E0 | (2221,-175) | (0,**-120**) | 30 | Y −3.6 | Y **+6** |
| E1 | (2233,-169) | (**124**,-11) | 90 | X +11.2 | X **+5** |

420ms 内 Vy 正负翻 6 次。服端只要做 `Δpos ≈ v·Δt` 距离校验必判非法。

四个具体成因：

| # | 成因 | 修复 |
|---|---|---|
| 1 | 速度 = 每帧鼠标原始抖动 / dt | 加速度限幅追踪器（`kFlyAccelX/Y`） |
| 2 | 静止时假报 `vy=-60`，位置却冻结 | 删除；滑翔下沉 `FLY_SINK`（**默认 25**；0=悬停易踢，55=更沉） |
| — | 位移偏慢 | 默认 `FLY_SPEED=0.70`；飞天水平速帽 `kFlyVelMaxX=160`（走路基线仍 125） |
| 3 | `AbsPos-last` 写成与 `AbsPos` 相同 | 写上一帧位置 |
| 4 | 上行钳位 670 > 基线跳跃峰值 555 | 拆成 `+555 / −670`；转向需求另收窄到 `+260 / −420` |
| 5 | 固定 `1/60` 积分，worker 用 `Sleep` 实际会漂 | `QueryPerformanceCounter` 实测 dt |

### 模型
鼠标拖的是**目标点**，不是身体：

```
target += mouseDelta;  target -= sink*dt;  target 受 leash 约束
wantV   = clamp((target - pos) * gain, 包络)
vel    += clamp(wantV - vel, ±accel*dt)
pos    += vel * dt          ← 位置由速度积出
```

`Δpos == v·dt` 由构造成立，不再依赖巧合。空中 Vy 另有 `±10` 下限，避免转向过零时出现基线从未有过的「空中静止」采样。

### 验证
`Dumps/runtime/fly_integrator_check.cpp` 离线重放同一套数学，7 个工况（含 dt 抖动、剧烈鼠标抖动）断言：
`Δpos 与 v·dt 偏差 ≤ 6e-5`、速度跳变不超加速度限幅、速度不出基线包络、空中无 `Vy==0` 采样。全部通过。
