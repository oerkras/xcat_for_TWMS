# fly Feature 模块设计（Classic TWMS）

> **状态**：模式 A 点击飞 / B 跟随飞  
> **产品**：新枫之谷：经典版（TW）· **不是**枫星  
> **源码**：`x/features/fly/`  
> **依赖**：`teleport_port::TeleportNativeSkillCall(..., snapStand=false)`

---

## 1. 目标

| 模式 | 面板文案 | 交互 | 位移手段 |
|------|----------|------|----------|
| **A** (`flyMode=0`) | 点击飞 | 武装后左键边沿 → 一跳 | fill+Doing hop |
| **B** (`flyMode=1`) | 跟随飞 | 武装后按自冷却跟鼠标连跳 | fill+Doing hop |

---

## 2. 行为

1. **面板「飞行」勾选** 或 **F6** 切换武装（`state/fly_armed` 会话态，不持久化）
2. **A**：armed + 前台 + 无 Ctrl/Shift + LMB 边沿 → hop
3. **B**：armed + 前台 + 无 Ctrl/Shift + CD 到 → hop；**客户区像素**判鼠标是否移动（≥3px 才 STW 新跳）；静止时不每拍 hover，约 200ms 软重钉上次落点保滞空（勿用世界坐标死区——相机跟随后会误钉旧点抖动）。换图 / 重新 PlayReady 时清跟踪并 `ClearNativeSelfCd`，立刻开闸首跳。
4. `SetNativeCooldownMs(flyHopCdMs)` + `TeleportNativeSkillCall`（默认 16ms，下限 5ms）
5. 屏→世界：`Camera.get_main` + `Transform.get_position` + **`ScreenToWorldPoint(Vector3)` 三参**（RVA `0x4DDD5F0`，内硬编码 `eye=Mono=2`）  
   勿绑四参版 `0x4DDD340` 且勿把 Mono 当成 0（Left）。

IPC：`state/fly_armed` / `core.flyMode`（固定跟随）/ `core.flyHopCdMs`

---

## 3. BIN 验收

1. `camera bind ok ScreenToWorld@0x4DDD5F0`
2. 跟随飞 → `hop ok tag=B to=(千级地图坐标)`，对齐 2026-08-02 更新前（如 `1458,640`）
3. 不应再 `to=(-0,0)` / `hover hold to=(-0,0)`
