## 0. 测什么

近战普攻官方 `maxCount=1`，一刀仍一只。P2 只把 FindHit 的 `Rect` 换成当前图 foothold AABB。

「全图」在这一刀上的含义：名单仍最多 1 只，但这只可以来自全图盒，不再被武器 80×67 近距盒挡住。

不抬 `maxCount`。服端拒伤或踢号 → 结案不可做，禁止回退造包。

## 1. 改了什么

`map_attack_port` 的 `BeforeFindHit`：`QueryPlayBounds` → `x=left, y=top(minY), w=right-left, h=bottom-top` 写入入参 Rect。失败则不改（`why=no_aabb` / `bad_aabb` / `write_fail`）。

`AfterFindHit` 打 `tag=MapAtk`：`exp` / `why` / `mc` / `n` / 新盒 / 旧盒 / `oid0` / `dx,dy`（相对角色 AbsPos）。

`simple_combat` Firing / `attack_rpc` Encode：**零 diff**。

## 2. BIN 清单（本机勾实验 TAB「全图攻击（P2 扩盒）」+ F5）

对 `bin/XCat_data/logs/x.jsonl` 搜 `MapAtk`：

| 看 | 过 |
|---|---|
| `exp=1 why=aabb` | 盒写进去了 |
| `xywh` 的 w/h 远大于 P1 的 64–80 × 14–67 | 真的是地图尺度 |
| `mc=1` 且 `n` 仍 ≤1 | 没偷偷抬 maxCount |
| `oid0` 的 `|dx|` 或 `|dy|` 明显大于武器盒 | 走开身边怪再打；FindHit 可能仍先扫到近的 |
| 该 oid 对应怪 hp 下降（combat.log / 血条） | 服端认远距近战 |
| 无踢号 / KickSniff 与开本项同时 | 否则结案 |

`exp=0`：AABB 没就绪，本刀等于没扩。换图后等 foothold 缓存再打。

## 3. 思考框架外

扩盒 ≠ 秒图。`mc=1` 时 FindHit 仍只停在第一只盒内怪（池顺序未知，CFF）。身边有怪时 `dx` 可能一直很小——那不是「扩盒没生效」，是扫描先碰到近的。先清近或走开，再谈服端范围核。
