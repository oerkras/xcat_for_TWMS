## 0. 结论先行

1. 自组发 **opcode 50**。A 空/普攻：`skillId=0`。A 槽近战攻击技（表内 `attackCount≥1`，如劈空斬/迴旋斬）：填 `skillId`，伤害段按 `attackCount` 重复。弓/弩/拳套/枪（51）、杖（52）、双飞斩、BUFF **拒组**。  
2. **不能**全武器套短刀包。短刀头是 `WAS + 恒 05`（BIN `03 05`）；单手 WAS=5 套同一条会变成 `05 05`，服端当双手剑 AttackType 空挥。  
3. 官方 `TryDoingMeleeAttack`（RVA `0x105AE40`）头两字节永远是 **`UserLocal+0x158`（AttackType）+ GetAttackSpeedDegree**。短刀自组与官方序相反，但能伤，**保持例外**。  
4. 地面环按兵器长短分：短兵器写**人脚下**（落物，短刀 BIN）；长兵器写**怪坐标**（双手剑 `send.log`）。**飞行怪**用 `MobData.MoveAbility` 识别（3=Fly / 4=FlyRandom），环改成官方两点：当前 `Pos@0x64` + `PosPrev@0x6C`。地面短刀头仍是 `WAS+05`（勿改）；**飞行短刀头走官方 AttackType+degree**（蝙蝠 BIN `04 05` 空刀）。双手剑仍 `05 06`。  
5. 本地 `SetAttackAction` 可用 spd=3 看起来快；**线上第二字节必须写真 degree**。双手剑写成 3 → BIN 100→99 磨血；`05 06` + Delay `C2 01` 才是 100→60。

## 3b. 地面 vs 飞行（组包策略）

| | 地面（Walk/Jump/Stop） | 飞行（Fly / FlyRandom） |
|---|---|---|
| 识别 | `MoveAbility` 不是 3/4 | `MobData+0x2C` = 3 或 4 |
| 短兵器环 | 人脚下，两枚同点 | **不要脚下**；`Pos` + `PosPrev` |
| 长兵器环 | 怪当前坐标，两枚同点 | 同上：`Pos` + `PosPrev` |
| 头 / 动作 / Delay / FA | 按武器族。短刀 `WAS+05` | 动作/Delay/FA 同族；**短刀头改官方 AT+degree**（WAS=4 → `01 04`） |

## 4. 已证伪（不要再争）

| 说法 | 事实 |
|---|---|
| 双手剑自组没发出去 | 有 `op=50`；服端不认伤 |
| 双手剑慢是发包间隔 | 间隔与短刀同量级；慢在 WAS=6 认伤次数。谎报 `05 03` → 磨血 |
| 短刀头组错了 | 短刀 `03 05` 能连杀，勿改 |
| 单手也可以套短刀头 | WAS=5 → `05 05` 空挥 |
| 飞行空刀只因为写了脚下 | 脚下会空；改成怪坐标两枚同点仍空。飞行必须第二点 PosPrev；地面两枚同点够用 |

`+0x158` 是 AttackType，不是攻速。短刀 BIN `atkType=1`、`WAS=3`。误把 0x158 当攻速：短刀能伤、双手剑空枪。

## 5. 日志怎么验

`AttackRpc`：

```text
melee encode fam=… wt=… atkType=… rawAt=… ring=feet|mob|fly delay=… fa=0x…
forge BODY … hdr=XX YY … fly=0|1 ring=… prev=(x,y) hex=…
```

`combat.log`：`forge_hit ok … wt=… hp=`

| 武器 | 应看到 |
|---|---|
| 短刀 | `fam=dagger hdr=03 05 ring=feet`，hp 连掉 |
| 单手剑 | `fam=1h hdr=01 04`（新手剑 WAS=4）或 `01 05`（WAS=5），**不要** `05 05` / `04 05` |
| 双手剑地面 | `fam=2h hdr=05 06 ring=mob`，Delay `C2 01`，hp 大跳不是 100→99 |
| 飞行短刀 | `fly=1 ring=fly hdr=01 04`（本机 WAS=4），**不要**再出现 `04 05`；hp 应掉 |

`forge_hit fail … (no OnFuncKey)` 是故意的：过远 / 非近战 / SendOut false 停刀，不走正路。
