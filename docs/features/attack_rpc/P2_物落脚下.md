## 0. 结论先行

1. **掉落生成点跟攻包命中环的 wire XY，不跟客户端 `Drop.Pt1` 本地改写。** 改 `Pt1`/`PickPt` 只改观感，CRC / 服端拾取点仍按进包。  
2. 官方 `OutPacket.EncodeVector2` **会把 Unity AbsPos 的 Y 翻成枫谷 Y-down 再写成 i16**。探针若 `Encode2S` 直写 AbsPos Y，线上符号反了。  
3. 探针曾把 AbsPos「瞄准禁止反号」套到 wire 上 → 服端把负 Y 当 Maple → 掉落画在人物头顶（约 `|2·Ap.y|`）。  
4. **物落脚下（短兵器）**：命中环两枚 XY 写**角色脚下 AbsPos**，`Encode2S` 做与官方相同的 `i16(x), i16(-y)`；`oid` 仍是怪；包尾玩家 XY 同样翻 Y。选怪距离继续用 AbsPos hypot。  
   **长兵器（双手剑/斧/钝/枪矛）**写怪坐标，见 [`P3_近战武器族组包.md`](P3_近战武器族组包.md)。飞行怪第二点写 `PosPrev@0x6C`（`MoveAbility` 3/4），不要跟地面同一套环。

## 1. 两套坐标（禁止混用）

| 空间 | 字段 | Y 增大 | 用途 |
|---|---|---|---|
| **AbsPos / ActorPos / `Pos@0x64`** | `VecCtrl.Ap`、Mob `Pos` | **更高**（Unity Y-up） | 瞄准、贴门、贴脸距离、命中环的**源** |
| **Maple / Drop.Pt1 / 攻包 wire** | `Drop.Pt1`、`PickPt`、op=50 的 i16 Y | **更低**（枫谷 Y-down） | 拾取门控、**线上 XY** |

拾取侧已钉：`ApToMaplePos` → `x=ax; y=-ay`（`drop_pool_port.cpp`）。  
攻包侧官方等价变换发生在 **`EncodeVector2` 内部**，不是调用方先翻。

> **AbsPos 铁律只约束瞄准加减。** 禁止把它理解成「攻包 Encode 也绝不能翻 Y」。

## 2. IDA：`EncodeVector2` 翻 Y

| 项 | 本轮（2026-08-15） | P0c 旧 dump（2026-08-03） |
|---|---|---|
| imagebase | `0x7FFD72820000` | `0x7FFB74A20000` |
| `EncodeVector2` RVA | **`0x1CF99D0`** | `0x1CC5090` |
| VA | **`0x7FFD745199D0`** | （按当时 base 换算） |

函数序言（与混淆种子无关；`0x80000000` 是立即数）：

```text
movd xmm7, edx              ; X 原样（Vector2 低 32 位 float）
shr  rdx, 20h
add  edx, 80000000h         ; Y：IEEE 符号位翻转 ≡ y = -y
movd xmm6, edx
cvtss2sd / cvttsd2si        ; trunc → i16
BlockCopy 2B + 2B           ; 线上每分量 2 字节
```

同文件孪生编码器 `sub_7FFD74519AD0`（`add edx,80000000h` @ `0x7FFD74519AEA`）Y 翻转相同。全映像该立即数加法共 10 处，攻包路径以本函数为准。

P0c「`BitConverter.GetBytes`×2 + `BlockCopy`」只描述了宽度；**漏了符号翻转**。宽度仍是 i16，探针 `Encode2S` 在补上 `-Y` 之后才与官方 wire 等价。

## 3. IDA：近战谁把什么喂给 EncodeVector2

近战大函数 `sub_7FFD7387AE40`（RVA `0x105AE40`，本 IDB）内：

| VA | 源 | 语义 |
|---|---|---|
| `0x7FFD7388D3CD` | 对象 getter `vtable+0x1E8` 返回 `Vector2` | 命中环第一点（怪位，Unity） |
| `0x7FFD7388D401` | `qword [Mob+0x6C]` | 第二点 PosPrev（Unity 两 float 打包） |
| `0x7FFD7388D64E` | `[actor+0x50]` VecCtrl → getter `0x7FFD739B7A60` | **玩家 AbsPos**（包尾） |

射击 `sub_7FFD73890390`（RVA `0x1070390`，P1 注释的 `TryDoingShootAttack`）同样 4 次 `EncodeVector2`，前两刀同源（getter + `+0x6C`）。

wire 上单怪命中是 **两枚命中 XY + 一枚玩家 XY**（off=55）；函数里多出来的调用在分支上，不以静态 count 当包长。

## 5. 「掉落在人物上方」机制

探针贴脸能结算（BIN：`dist≈2–23` 有掉落；`90+` 空枪）。命中环若写 AbsPos Y（负）且 **不经 EncodeVector2**：

| 步骤 | 值（蜗牛量级） |
|---|---|
| 角色 `Ap.y` | -365（Unity，贴地） |
| 错误 wire Y | -365（被服端当 Maple） |
| Maple 高空 | y=-365 在 Y-down 里是「很高」 |
| 客户端再 `worldY=-Pt1.Y` | Unity +365 |
| 与角色的视觉差 | ≈ **730px 在头顶** |

贴脸时「从怪头顶抛下」的几十字抛物线是另一回事；**半空不落地 / 整堆在脑门以上几百像素** 走的是本条 Y 空间错误。

「手边 ±28px、Y 跟 Ap 同层禁止反号」只挪了 X，Y 仍错，不能当物落脚下验收。

## 6. 实现（探针）

代码：`x/features/ports/attack_rpc_port.cpp` · `FireJobOnMain` 的 `encXY`。

```text
源：QueryCombatCtx = ReadActorPos = VecCtrl.Ap（AbsPos）
命中环：oid = 怪；XY = 角色脚下 AbsPos（kDropFootReachX=0）
encXY(fx, fy)：Encode2S(i16(fx), i16(-fy))     ← 等价 EncodeVector2
包尾玩家 XY：同一 encXY(ctx.x, ctx.y)
选怪：hypot(mob.Pos - ctx) 仍 AbsPos；kMeleeMaxDist=50
```

日志：`dropAimAp=(x,y) wireY=N`。`wireY` 应接近真包正 Y（`C6 00` / `6D 01` 一类），不应再跟 `Ap.y` 同号。
