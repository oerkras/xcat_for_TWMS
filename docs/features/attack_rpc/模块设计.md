## 0. 一句话

研究「不走 `OnFuncKey` 完整出刀」时如何让客户端仍发出 50–53 攻包；**已否决**「直调 CMS `OnMeleeAttack`」——那是 **`UserRemote` 收包路径**。  
**P0b 已钉**：`OutPacket.Create` → `Encode*` → `Session.SendPacket`。  
**P0c + 实机修正**：头/命中环以 **现网 `send.log` op=50** 为准（见 P0c §实机修正）；`tOrKey` = `WorldManager.GetUpdateTime`。  
**P2**：`EncodeVector2` 内部翻 Y；短兵器环写角色脚下才可能物落脚下（见 [`P2_物落脚下.md`](P2_物落脚下.md)）。  
**P3**：近战按武器族填头/动作/环/Delay；短刀 `03 05` 与双手剑 `05 06` 不得混套（见 [`P3_近战武器族组包.md`](P3_近战武器族组包.md)）。
