# travel Feature 模块设计（Classic TWMS）

> **状态**：✅ 同盘 seed BFS 赶路 + 瞬移贴门进门（世界地图 Spot 入口）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **源码**：`x/features/travel/` · `x/features/ports/travel_port.*` · `x/features/worldmap_marker_travel/`  
> **依赖**：`teleport_port::TeleportNativeSkillCall(snapStand=true)` · `foothold_path::SnapStandAt` · `world_port` 场景门 · `invuln` 赶路 Hold  
> **对照枫星**：假火软确认 / 唯一桥 / 按门名重解 / PlayReady 闸——**仅模式对照**；偏移与进门以经典版为准  
> **明确非目标**：码头自动化、跨板块自动爬图、港口换乘脚本

---

## 0. 一句话

世界地图 Spot 双击 → 同盘 BFS 求路径 → 每跳 **官方瞬移贴门** + CheckMove/↑ 进门；卸图期间禁止再 Doing。

## 2. 产品路径（进门）

默认 `FireMode::DirectEnter`（可切 `TeleportStick`）：

```
FirePortalByName(name)
  → StickThenEnterReady(门 x,y)
       → TeleportToPortal → SnapStandAt → TeleportNativeSkillCall(sx,sy,fh, snapStand=true)
       → WaitStoodNearStand（几何贴台）
       → 成功后已卸图 → MAP_TRANSITION / MAP_CHANGED，禁止再 CheckMove
       → 仍稳图未站稳 → 重贴一次；仍失败 → NOT_STOOD
  → 仍 PlayReady → 主线程 CheckMovePortal（DirectEnter）或 ↑（TeleportStick）
```

调试旁路（非产品默认）：`Up` / `CheckMove`（AbsPos 硬钉）/ `Rpc`。

枚举：优先 PortalManager；空则回退 `MapData.Portals@0x40`。

## 2.1 贴门钉台实现（`travel_port`）

源码：`StickThenEnterReady` / `TeleportToPortal` / `WaitStoodNearStand`（`x/features/ports/travel_port.cpp`）。

### 落点策略（产品定案）

与 **战斗贴怪同一条原生链**：先由 `PortalRect`/`HImpact` 得触发区，瞄准点夹进区内，再
`foothold_path::SnapStandAt(aim → stand,fh)`（Snap 出台则 X 夹回区内），再

`teleport::TeleportNativeSkillCall(standX, standY, fh, /*snapStand=*/true)`。

| 约束 | 行为 |
|------|------|
| 触发区 | `MapPortalData.PortalRect`（hash→offset 防漂移）；空则 `±HImpact/VImpact` 兜底 |
| Snap 失败或 `fh==0` | 直接 `FH0_FORBID`，**禁止** fill+Doing |
| Snap 出台 | clamp X 进 rect；必要时以 `(clampedX, portal.y)` 重 Snap |
| `snapStand=true` | 种 CurFh / 钉台（日志应见 `fh=<非0> snap=1`） |
| 赶路自冷 | 贴门前 `SetNativeCooldownMs(80)`（不永久改战斗冷却） |
| 补给 ForceNative 冷却未尽 | `TELEPORT_COOLDOWN`，本跳暂不贴门 |
| 边界闸（`teleport_port`） | 已种 `fh≠0` → **margin=0**；BIN 14:12：门在 FH AABB 底边 `land.y==B` 时，24px 内缩会误杀 → `TELEPORT_FAIL` |

### 站稳判定（几何，不依赖 PeekCurFh）

瞬移后 `Sleep(kTeleportSettleMs)`，再轮询 Ap 是否贴近 **snap 台面**（非门原始坐标）：

| 常量 | 值 | 用途 |
|------|-----|------|
| `kTeleportSettleMs` | 80 | Doing 后短暂落定 |
| `kStandWaitMaxMs` | 400 | 站稳等待上限 |
| `kStandPollMs` | 40 | 轮询间隔 |
| `kStandYTol` | 12 | `|Ap.y − standY|` |
| `kStickNearR` | 72 | 平面距离（含 X） |

- 几何 OK → 视为站稳（`PeekCurFhId` 卸图后常为 0，**不当唯一条件**）
- 等待中卸图 / 非 PlayReady → `MAP_TRANSITION`（真换图，成功）
- 超时仍未贴台 → `NOT_STOOD`；`StickThenEnterReady` **至多重贴一次**；卸图中禁止 re-stick（BIN：re-Doing 撞死 LU）

### 否决方案：悬空落点「自然落下」

曾试：`landY = standY − 10`、`fh=0`、`snapStand=false`，指望角色落到台面再进门。

| BIN | 现象 | 结论 |
|-----|------|------|
| 07:26 | `land=(1907,-375) fh=0 snap=0` → `ap` 从 -375 **穿台**到 -805；`NOT_STOOD` 循环 re-stick | 悬空 + 不种台 = 穿台直坠 |
| 07:16 | 仅看 `PeekCurFh` 站稳：贴后 `curFh` 长期 0 → 永远 NOT_STOOD | CurFh 不可作唯一站稳条件 |
| 07:38 | 钉台恢复后：`land=(1907,-365) fh=58 snap=1`；同盘往返 `50001↔60001` 两趟均 `arrived`，无 re-stick | **定案验收** |

> 贴门必须 Snap + `snapStand=true`；`fly` 点飞的 `fh=0 snap=0` 语义**不得**搬到赶路贴门。

### 与 Goto 的衔接

- `NOT_STOOD` ∈ `IsTransientFireFail` → 本跳可短暂重试，不立刻假火熔断
- `FH0_FORBID` **不**进 transient；走假火软确认 / 重规划路径
- `MAP_TRANSITION` / `MAP_CHANGED`：`FirePortal` 返回 true，**跳过** CheckMove

## 3. Goto 状态机要点

1. **解析目标**：`map_names` 解析；无当前图 → `pending goto` 等 `CurrentMapKey`
2. **BFS**：`Graph::PathTo(src,dst)`；空则 revive DEAD 再试；仍空 → `Unreachable` + 通知
3. **开火**：解析 live 门名 → `FirePortalByName`（**放 `gMu`**）→ 记 `gExpectMap` / pending
4. **换图确认**：离开 `gPendingFrom` → `OnMapEnterConfirmed`（实测写边）
5. **到站**：仅 `cur == gTarget`；跳数用尽未到 → `ReplanOrStop`（禁止假 arrived）
6. **假火**：超时未换图 → soft 重试 → fuse 停（`FakeFireStop`）；唯一桥不标死、可 late-wait
7. **Shutdown / SetIdle**：清状态 + `ReleaseInvulnForTravel`；`++gFireEpoch`

### 3.1 时序护栏

| 常量 | 约值 | 用途 |
|------|------|------|
| `kHopWaitMs` | 1200 | 普跳等换图 |
| `kHopWaitUniqueBridgeMs` | 1500 | 唯一桥等换图 |
| `kMidHopSettleMs` | 700 | 换图后稳图再开火 |
| 瞬移自冷（赶路） | 80ms | `SetNativeCooldownMs`；战斗侧各自再 Set |

硬门禁：

- `!IsInMapScene \|\| !IsPlayReady` → 禁止瞬移 / 禁止开火；midhop settle 时钟后推
- `SnapStandAt` 失败或 `fh==0` → `FH0_FORBID`（禁止 fill+Doing）
- 卸图中禁止 re-stick（BIN：re-stick Doing 撞死 LU）

### 3.2 开火放锁与 epoch

`FirePortalByName` 内含 Sleep/瞬移，**禁止持 `gMu`**（否则 `QuerySnapshot` / Stop 卡死）。

```
fireEpoch = gFireEpoch
unlock → FirePortalByName → lock
若 mode≠Goto 或 epoch≠gFireEpoch → 丢弃提交（仅打 log）
```

`SetIdle` / 新 `StartGotoResolved` 递增 `gFireEpoch`。

### 3.3 瞬移结果语义（诚实）

| 结果 | 含义 |
|------|------|
| `FH0_FORBID` / `TELEPORT_FAIL` / `NOT_PLAY_READY` / `TELEPORT_COOLDOWN` / … | **失败**，不得冒充换图成功 |
| `NOT_STOOD` | 钉台后几何未贴台（已重贴仍失败）；**瞬态**，可重试本跳 |
| `MAP_TRANSITION` | 瞬移**已成功**且随后卸图 → `FirePortal` 返回 true，跳过 CheckMove |
| `MAP_CHANGED` | 贴门后 `CurrentMapKey` 已变 |
| `STUCK` / `OK` | 仍在稳图，可继续进门触发 |

`IsTransientFireFail`：`TELEPORT_FAIL`、`NOT_PLAY_READY`、`TELEPORT_COOLDOWN`、`NOT_STOOD`、`MAIN_TIMEOUT`…  
`FH0_FORBID` → 假火软确认路径；**不**当无限 transient 空转。

## 4. 世界地图入口

详见 **[`../worldmap_marker_travel/模块设计.md`](../worldmap_marker_travel/模块设计.md)**（锚点 / 字段偏移 / BIN）。

摘要：

1. Spot 双击 → 优先 mapId；否则名/简介经 `map_names` 反查（禁止把简介原文当 goto）
2. **`PathHopCount(cur, dst)` 预检**
   - 不可达 / 坏目标 / 已在目标 → 游戏内 `UIUtilDialog.Notice`（RVA `0x749420`），不弹赶路确认
   - 可达 → YesNo（RVA `0x7454B0`），文案含「预计 N 跳」
3. 确认 → `travel::RequestGoto`

launcher 气泡 / 历史事件：`NotifyTravelOutcome` → `PublishNotification` → launcher `eventlog::Record`（Unreachable / FakeFireStop / BadTarget / AlreadyThere / **FireStuck**）；不可达以游戏内 Notice 为主。

## 5. 失败与用户可见反馈

| FailKind | 典型触发 | 反馈 |
|----------|----------|------|
| Unreachable | 同盘无路径 | Notice（预检）+ launcher / 历史事件 |
| AlreadyThere | src==dst | Notice / Info |
| BadTarget | 解析失败 | Warning + 历史事件 |
| FakeFireStop | 进门多次未换图 | Danger + 历史事件 |
| FireStuck | 硬贴门失败持续 ≥8s（`TELEPORT_FAIL` / `NOT_STOOD` 等；**不含** `TELEPORT_COOLDOWN` / `NOT_PLAY_READY`） | Danger + 历史事件（`travel.fire_stuck`） |

## 7. BIN / 验收清单

1. 同盘可达 Spot → YesNo 显示预计跳数 → 确认后逐跳 `FIRED`，最终 `arrived`
2. 跨盘/无边 Spot → **Notice 不可达**，不启动 Goto
3. 已在目标 Spot → Notice「已在目标」，不赶路
4. 击退离门：snap 测距 → 至多重贴一次；卸图中无 re-stick 闪退
5. `fh==0` 门：log `FH0_FORBID`，不 Doing
6. **贴门日志必须** `native ok … fh=<非0> snap=1`；禁止再出现赶路贴门 `fh=0 snap=0` 后 `ap` 穿台直坠
7. **FH AABB 外沿门**：如 `101030100/east01` `land.y==B`，不得再 `out_of_bounds`（种台 margin=0）
8. 假火满 fuse：停赶路 + `fake_fire` 通知；唯一桥不标死边
9. 关 payload / Shutdown：赶路无敌释放（`invuln release`）
10. 赶路中面板 Snapshot 不因开火 Sleep 长时间卡死（放锁）
