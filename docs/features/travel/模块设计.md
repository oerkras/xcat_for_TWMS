# travel Feature 模块设计（Classic TWMS）

> **状态**：✅ 同盘 seed BFS 赶路 + 瞬移贴门进门（世界地图 Spot 入口）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **源码**：`x/features/travel/` · `x/features/ports/travel_port.*` · `x/features/worldmap_marker_travel/`  
> **依赖**：`teleport_port::TeleportNativeSkillCall(snapStand=true)` · `foothold_path::SnapStandAt` · `world_port` 场景门 · `invuln` 赶路 Hold  
> **对照枫星**：假火软确认 / 唯一桥 / 按门名重解 / PlayReady 闸——**仅模式对照**；偏移与进门以经典版为准  
> **明确非目标**：码头自动化、跨板块自动爬图、港口换乘脚本

---

## 0. 一句话

世界地图 Spot 双击 → 同盘 BFS 求路径 → 每跳 **官方瞬移贴门** + CheckMove/↑ 进门；卸图期间禁止再 Doing。

## 2. 产品路径（进门）

默认 `FireMode::DirectEnter`（可切 `TeleportStick`）：

```
FirePortalByName(name)
  → StickThenEnterReady(门 x,y)
       → SnapStandAt → TeleportNativeSkillCall(sx,sy,fh, snapStand=true)【种 CurFh，禁止 fh=0 悬空】
       → WaitStood：Ap 贴近台面（≤400ms）；未站稳重贴一次 → `NOT_STOOD`
       → 成功后已卸图 → MAP_TRANSITION / MAP_CHANGED，禁止再 CheckMove
  → 仍 PlayReady → 主线程 CheckMovePortal（DirectEnter）或 ↑（TeleportStick）
```

> BIN 07:26：`fh=0` 悬空落点会穿台直坠（ap -375→-805）。贴门与战斗贴怪一样必须 Snap+种台；悬空自然落下方案已否决。

调试旁路（非产品默认）：`Up` / `CheckMove`（AbsPos 硬钉）/ `Rpc`。

枚举：优先 PortalManager；空则回退 `MapData.Portals@0x40`。

## 3. Goto 状态机要点

1. **解析目标**：`map_names` 解析；无当前图 → `pending goto` 等 `CurrentMapKey`
2. **BFS**：`Graph::PathTo(src,dst)`；空则 revive DEAD 再试；仍空 → `Unreachable` + 通知
3. **开火**：解析 live 门名 → `FirePortalByName`（**放 `gMu`**）→ 记 `gExpectMap` / pending
4. **换图确认**：离开 `gPendingFrom` → `OnMapEnterConfirmed`（实测写边）
5. **到站**：仅 `cur == gTarget`；跳数用尽未到 → `ReplanOrStop`（禁止假 arrived）
6. **假火**：超时未换图 → soft 重试 → fuse 停（`FakeFireStop`）；唯一桥不标死、可 late-wait
7. **Shutdown / SetIdle**：清状态 + `ReleaseInvulnForTravel`；`++gFireEpoch`

### 3.1 时序护栏

| 常量 | 约值 | 用途 |
|------|------|------|
| `kHopWaitMs` | 1200 | 普跳等换图 |
| `kHopWaitUniqueBridgeMs` | 1500 | 唯一桥等换图 |
| `kMidHopSettleMs` | 700 | 换图后稳图再开火 |
| 瞬移自冷（赶路） | 80ms | `SetNativeCooldownMs`；战斗侧各自再 Set |

硬门禁：

- `!IsInMapScene \|\| !IsPlayReady` → 禁止瞬移 / 禁止开火；midhop settle 时钟后推
- `SnapStandAt` 失败或 `fh==0` → `FH0_FORBID`（禁止 fill+Doing）
- 卸图中禁止 re-stick（BIN：re-stick Doing 撞死 LU）

### 3.2 开火放锁与 epoch

`FirePortalByName` 内含 Sleep/瞬移，**禁止持 `gMu`**（否则 `QuerySnapshot` / Stop 卡死）。

```
fireEpoch = gFireEpoch
unlock → FirePortalByName → lock
若 mode≠Goto 或 epoch≠gFireEpoch → 丢弃提交（仅打 log）
```

`SetIdle` / 新 `StartGotoResolved` 递增 `gFireEpoch`。

### 3.3 瞬移结果语义（诚实）

| 结果 | 含义 |
|------|------|
| `FH0_FORBID` / `TELEPORT_FAIL` / `NOT_PLAY_READY` / … | **失败**，不得冒充换图成功 |
| `MAP_TRANSITION` | 瞬移**已成功**且随后卸图 → `FirePortal` 返回 true，跳过 CheckMove |
| `MAP_CHANGED` | 贴门后 `CurrentMapKey` 已变 |
| `STUCK` / `OK` | 仍在稳图，可继续进门触发 |

`IsTransientFireFail`：仅瞬态失败（TELEPORT_FAIL、NOT_PLAY_READY、MAIN_TIMEOUT…）。  
`FH0_FORBID` → 假火软确认路径；**不**当无限 transient 空转。

## 4. 世界地图入口

详见 **[`../worldmap_marker_travel/模块设计.md`](../worldmap_marker_travel/模块设计.md)**（锚点 / 字段偏移 / BIN）。

摘要：

1. Spot 双击 → 优先 mapId；否则名/简介经 `map_names` 反查（禁止把简介原文当 goto）
2. **`PathHopCount(cur, dst)` 预检**
   - 不可达 / 坏目标 / 已在目标 → 游戏内 `UIUtilDialog.Notice`（RVA `0x749420`），不弹赶路确认
   - 可达 → YesNo（RVA `0x7454B0`），文案含「预计 N 跳」
3. 确认 → `travel::RequestGoto`

launcher 气泡：`NotifyTravelOutcome`（Unreachable / FakeFireStop / BadTarget / AlreadyThere）作辅；不可达以游戏内 Notice 为主。

## 7. BIN / 验收清单

1. 同盘可达 Spot → YesNo 显示预计跳数 → 确认后逐跳 `FIRED`，最终 `arrived`
2. 跨盘/无边 Spot → **Notice 不可达**，不启动 Goto
3. 已在目标 Spot → Notice「已在目标」，不赶路
4. 击退离门：snap 测距 → 至多重贴一次；卸图中无 re-stick 闪退
5. `fh==0` 门：log `FH0_FORBID`，不 Doing
6. 假火满 fuse：停赶路 + `fake_fire` 通知；唯一桥不标死边
7. 关 payload / Shutdown：赶路无敌释放（`invuln release`）
8. 赶路中面板 Snapshot 不因开火 Sleep 长时间卡死（放锁）
