# travel Feature 模块设计（Classic TWMS）

> **状态**：✅ 同盘 seed BFS 赶路 + Impact 贴门进门（世界地图 Spot 入口）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **源码**：`x/features/travel/` · `x/features/ports/travel_port.*` · `x/features/worldmap_marker_travel/`  
> **依赖**：`simple_combat::heli`（与 F5 贴怪同旋翼：`SetSetpoint`+`Tick`→`ImpactSetVelocity`）· `fly_fh_ban::BanSource::Travel`（滑翔期清台，与 F5/F6 多源 OR）· 贴门速度 = 面板「滑翔速度」（与打怪同）· `world_port` 场景门 · `invuln` 赶路 Hold  
> **对照枫星**：假火软确认 / 唯一桥 / 按门名重解 / PlayReady 闸——**仅模式对照**；偏移与进门以经典版为准  
> **明确非目标**：码头自动化、跨板块自动爬图、港口换乘脚本

---

## 0. 一句话

世界地图 Spot 双击 → 同盘 BFS 求路径 → 每跳 **旋翼滑翔到传送门**（对齐自动打怪贴怪）+ CheckMove/↑ 进门；fill+Doing 已废。

## 2. 产品路径（进门）

默认 `FireMode::StickUp`（贴门+↑；比直调 CheckMovePortal 更接近人手，边门少 205）：

```
FirePortalByName(name)
  → StickThenEnterReady(门)
       → 已在触发区 → OK（外层补一枪 ↑）
       → ImpactStickToPortal
            → 瞄准 **发门带 [portal.x±16] 里离门心最近的可站点**（可不是门心）；
                 `landY`=该处台面；旋翼 `aimY=landY+lift`（同层已挂台不抬）；
                 发门带空 → 门心 + 悬停（**禁**远岸同高 Y）
            → 需 invuln；否则 INVULN_OFF
            → `BanSource::Travel` 清台 + heli **面板滑翔速度** Cruise → Station（滞后锁 approach）
                 进触发框后**继续 Station 收速**
                 **门边刹住再落地**：`|vx|≤kPortalHoldEnterVx(30)` ∧ `|vy|≤kPortalHoldEnterVy` ∧ `|ap.y-landY|≤40` ∧ `ap.y≥landY-12`
                 （**禁**对抬高 aimY 做 bleed；落地用 landY；**禁** hold 硬刹 (0,0)）
                 才进 **hold**（卸 ban + 停旋翼）；超时未刹住则继续 Station 自然收速
                 → **就绪即走**：`onFh` + 合速≤fire + `|ap.x-portal.x|≤16` + 在触发框（stable≈400ms）→ ↑
                 **禁止**固定盲等 1.5s；**禁止** Disarm 后自由落体假站稳 / 掠过即火
                 hold 未站稳：出框宽限 / nearAim 保海岸；真甩远才 abort 再贴（仍面板倍率）
                 / 卸图 MAP_TRANSITION / 超时 NOT_STOOD / 连续失败 IMPACT_STICK_FAIL
  → 已 FIRED_* / MAP_* → 直接成功（勿二次 inRect，防残速 OUT_OF_RECT）
  → 仅 already_in 的 OK → 外层再 ↑
```

**StickUp 进门（产品定案）**：站稳后只 `unity_kbd` ↑（`CallUpKey` → **`HoldUntil`**，最短≈160ms / 最长≈700ms，MapId|transit 结束 + post-change drain）。**禁止**直调 `WM.CheckMovePortal`
（BIN：贴门后 `FIRED_DIRECT` / `CheckMovePortal primary` 均 ~100ms 断线；`FIRED`≠换图成功）。
日志认 `UnityKbd HoldUntil` + `kbd Up done mapId … (gate)`；失败路径常见 `pulse` + `FIRED_STICK_UP` + `interstage_stuck`（松键过早）。纯 ↑ 调试仍走 `FireMode::Up`。
输入模块说明：[`../unity_kbd/模块设计.md`](../unity_kbd/模块设计.md)。
**禁止**在 `managed_main::Call(FireJobOnMain)` 内再 `EnqueueAndWait`（主线程嵌套 → KEY_FAIL）。

**贴门速度（产品定案）**：全程面板「滑翔速度」（与打怪同款，**不再**封顶 2X / 接近压 1X）。
`approach` = Cruise→Station 档位切换：`dist≤140` 或进触发框则锁住；回 Cruise 须 `dist>220` 且离框（`enterR+slack` 滞后，防档位抽风）。
↑ 失败路径必须松键（`CallUpKey` `releaseUp`）。

**进 hold（产品定案 · 高门掉框）**：Station 收横/竖速、贴台面后再 Disarm；日志认 `bleed wait`（含 `need|vx|`）/ `hold begin … bleed=1`。
**禁止** hold 内 `ImpactSetVelocity(0,0)` 硬刹（kill-switch）。
**禁止**仅靠合速≤80 或 settle 超时就带 `vy≈64~125` 卸推（BIN：自由落体 → `hold abort (left trigger)`×2~3）。

**hold 就绪（产品定案）**：**有残留就必须等站稳再进门**。进 hold 只 `heli::Disarm` + 卸 ban，
**禁止** `ImpactSetVelocity(0,0)` 硬刹（疑非自然急停致断线）。站稳真源 =
AbsPos 连续静止 `kPortalReadyStableMs`(400)：邻步≤4、相对锚点≤8，另辅合速≤18 / onFh / 在框。
滑移日志 `wait settle (ap-drift|ap-step|speed)` → **整段重等**。`already_in` 同口径；超时禁 blind 补火。
就绪后再 `kPortalPreFireLandMs`(120) 确认未漂。

调试旁路（非产品默认）：`Up`（同 unity_kbd）/ `CheckMove` / `DirectEnter`（易 205）/ `Rpc`。
贴门只走 F5 同款旋翼 Impact；**禁止** AbsPos / Transform 硬钉；**禁止** fill+Doing；**禁止**再走 F6 `ImpactImpulseToward` 开环贴门。
`Transform.set_position` 解析与 TravelPos 锚灯已退役（产品不硬写坐标）。

枚举：优先 PortalManager；空则回退 `MapData.Portals@0x40`。

## 2.1 贴门滑翔实现（`travel_port`）

源码：`StickThenEnterReady` / `ImpactStickToPortal` / `AlreadyStoodAtPortal`（`x/features/ports/travel_port.cpp`）。

### 落点策略（产品定案）

对齐自动打怪「滑翔到怪位置」：瞄准传送门坐标（有框则夹进触发区），发布
`heli::Setpoint{Cruise|Station, aim}`，worker 循环 `heli::Tick`（内部 `ImpactSetVelocity` /
`SetImpactNext`）。打怪仍吃面板「滑翔速度」；贴门同面板倍率（不压 1X）。

| 约束 | 行为 |
|------|------|
| 触发区 | `MapPortalData.PortalRect`；空则 `±HImpact/VImpact` 兜底 |
| 瞄准 | **X=发门带可站点**（|dx|≤16）；Snap / `CurFh`；空集才门心+悬停；旋翼 `aimY=landY+24`（同层不抬）；开火 `|ap.x-portal.x|≤16` |
| 驱动 | `heli` Cruise（>140px）/ Station（≤140px），与打怪 `kHeliCruiseRadius` 同 |
| 速度 | **全程面板「滑翔速度」**（与打怪同；不再封顶 2X） |
| 进 hold | 台面上空 ∧ 横速收住；Station 悬停竖速 35~64 不挡；爬到 `landY+抬升` 即清 recover（禁再用悬停 vy 卡门）；空中不卡门 X，挂台后 `|ap.x-portal.x|≤16` |
| 无敌 | `invuln::IsEnabled()`；赶路 `HoldInvulnForTravel`；否则 `INVULN_OFF` 硬停 |
| 清台 | 滑翔期 `BanSource::Travel`；hold 起卸 ban 落地；停旋翼不再发 Move |
| hold 出框 | 宽限≈800ms；未站稳且 nearAim 保海岸；abort 后重贴（面板倍率） |
| hold 结束 | `onFh` + 合速≤`kPortalFireSpeed` + 门 X + 框内，stable≈400ms + prefire≈120ms |
| 超时 | `kImpactStickMaxMs≈14s` → `NOT_STOOD`（瞬态可重试） |

### 站稳判定

几何进门：`AlreadyStoodAtPortal`（strict rect，或无 rect 时近距 `kStickNearR`）。

- hold 就绪：`FlightState.onFh` + 低速 + 在触发框 → 立刻 ↑ / CheckMove
- 循环中卸图 / 非 PlayReady → `MAP_TRANSITION`（真换图，成功）
- 超时仍未进区 / 挂不上 FH → `NOT_STOOD`；`IMPACT_STICK_FAIL` 旋翼连续失败

### 与 Goto 的衔接

- `NOT_STOOD` / `IMPACT_STICK_FAIL` / `OUT_OF_RECT` ∈ 瞬态失败 → 可重试熔断
- `INVULN_OFF` → 立刻停赶路
- `MAP_TRANSITION` / `MAP_CHANGED`：`FirePortal` 返回 true，**跳过** CheckMove

## 3. Goto 状态机要点

1. **解析目标**：`map_names` 解析；**无 MapData**（`CurrentMapKey` 空）→ `pending goto` 等稳图。出生图 Field `0` / `000000000`（菇菇村訓練所入口）是合法 src，种子边 `out00 → 000010000`；**禁止**把 0 当成「没进图」。门的 `tm=0` 仍是假目标（`IsBogusDest`），与出生图同号但语义不同。
2. **BFS**：`Graph::PathTo(src,dst)`；空则 revive DEAD 再试；仍空 → `Unreachable` + 通知
3. **开火**：解析 live 门名 → `FirePortalByName`（**放 `gMu`**）→ 记 `gExpectMap` / pending
4. **换图确认**：离开 `gPendingFrom` → `OnMapEnterConfirmed`（实测写边）
5. **到站**：仅 `cur == gTarget`；跳数用尽未到 → `ReplanOrStop`（禁止假 arrived）
6. **假火**：超时未换图 → soft 重试 → fuse 停（`FakeFireStop`）；唯一桥不标死、可 late-wait  
   - 换图等待钟：`gHopStartedMs` 必须在 `FirePortalByName` **返回后**用 `GetTickCount()`（禁止 Tick 入口 stale now）  
   - StickUp follow-up ↑：首枪未换图时默认补第二枪（`kTravelUp2Default`；MapId 闸后才发）  
   - **首跳假火根因（BIN 2026-08-19 出生图 out00）**：世界地图仍开着时 StickUp 的 ↑ 被吞（三次 `HoldUntil timeout until=0`）。根治：确认后 `UIWorldMap.Close` + `kFirstHopSettleMs` + 未换图补 ↑  
   - 唯一桥等换图 `kHopWaitUniqueBridgeMs=700`：假火安全网（非根治）
7. **Shutdown / SetIdle**：清状态 + `ReleaseInvulnForTravel`；`++gFireEpoch`
8. **断线 / 软重连**：Goto **暂停**（`wait_resume`），不走 12s `interstage_stuck` / 假火墙钟。落地（hold 放 + land quiet 完）按当前图 `PathTo` 重规划剩余跳；**禁止**把重连当实测进门边。重连后 F5 仍勾选时在途赶路优先（Combat 对 `IsActive` 让路）。用户点停止仍立刻 Idle。

### 3.1 时序护栏

| 常量 | 约值 | 用途 |
|------|------|------|
| `kHopWaitMs` | 1200 | 普跳等换图 |
| `kHopWaitUniqueBridgeMs` | 700 | 唯一桥等换图（假火安全网） |
| `kMidHopSettleMs` | 1200 | 换图后稳图再下一跳 |
| `kFirstHopSettleMs` | 1200 | Goto 首跳稳图再开火（关世界地图后） |
| StickUp up2 | 默认开 | 首枪未换图且仍同图 PlayReady 时补 ↑ |
| Impact 贴门 | — | `heli::Tick`（共用滑翔速度）；无敌 Hold；无 fill+Doing |

硬门禁：

- `!IsInMapScene \|\| !IsPlayReady` → 禁止贴门冲量 / 禁止开火；hop settle 时钟后推
- 卸图中禁止 re-stick
- `FH0_FORBID` 已退役（旋翼滑翔不要求钉台）
- **贴门近台**：已 `onFh` 且 `|ap.y-landY|≤12`（**不限距离**）→ **不** `BAN` 撕台、**不** lift；旋翼贴台面推 X 到发门带再 hold↑。掉出台再改回远距飞。飞落残留 vx 会滑出带：未进 `|ap.x-portal.x|≤16` 或 coast 会出带时不 holdZero；带外 1px 打穿旋翼死区把人拉回可站点，不走进门心缝。有台仍空中卸推落地（禁止拿 `onFh` 挡 hold，BAN 开着永远挂不上台）。
- **贴门瞄准**：X = 发门带可站点（`SnapStandForPortal` / 当前 `CurFh`）；Y 巡航 `landY+24`，末段/recover/空集悬停用调试 TAB「贴门抬升」（默认 16）。禁止贴 `landY` 就 Disarm（空中接近）。
- **悬崖内缩**：`kEndInsetCliff=36` **只用于战斗** fill+Doing。F6 / 超级赶路 `SnapStandAt` / `SnapOnFh` / 贴门 snap 一律 `cliffInset=false`（只留 2px）。门口台被内缩切走不算空集（BIN 19:27 `105050400` east00 `x=2881`）。
- **发门带空集**（`aimFh=0`）：门心±16 真没台才 keep-station 悬停，ready **不**要求 `onFh`，也不卡门竖速（Station 竖速常 56+）。门口 `SpanX<16` 的近水平短台算有台（沼泽 `east00`），走普通空中 hold 落地，**禁止**当墙后假空集浮空。
- **换图后 settle / 托台**（BIN `9d504e` / `8fa033` / `adfed6`）：
  - **整段 transfer 窗都要 hover**：`wait_wm_field` / `wait_play_ready`（InterStage）/ `map_enter_stable` / `unique_bridge_*`，以及 `hop_settle` / `hop_land` / `arrive_settle` / `arrive_land` / `play_ready_stable`。
  - **假 transfer 收口**（BIN `cb18f8`）：同图 `MAP_TRANSITION` 且仍 Field/PlayReady **不** `NoteTransferStarted`；若已误 latch，同图稳图超时清 latch → 假火软确认（禁止干等到补给 180s）。
  - **对齐软着陆**：远距 approach 带 Travel FH ban；**近台 soft**（≤100px 且非暴坠）**不启旋翼**，只卸 ban 等引擎 `onFh`（BIN 0b0e8c：旧逻辑 soft 仍 Station 350ms →「多余飞一下再落地」）。远距拉近后仍可短 Station 消速再 drop。一直 BAN ON 则引擎永不 `onFh`。
  - 落点钉死首次近距 Snap（`preferFlat=false`，拒 >100px 远台，BIN `d76f13` 回城横飞）；settle 中清 heli `bail stale`。
  - 到站：稳图后再等挂台；仍悬空则 `RequestSafeLand(travel_arrive_airborne)`。
  - 此窗内 `simple_combat` 不抢旋翼（`travel::IsActive()`）。软着陆 `onFh` 结束须清 `gHeliAirborneUntilMs`，否则立刻 BAN ON 撕台。

### 3.2 开火放锁与 epoch

`FirePortalByName` 内含 Sleep/冲量，**禁止持 `gMu`**（否则 `QuerySnapshot` / Stop 卡死）。

```
fireEpoch = gFireEpoch
unlock → FirePortalByName → lock
若 mode≠Goto 或 epoch≠gFireEpoch → 丢弃提交（仅打 log）
```

`SetIdle` / 新 `StartGotoResolved` 递增 `gFireEpoch`。

### 3.3 贴门 / 进门结果语义（诚实）

| 结果 | 含义 |
|------|------|
| `IMPACT_STICK_FAIL` / `NOT_PLAY_READY` / `INVULN_OFF` / … | **失败**，不得冒充换图成功 |
| `NOT_STOOD` | 冲量超时仍未进触发区；**瞬态**，可重试本跳 |
| `MAP_TRANSITION` | 开火后卸图 → `FirePortal` 返回 true，跳过二次 CheckMove；**同图且仍 Field/PlayReady 不 latch transfer**（BIN cb18f8） |
| `MAP_CHANGED` | 贴门后 `CurrentMapKey` 已变 |
| `FIRED_*` / `OK` | 已开火或已在门内可继续 |

`IsTransientFireFail`：`IMPACT_STICK_FAIL`、`NOT_PLAY_READY`、`NOT_STOOD`、`OUT_OF_RECT`、`MAIN_TIMEOUT`…（兼容残留 `TELEPORT_*` 字符串）  
`IsTransientFireFail`：`IMPACT_STICK_FAIL`、`NOT_PLAY_READY`、`NOT_STOOD`、`OUT_OF_RECT`、`MAIN_TIMEOUT`…（兼容残留 `TELEPORT_*` / 旧 `FH0_FORBID` 字符串）

## 7. BIN / 验收清单

1. 同盘可达 Spot → YesNo 显示预计跳数 → 确认后逐跳 `FIRED`，最终 `arrived`
2. 跨盘/无边 Spot → **Notice 不可达**，不启动 Goto
3. 已在目标 Spot → Notice「已在目标」，不赶路
4. 击退离门：旋翼重贴；卸图中无 re-stick 闪退
5. 贴门日志：`… approach (latched)` →（高门可有 `bleed wait`）→ `hold begin … bleed=1` → `stood onFh` → 很快 `enter-armed`；不应再连刷 `hold abort (left trigger)`
