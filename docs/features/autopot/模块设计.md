# autopot Feature 模块设计（Classic TWMS）

> **状态**：✅ MVP 已挂入 `xcat.dll`（策略 + IPC + 用药通路；实机喝药待验收）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **对照来源**：`xcat_for_fengxing` 的 `x/features/autopot`（**只复用策略 / IPC / UI，不搬 Lua**）  
> **源码根**：`x/features/autopot/` · `x/features/ports/consumable_port.*` · `x/ui/player_vitals.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) — **禁止 E9 / 改 `GameAssembly.dll` `.text`**

## 0. 一句话目标

HP/MP 低于面板阈值时，经官方 `UISlotItem.SendStatChangeItemUseRequest(nPOS, 0)` 喝绑定/扫描到的消耗栏药水；带冷却、核对、软退避与硬熔断，避免空烧药。

---

## 1. 与枫星差异（勿混）

| 层 | 枫星（对照） | TWMS 经典版 |
|---|---|---|
| 读 HP/MP | IL2CPP `player_stats` + VitalsReady | `WM→CharacterData→CharacterStat`（共享 `player_vitals`；+ WM BasicStat） |
| 找药 | Lua PageDown/PageUp 绑定 | `CharacterData.ItemSlots[Consume]` 扫描 + itemId 启发式 |
| 用药 | Lua `_UseController:UseItemByItemId` | `UISlotItem.SendStatChangeItemUseRequest`（**共享** `main_thread_pump`） |
| 策略 | 冷却/核对/退避/危急 | **同形移植**（默认阈值 50/30） |
| 非目标 | 法师蓝优先、补药提醒、战斗逃逸 | MVP **不做** |

## 2. Phase 0 逆向结论（本轮已核）

| 项 | 证据 | 结论 |
|---|---|---|
| `SendStatChangeItemUseRequest` | dump RVA `0x5E4940` / VA `0x7FFB17124940` | 静态方法；`(int nIdx /*nPOS*/, int pPet)`；`pPet=0` 玩家自用 |
| CFF | IDA Hex-Rays 入口为控制流平坦化 | 仍可按 dump 签名直调；**不**改 `.text` |
| `WorldManager`→`CharacterData*` | getter `0xDBDB10` → `*(this+0xE0)` | **`WorldManager+0xE0`** |
| `CharacterData.ItemSlots` | dump `List<ItemSlotBase>[] @+0x40` | 按下标 `ItemType.Consume=2` 取消耗栏 |
| `ItemSlotBase.ItemId` | `int @+0x10` | 扫药主键 |
| `ItemSlotBundle.nNumber` | `ushort @+0x28` | 数量 |
| 主线程调用 | 对齐 `auto_enter` | **共享** `x/runtime/main_thread_pump`（`SendWillRenderCanvases` MethodInfo 或 attach 直调）；禁止各 feature 自建第二套泵 |

HP/MP 药判别（MVP 启发式，可后续换 ItemInfo）：

- 消耗段：`itemId ∈ [2000000, 2010000)`
- **已知蓝药**集合（含 2000003/4/6/18/23/38/39 等）→ MP
- 其余该段 → HP

`nPOS`：消耗栏 List 采用经典 1-based（`pos = listIndex` 当 `[0]==null`；否则 `pos = listIndex+1`），运行时日志可核对。

## 3. 策略状态机（对齐枫星）

默认（`autopot_config.h`）：

| 常量 | 值 |
|---|---|
| 检查间隔 | 100 ms |
| HP/MP 冷却 | 250 ms |
| 核对延迟 | 450 ms |
| 失败 streak | 3 → 软退避 8s |
| heal-stuck | 15s 硬熔断（含 emergency 不可破） |
| HP/MP 阈值默认 | 50% / 30% |
| 危急 | HP&lt;25% / MP&lt;15% 可破软退避 |

门控：`ports::world::IsPlayReady()`（地图场景 ∧ WM alive）→ 未落地（无可信 vitals）/ 死亡 HP≤0 / 双 1% 短窗假读数 / 开关关闭 → 不发用药。

```text
Tick
  → ReadVitals + latch
  → Verify 上次用药
  → allowHp/allowMp（冷却/退避/stuck/pending）
  → below threshold 或 emergency → FindPotion → UseRequest(main)
  → 记录 before + verifyAt
```

## 4. 目录与接线

```
x/ui/player_vitals.{h,cpp}          # 共享读数 + 可信闩锁
x/features/ports/consumable_port.*  # 扫消耗栏 + 主线程 UseRequest
x/features/autopot/autopot.*        # 策略 Tick / SetDesired
common/xcat_payload_control.*       # hpPotion/mpPotion/thresholds
x/ipc/payload_control.cpp           # ApplyControl
xcat_app/workspace_tabs.cpp         # 自动加血/加蓝 + %
x/probe/xcat_probe.cpp + CMake
```

Worker：独立线程 ~100ms 醒一次；用药经主线程泵（与 auto_enter 同模式）。
