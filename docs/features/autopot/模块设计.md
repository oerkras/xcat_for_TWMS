# autopot Feature 模块设计（Classic TWMS）

> **状态**：✅ MVP 已挂入 `xcat.dll`（策略 + IPC + **PageDown/PageUp 绑药** + UseRequest）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **对照来源**：`xcat_for_fengxing` 的 `x/features/autopot`（**复用策略 / IPC / 绑定语义，不搬 Lua**）  
> **源码根**：`x/features/autopot/` · `x/features/ports/consumable_port.*` · `x/ui/player_vitals.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) — **禁止 E9 / 改 `GameAssembly.dll` `.text`**

## 0. 一句话目标

HP/MP 低于面板阈值时，只喝 **PageDown（红）/ PageUp（蓝）** 上 `FuncType.Item` 绑定的那瓶药，经官方 `UISlotItem.SendStatChangeItemUseRequest` 用药；未绑则不喝。带冷却、核对、软退避与硬熔断。

---

## 1. 与枫星差异（勿混）

| 层 | 枫星（对照） | TWMS 经典版 |
|---|---|---|
| 读 HP/MP | IL2CPP `player_stats` + VitalsReady | `WM→CharacterData→CharacterStat`（共享 `player_vitals`；+ WM BasicStat） |
| 找药 | Lua PageDown/PageUp 绑定；未绑则不喝 | `FKM.GetDataByKeyCode(PageDown/Up)` → `FuncType.Item` → 消耗栏按 itemId 定位；**未绑不喝**（无全栏白名单回退） |
| 用药 | Lua `_UseController:UseItemByItemId` | `UISlotItem.SendStatChangeItemUseRequest`（**共享** `main_thread_pump`） |
| 危急兜底 | heal-stuck 时脉冲 PageDown/PageUp | 同形：`input::InjectKeyHold` → **unity_kbd**（非 OnKey） |
| 策略 | 冷却/核对/退避/危急 | **同形移植**（默认阈值 50/30） |
| 非目标 | 法师蓝优先、补药提醒、战斗逃逸 | MVP **不做** |

## 2. Phase 0 逆向结论（本轮已核）

| 项 | 证据 | 结论 |
|---|---|---|
| `SendStatChangeItemUseRequest` | TW RVA **`0x5E59C0`**（方法哈希 `bf5cbfce…`） | 静态 `(nPOS, itemId)`；**仅药水/属性消耗**。FuncKey 传 `(nPOS, itemId, MI=null)` |
| `SendPortalScrollUseRequest` | TW RVA **`0x5E8610`** | **回家/城镇卷专用**；与 StatChange **不可混用**。去店用卷见 [`../auto_supply/模块设计.md`](../auto_supply/模块设计.md) §2.1 |
| `FuncKeyMappedManager.GetDataByKeyCode` | remount 2026-08-04 RVA **`0x164F7C0`** | 与 `attack_input_port` 同源钉值；Key=Unity InputSystem（PageDown=66 / PageUp=67） |
| `FuncType.Item` | dump `= 2` | `FuncKey.Type==2` 时 `Value` = itemId |
| CFF | IDA Hex-Rays 入口为控制流平坦化 | 仍可按 dump 签名直调；**不**改 `.text` |
| `WorldManager`→`CharacterData*` | getter `0xDBDB10` → `*(this+0xE0)` | **`WorldManager+0xE0`** |
| `CharacterData.ItemSlots` | dump `List<ItemSlotBase>[] @+0x40` | 按下标 `ItemType.Consume=2` 取消耗栏 |
| `ItemSlotBase.ItemId` | `int @+0x10` | 绑药定位主键 |
| `ItemSlotBundle.nNumber` | `ushort @+0x28` | 数量 |
| 主线程调用 | 对齐 `auto_enter` | **共享** `x/runtime/main_thread_pump` |

绑药策略（产品约定）：

- **用户绑什么就喝什么**：`FuncType.Item` + `itemId>0` 即用，**无**红/蓝反类 soft-reject
- 未绑 / Type≠Item / 包内无该 id → 不喝
- 扫栏 `FindAndUsePotion` 仍走白名单硬过滤（autopot 不用）

`FindAndUsePotion`（全栏白名单扫描）**保留**给其他调用方；**autopot 只走** `FindAndUseBoundPotion`。

`nPOS`：默认优先 `pos = listIndex`（index≥1；BIN：PageUp 绑药成功恒为 `pos=listIndex`）。旧 `[0]==null` 启发式会随栏位抖动把 primary 打成 `listIndex+1` → empty + 烧 CD；仅当 `pos==listIndex` 成功时 latch（**禁止** alt 误锁成 PlusOne）；失败仍可 worker 侧 alt 重试但不改 latch。

## 3. 策略状态机（对齐枫星）

默认（`autopot_config.h`）：

| 常量 | 值 |
|---|---|
| 检查间隔 | 100 ms |
| HP 冷却 | 250 ms |
| MP 冷却 | 150 ms |
| empty 用药冷却 | 900 ms（qty 未降；紧急也不可破；阈值以上清） |
| empty streak 间距 | 2500 ms；满 3 次 → **仅**软退避 8s（**不** heal-stuck） |
| 核对延迟 | 300 ms（vitals）；绑药 qty 双段 delayed 200+180 ms |
| 绑药 miss | 未绑 / Type≠Item / 空袋 → 3s 退避（**紧急不可破**） |
| heal-stuck | 15s 硬熔断（含 emergency 不可破） |
| HP/MP 阈值默认 | 50% / 30% |
| 危急 | HP&lt;25% / MP&lt;15% 可破软退避；无效核对后可脉冲 PAGE 键 |

门控：`ports::world::IsPlayReady()`（地图场景 ∧ WM alive）→ 未落地（无可信 vitals）/ 死亡 HP≤0 / 双 1% 短窗假读数 / 开关关闭 → 不发用药。

```text
Tick
  → ReadVitals + latch
  → Verify 上次用药（连续无效 → heal-stuck + 危急时 unity_kbd PAGE 兜底）
  → allowHp/allowMp（冷却/退避/stuck/pending）
  → below threshold 或 emergency
       → FindAndUseBoundPotion(PageDown/Up)
       → 未绑 / Type≠Item / 包里没有 → 不喝（绑了就喝，不查红蓝类）
  → 记录 before + verifyAt
```

## 6. 日志与验收

- tag：`AutoPot` / `Consumable` / `Vitals`（统一 `xcat_log`）
- 期望：PageDown 绑红 → `act=hp pos=… id=绑定id`；解绑 → `no PageDown HP bind` / `bound pot miss`，**不再扫栏喝**
- BIN：`Consumable`/`AutoPot` 出现 bind miss，而非扫栏命中

### 验证清单

- [ ] 编译 `xcat_probe` → `xcat.dll`
- [ ] 面板勾选加血/加蓝 + 阈值落盘（`workspace_tabs` → `[core]`）
- [ ] 实机：PageDown 绑红药、开自动喝、掉血 → `act=hp` 且 id=绑定 id
- [ ] 实机：解绑 PageDown 后不应再喝
- [ ] 实机：PageDown/PageUp 绑任意消耗品 id（含白名单外）→ 按绑定 id 喝
- [ ] 实机：残蓝 + PageUp 绑药 → `act=mp`
- [ ] 死亡 / 选角 / 换图静默不发
- [ ] UseRequest 连续无效 + 危急 → 日志 heal-stuck，可观测一次 PAGE 脉冲
