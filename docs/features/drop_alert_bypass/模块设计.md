# drop_alert_bypass Feature 模块设计（Classic TWMS）

> **状态**：✅ 已挂入（**v3 threshold global** · 产品语义已定）  
> **源码根**：`x/features/drop_alert_bypass/` · IPC：`x/ipc/payload_control.*` · 契约：`common/xcat_payload_control.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **对照**：枫星 `drop_alert_bypass`（Lua `IsAlert` / `StartAlertAt`）；本仓不搬 Lua  
> **产品**：经典版 TWMS · **不是**枫星  
> **安全**：禁止 E9 / 改 GA `.text`；**不**占硬件断点槽

现行 RVA / 类哈希以源码为准（换版 remount 只改常量）。下文锚点为 **2026-08-16** 快照。

---

## 1. 产品语义

开着时：

- 战斗中可丢物（本地 `IsAlertMode` 门控放开）
- **同时抑制客户端警戒态**（打怪后警戒立不住；所有直调 `IsAlertMode` 的本地逻辑按「不在警戒」走）
- **不**改服务端 Drop 权威；保护物确认 / 交易封锁等其它检查仍在

关着时：警戒时长与拒丢恢复官方行为。

---

## 2. 根因与版本

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 | `DragManager.CanPerformAction` MethodInfo 交换，强制 `bCheckAlert=0` | 日志绿；GA 内多处 `E8` **直调 native**，钩进不去 |
| v2 | 周期清 `LocalUser` 警戒戳 | 能丢；出刀间隔≈1ms 时 stamp 被刷回，hold/32ms 必有空窗 |
| **v3（现行）** | 改写 `IsAlertMode` 专用比较常量 global | 装一次；出刀刷戳无空窗 |

真门控（IDA）：

```
IsAlertMode:
  mov eax, imm32
  add eax, [rip+disp]          ; 该 dword 仅 1 处 xref
  cmp [rcx+0x118], eax         ; signed：stamp > (imm+global)
  setnle al
  ret
```

文件里 `imm + *global == 0` ⇒ 语义即 **`stamp > 0`**。  
dump：`UserBase` 上 `+0x114` 是 **bool**（误锚）；警戒戳是旁边的 **int `+0x118`**。

**勿与** [`pet_loot/P0b`](../pet_loot/P0b_Drop归属预筛.md) 的 **`WorldManager+0x114`（Drop.OwnerId）** 混淆。

## 3. 现行实现（v3）

### 3.1 主路径：threshold global

1. Shape 扫 `IsAlertMode` 前 48 字节，须同时命中：
   - `B8 ?? ?? ?? ??  03 05 ?? ?? ?? ??`（`mov eax,imm` + `add eax,[rip]`）
   - `39 81 <alertOff>`（`cmp [rcx+off],eax`；`off` = field hash → fallback `0x118`）
2. `global = fn + movAt + 11 + disp32`（**运行时解析，不死钉 .data RVA**）
3. 功能开：`*global = 0x7FFFFFFF - imm`（使 `imm+*global == INT_MAX`）  
   → 任意正常 stamp 都过不了 signed `>` → `IsAlertMode` 恒假
4. 功能关 / worker 停 / `Shutdown`：`restore` 为首次读到的 `orig`
5. Worker 开时 **1s** 扫一次；发现被回写则再 arm（`threshHits++`）

不匹配 → **拒绝写 global** + 灯 `DropAlert=MISS` + BIN `shape FAIL`。

```
Probe IsAlertMode bytes
  → global = rip + disp
  → *global = INT_MAX - imm
  → IsAlertMode always false
```

### 3.2 次路径：MethodInfo

仍交换 `CanPerformAction` 的 `methodPointer`（少数 MI 调用方）。主丢物走直调，`miHits` 预期 **0**。

### 3.3 明确不做

- 改 GA `.text` / inline hook / E9
- HWBP 改 `bCheckAlert`
- 拦 `UpdateAlert*`（无单一 MI 可达写入漏斗）
- 主路径不再周期清 `+0x118`（v2 已撤）

### 3.4 锚点快照（2026-08-16）

| 项 | 值 |
|---|---|
| `IsAlertMode` RVA | `0x124DC50` |
| `CanPerformAction` RVA | `0x4CFEC0` |
| 警戒戳 | `UserBase+0x118`（int）；hash 见源码 `kHashAlertAt` |
| 误锚 | `+0x114` bool，勿清 |

BIN 装载样例（`x.jsonl` 15:06:24）：

```
shape OK cmp[rcx+0x118] imm=0xAF6AB7DB global=…60A91648
threshold arm orig=0x50954825 want=0xD0954824 (imm+want=0x7FFFFFFF) hits=1
```

之后每 15s `threshold ok … cur=0xD0954824 armed=1 threshHits=1`（未被回写、未重装）。

## 4. 生命周期

| 事件 | 行为 |
|---|---|
| `Init` | `gDesired=false`（等 `ApplyControl`） |
| `ApplyControl` | `SetEnabled(dropAlertBypass!=0)`；`!playReady` 时推迟玩法灌开关，**不**把已开的 desired 清 0 |
| 换图 | GA `.data` 仍在；dword 不丢 |
| 软重连（同进程） | BIN 已证：重连半截仍 `armed=1 threshHits=1`，无 `restore` / 无二次 `arm` |
| 关勾选 / worker 停 / `Shutdown` | `restore orig` |
| 杀进程再开 | GA 原值；进图后再 arm |

实验 Tab `persistDrop`：Write 后必须回读 `writeTickMs`（对齐 PartyBooster），否则勾上会被冲回 0。

---

## 5. 检测面与交叉功能

**检测**：无 `.text`/inline；主路径改 `IsAlertMode` 专用 `.data` dword（1 xref）。暴露主要是行为（客户端警戒被压住）。

| 模块 | 开着时 |
|---|---|
| `channel_hop` | 直调 `IsAlertMode` → **不再等脱战警戒** |
| `pet_feed` | 读 `+0x118` 戳，不调 `IsAlertMode` → 召唤仍可能等戳落 |
| 服务端 Drop / 保护物 / 交易封锁 | 不变 |

IDA：`IsAlertMode` 约 13 处 `call`（含 `CanPerformAction`）；该 threshold global **仅 1 xref**。

## 7. 验收

1. 开 → `shape OK` + `threshold arm`；极短出刀间隔边打边丢不再间歇拒  
2. 换版机码漂 → `shape FAIL`、灯 MISS、**不改 global**  
3. `miHits` 可为 0  
4. 关 → `threshold restore`；警戒恢复；警戒态再拒丢  
5. 保护物/交易封锁仍在  
6. 软重连后无 `restore`、`threshHits` 不无故 +1；落地后仍 `armed=1`
