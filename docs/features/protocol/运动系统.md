## 1. 时钟：一拍多少 ms

| 项 | 值 | 证据 |
|---|---|---|
| 基类 `BeginUpdateActive` 返回值 | **30** | RVA `0x11C78A0` 函数体 **唯一** 立即数 `mov eax, 1Eh`（size `0x208`） |
| `tSec` | `tElapse / 1000.0` | 旧笔记 `0x408F400000000000`；与 AccSpeed 的 `* t` 配套 |
| 人 `VecCtrlUser.BeginUpdateActive` | **先 call 基类**（返回 30），终速只动坠落计数、**仍返回 30** | RVA `0x11FF8C0`：`call 0x11C78A0` → `edi=eax`；`-Apl.Vy`（`+0xD0` 取反）与 `FallSpeed(+0x78)` 比。`cmovnb edi,0` 只是中间态：过快则 `+0x108++` 再 `mov edi,ecx` **把 30 填回**；未过快则 `[+0x108]=0`。函数出口 **不是** tElapse=0 |
| 怪 | 走基类 Slot 10，**没有** User 那套坠速掐 tick | `VecCtrlMob` dump **无 Slot 10 override**；Slot 11 WUA `0x11DADE0` 吃入参 `tElapse` |

`xorpd` 取反用的是符号位掩码 `0x8000000000000000`（`xmmword_7FFD65DD08E0`）。AbsPos Y 增大=更高，下落 `Vy<0`，取反后与正的 `FallSpeed` 比。

**500ms Flush 窗口 × 30ms/拍 ≈ 16 拍。** 帧夹 48px/拍 → 一包内可到 ~768px，压不住包位移（与吸怪 §10.10 一致）。

## 5. 人：自由落体 tick

`VecCtrlUser` 字段：`_user+0xF8`（runtime dump 在 `+0x100` 起，基类尾对齐后）、`_nMaxFreeFallTick+0x108`（dump）、静态 `FreeFallTick`。

`.cctor` RVA `0x1203790` 尾部实算（非猜）：

```text
TypeInfo qword_671E1A88 → static_fields(+0xB8) → [+0x20] 对象
rsi = *(uint64*)(obj+0x30) >> 32          ; 高 dword，不是低 32 位
ecx = esi * 1000                           ; imul 3E8h
xmm0 = (double)ecx / Constants.FallSpeed(+0x78) / 30.0
FreeFallTick = (int)xmm0
```

即 **`FreeFallTick = esi / (FallSpeed * 0.03)`**。`esi` 的类名要活读堆上 TypeInfo（IDB 里是 `0x1bda1ccbef0`，未映射）。同 TypeInfo 还被 RVA `0x4B61C0` 引用。

User Begin：若 `-Apl.Vy >= FallSpeed`，**累加** `+0x108`（连续终速帧）；否则 **清零**。返回值仍是基类的 **30**。`cmovnb edi, 0` 在 `mov edi, ecx` 之前就被盖掉，**不会**把本拍积分掐死。`FreeFallTick` 静态算出来了，本函数里没拿它跟 `+0x108` 比（谁读这个计数还没摊）。

### 9.3 `CalcWalk` 水平力（AccSpeed 内联）


#### 9.3.1 踏板 `Force`（传送带）——`0.2` 在这里，不是 UV

先前把 `0.2 / |x|` 写成 UV 修正 **不准确**。出盒后 `xmm10 = AttrFoothold.Force`（`r13+0x18`）。`xmm11` 才是 UVY。

`sub_7FFD646CD880`：比较 `*(float*)Drag == 1.0f`（NaN 两边也算相等）。`ebp = (Force == 0)`（`cmpeqss`）。

`Force ≠ 0` 时对 **走力 f** 和 **vmax** 各有一套相同结构（vmax 在 `MaxWalkSpeed` 返回之后，`0x7FFD619FB850`）：

```text

absF = |Force|                          ; andps 掩码 xmmword_65B4B2C0 = 0x7FFFFFFF
ratio = 0.2 / absF                      ; qword_65D853C8 = 0x3FC999999999999A
two   = 2 * absF
按 prod 的符号与另一路比较，三选一乘上去：
  vmax 或 f  *=  |Force|  或  2*|Force|  或  0.2/|Force|
```

`0.2` 是传送带力的混合系数，**不是** 1000ms，也不是斜面 UV。

#### 9.3.2 UVY 斜面（`1 ± UVY²`）

```text

xmm7  = |UVY|²                          ; mulss
r15d  = UVY>0 ? +1 : -1                 ; lea r15d, -1[rax*2]

xmm14 = 1.0f - UVY²                     ; 仅当 UVY² < 1（单位 UV 时 ≈ UVX²）
```

`1.0f` 来自 `xmmword_65B4B30C`（`0x3F800000`）。**此处会覆盖 xmm11 里的 UVY**，后面斜面只用 xmm8/xmm7/r15。

`MaxWalkSpeed` 的 `dir` 种子仍解成 **0**，MWS 内部的 `(1+dir·UVY²)` **不走**。`xmm14` 在 MWS 之后转成 double 乘进走力支路（`cvtss2sd xmm1, xmm14; mulsd xmm1, xmm12`）——水平投影项，不是 vmax。

#### 9.3.3 `WalkSlant`（鞋 `+0x20`，ctor **0.9f**）

乘点不在 `MaxWalkSpeed`。CalcWalk `0x7FFD619FC076`：

### 9.5 `CalcFloat` 重力（`xmm9` 已钉）

```text

xmm6 = Ap.Vx                     ; +0xA8
xmm7 = Ap.Vy                     ; +0xB0

       * AttrField.G             ; VecCtrl+0x48 → +0x28
       * (double)Mass            ; cvtss2sd xmm9
  xmm0 /= Mass                   ; 质量抵消
  xmm0 *= tSec
  Ap.Vy -= xmm0                  ; subsd xmm7, xmm0
```

净效果：**`vy -= GravityAcc × Field.G × tSec`**（与质量无关）。`tSec = tElapse / 1000.0`（`divsd xmm8, qword_65C63718`，IEEE 实读 **1000.0**）。

BIN 每拍 `dvy = −60`、步长 30ms ⇒ **`GravityAcc × G = 2000` px/s²**（场 G 默认 1.0 时 GravityAcc 就是 2000）。DLL `.rdata` 里搜不到这个 double，它在 Unity 序列化的 Constants 上。

**积分（`0x11D0FB8`，`0.5`=`qword_65B619B0`）：** CalcFloat 改完速度之后用梯形，不是 `x += v_new * t`：

```text

Ap.Y += 0.5 * (Vy_进入CalcFloat + Vy_新) * tSec
然后才写回 Ap.Vx / Ap.Vy
```

WUA 里 **ApplyImpact 在 CalcFloat 之前**，所以「进入 CalcFloat 的 V」已经是冲量后的值。一拍重力若把 Vy 减 60，位置用的平均速度比冲量瞬间值少 **30 px/s** —— 这就是 `heli_rotor` 配平里那步 `kGravityPerStep/2`。

**`WingsNow(+0x71)` 分流（`0x11cf583`）：** `test al; cmovnz`。非 0 → **`0x11CF5A3`** 翼支：`xmm7 = JumpSpeed(+0x80) * (double)WingsParam(+0x74) / -1000.0`（除数 `qword_65E6D130` 实读 **−1000.0**）。**0 → `0x11D083A` 坠落支**（重力 + 终速夹 + 梯形）。`SetImpactNext` 每次把 Now 写成 **0**（见 §12.5），F5/F6 因而一直在坠落支，不会进翼。

**空阻预载（WingsNow 分流之前，两支都会执行）：**

```text

xmm11 = FloatDrag2(+0x40) * AttrField.Drag         ; 坠落支还活着
```

`dump.cs` 里的 `CalculateFloatDragSensitivity` 是 **Unity 编辑器** `NumericFieldDraggerUtility`（RVA `0x3BBE2E0`），**不是** 这条空阻。

**坠落支（`0x11D083A`）还做的：**

- 竖：`Δvy = (FloatDrag2×Drag / Mass) * tSec`。`Vy<0`（下落）时 **加上**（减缓坠落），`Vy>0` 时 **减去**（减缓上升）。然后 `vy -= GravityAcc×G×tSec`。再 `ucomisd` 把 Vy 夹进 **`±(FallSpeed×G)`**（`0x11d0a79 movapd xmm7, xmm12`）。
- 横：`InputX != 0`（`0xA5DD1E1E + dword_670D2AB4` → **0**）才 `xmm11 *= InputX; xmm11 += xmm11`（×2），`Vx += (xmm11/Mass)*tSec`，再夹到派生 xmm10，**然后直接去梯形**（不走松键减速）。
- 横、`InputX == 0`（旋翼默认）：`DecSpeed` 把 Vx 往 **0** 拖，夹零用的是 IEEE **−0.0**（`qword_65E6D128`，不是速度常数）。
  - `|Vy|` 还没到终速（`Vy > -FallSpeed×G`，悬停/慢坠/上升都在这）：`f = FloatDrag2 × Drag × FloatCoefficient(+0x48)`
  - 已到或超过终速（`Vy <= -FallSpeed×G`）：`f = FloatDrag2 × Drag`（**不乘** Coefficient，更猛）
  - `Vx>0`：`Vx -= (f/Mass)×tSec`，穿过 0 则钉 0；`Vx<0`：对称加上去。
- **`qword_65E6D140 = 0.015`、`×(-1.5)`、`×0.3` 在翼/飞续段（`0x11cf76c` 一带），坠落支跳过。** 不要把 0.015 写成坠落终速系数。

人 Begin 若 `-Apl.Vy >= FallSpeed` 只给 `+0x108` 计数（未过快则清零），**返回值仍是 30**，坠落支照样积分。

## 10. RelPos ↔ AbsPos 与走路碰撞（新块）

`RelPos` 在 `VecCtrl+0x88`：`Pos` double、`V` double（速度沿踏板，px/s）。`AbsPos` 在 `+0x98`。

### 11.1 `SetFromRelPos` RVA `0x11D9900`（已反编译，无 CFF）

`void(AbsPos* ap, RelPos* rp, StaticFoothold* fh)`，fh 空则 `60BBF390`：

```text
ap.X  = (double)fh.X1 + fh.UVX * rp.Pos
ap.Y  = (double)fh.Y1 + fh.UVY * rp.Pos
ap.Vx = fh.UVX * rp.V
ap.Vy = fh.UVY * rp.V
```

AbsPos Y 增大=更高：UVY>0 的踏板，Pos 增大就是往更高处走。

### 11.2 `SetFromAbsPos` RVA `0x11D9980`

```text
if |UVX| > 0.5:   Pos = (ap.X - X1) / UVX     ; 更平的板用 X
else:             Pos = (ap.Y - Y1) / UVY     ; 更陡的板用 Y
V   = UVX*ap.Vx + UVY*ap.Vy                   ; cvtps2pd UV，mulpd 速度，addsd
Pos = clamp(Pos, 0, Len)                      ; Pos>Len → Len；Pos<0 另支
```

`0.5` 仍是 `qword_65B619B0`。`|UVX|` 用同一 `0x7FFFFFFF` abs 掩码。

另被 `0x11C5BD0`、`0x11D2F00`（Impact 的 callee）调用。

### 11.3 `CollisionDetectWalk` RVA `0x11D4220`

CalcWalk 改的是 `RelPos.V`；本函数按 Pos 对 **Len** 出界换板，再 `SetFromRelPos` 刷新 Ap。

```text
if Pos >= Len:
    走 NextFoothold (FH+0x60)；校验 next.Prev 与当前的链接
    若 next.UVX > 0: Pos = next.Len，否则 Pos=0（从哪一端上板）
    SetFromRelPos(Ap, RelPos, next)
if Pos < 0:  对称走 PrevFoothold(+0x58)，Pos 钉 0
```

Helper `0x11D5320`：用 `X1 + UVX*Pos` 对照 `MapBound`（`VecCtrl+0xD8`）。出界则

```text
Pos = (boundX - X1) / UVX
V   = 0
```

### 11.4 `CollisionDetectFloat` RVA `0x11D5BB0`（size `0x1F31`）

签名 CMS：`(ref AbsPos p1, ref int tElapse, bool bCalcFloat=false)`。吃的是 **AbsPos 线段**（上一拍 / 本拍），不是 RelPos。CDFloat 本体也是 CFF；下面按真实 `call` 顺序，不靠 Hex-Rays 总览。

#### 11.4.1 先夹地图框：`0x11D7C10`（size `0x9CE`，CFF）

**不是** `GetCrossCandidate`。入参 `rcx=this, rdx=&p1, r8d=tElapse`，返回 **eax = 夹过的 tElapse**（CDFloat 存进 `r13d`）。

`Math.Max/Min(int)` = `0x646B74B0` / `0x646B75F0`；比较器夹 = `0x62BAAEC0`。业务是 **把 Ap 钉在 `MapBound`（`VecCtrl+0xD8` Unity Rect：x/+0、y/+4、w/+8、h/+C）里**，出界清速度：

```text
xMax = (double)(MapBound.x + MapBound.width)     ; +D8 + +E0
yMax = (double)(MapBound.y + MapBound.height)    ; +DC + +E4
; 命中 X 边：Ap.X = 边，Ap.Vx = 0（+A8）
; 命中 Y 边：Ap.Y = 边，Ap.Vy = 0（+B0）
; 撞击时刻：t' = tElapse * (bound - p1) / (Ap - p1)，再 clamp 到 [0, tElapse]
```

虚转 `0x130/0x148`、`+0x160`、`+0x198`、`+0x1F8` 是 VecCtrl 槽（CFF `jmp [r14+…]`），**不是** PhysicalSpace 找板。本函数 **0 次** call `0xD63B20` / `0x14B2430`。

#### 11.4.2 格子没动就整段跳过

`0x11C483A0`：`x>=0` → `cvttsd2si`（朝 0）；`x<0` → `0.499999999 - x`（`qword_65DD0958`）再截、MBA 取反 ≈ **floor**。对 `p1.X/Y` 与 `Ap.X/Y` 各一次。

`Δx`/`Δy` 的 MBA 比较常数（`0x122A21C9+seed`、`0x2F16E63B+seed`）都解成 **0**。两轴整数格都不变 → `0x11D750D`，不找板。

#### 11.4.3 候选列表 = `MapData.GetCrossCandidate` `0x14B2430`

格子有动才走。`PhysicalSpace2D` stub `0xD63B20` 把 `this` 换成 **`MapData*`（`PS2D+0x20`）** 再进本体。CDFloat **不 call** `GetFootholdUnderneath` `0xD64D30`。

`edx,r8d,r9d,(stack)y2` = `p1.X, p1.Y, Ap.X, Ap.Y`：

```text
minX,maxX = sort(x1,x2)     ; r15 / edi，cmovge
minY,maxY = sort(y1,y2)     ; r14 / esi
w = |maxX-minX|             ; MBA a+2*~a+2 再 abs
h = |maxY-minY|
search = RectInt(minX, minY, w, h)     ; 与 Unity RectInt 同布局
out List = new List<StaticFoothold>()  ; object_new + 62DB4B40 写 out

enum = _footholdRectMap(+0xE8).GetEnumerator()   ; 63CEFA30 / MoveNext 63F2EF80，entry stride 28
loop:
    id = enumerator.current key                  ; r12d
    rect = dict[id]                              ; 63CEFD90 拷 16B RectInt（stride 28）
    if !Overlap(rect, search): continue          ; 0x1417D80，al=0 → 下一条
    fh = _footholdMap(+0xE0)[id]                 ; 63CEC0D0 回指针（stride 24）
    list.Add(fh)                                 ; _items+0x10，_size+0x18，_version+0x1C
```

**重叠** `0x1417D80`（size `0x57D`，CFF）：`rdi`/`rsi` 两个 `RectInt`，先 X 再 Y。`[p+0]=x`、`[p+8]=width`（y/height 在 +4/+C 的对称支）。MBA 算出 `x+width`，然后 `max(left) ? min(right)`：`cmovl` → 无重叠 `eax=0`；两轴都过才 `al=1`。就是轴对齐盒相交，**不是** 线段-踏板叉积（叉积在 CDFloat 里对过筛结果做）。

#### 11.4.4 过滤候选

`r12` = 当前 `StaticFoothold*`：

| 偏移 | CMS | 本函数用法 |
|---|---|---|
| `+0x74` | ZMass | 先比 `get_BaseZMass`（`0xD613E0` = `MapData+0x100`），再比 `VecCtrl+0xF0`；**不等本机 ZMass → `0x11D6EAD` 跳过** |
| `+0x78` | UVX | `ucomiss 0, UVX` 分支（xmm10 在循环前 `xorps` 清零） |

#### 11.4.5 穿越 + 阻挡

对过筛踏板 **两次** `get_cross_product` `0xD63B70`（MBA ≡ 标准叉积；比较常数全 0）：

- 两次同号（都 `<0` 或都 `>0`）→ 没穿过，下一条
- **异号** → `is_blocked_area` `0xD63C00`；过了才落地

`is_blocked_area`（size `0x35C`，CFF；几乎无 call）：

```text
fh1: X1+0x14 Y1+0x18 X2+0x1C Y2+0x20
fh2: 同上（后半再读 fh2.X1/Y1）
点 (x,y) 在栈上
MBA 减法（a+2*~a+2 ≡ -a）+ imul 做叉积/面积
最终 cmp eax, 0     ; 0xBD267D48 + dword_670BF578 → 0
setnle al           ; 返回 (signed 乘积) > 0
```

真则视为挡住、不能从这条踏板落地。第三次叉积在 `0x11D730D`。`call r8` 在 `0x11D6EFE` 是虚调用，不是找板 API。

#### 11.4.6 落地

```text
t = RelPos.V * InputX
RelPos.V = (t < 0) ? 0 : RelPos.V * 0.5     ; cmpltsd + andnpd，0.5=65B619B0
SetFromRelPos(&Ap 或 p1, RelPos, fh)        ; 0x11D9900
OnAttachedObjectChanged(this, fh, 0, tElapse)   ; klass+0x248
return true
```

另一支：`SetFromRelPos` + `MakeContinuousMovePath`（klass+0x228）。`0x62BAB220` 是落地前的 double 夹（IComparer），不是 List。

活读 Constants：游戏进程仍可能被 NGS 护着（RPM **ERROR_ACCESS_DENIED**）。公式侧不猜 140000。

## 12. 空中滑翔对照（F5/F6 Impact 旋翼）

产品侧滑翔 = **`SetImpactNext` + `fly_fh_ban` 挡 Slot 13/14`**，不是引擎 `Wings()` / `FlySpeed`。下面只列旋翼闭环真会碰到的引擎量。

### 12.1 一拍里谁先谁后（基类 WUA）

```text
BeginUpdateActive          人：过速坠落可能 tElapse=0
ApplyImpact                清 Valid → 有台则 LeaveFoothold → Min/Max → 整值 → 加格 type=2
                           0x11C85D0
CalcWalk                   CurFH==0：`test rax; setnz` 跳过 FH.Walk/UV 本体（0x11cb1ed）
CalcFloat                  重力 + FloatDrag2 空阻 + 梯形                     0x11CCBE0  ← BAN 挡不住
CollisionDetectFloat       找板落地 / MapBound 夹边                           0x11D5BB0  ← BAN return 0
MakeContinuousMovePath     fh=0 → FallDown/Normal，不是 Wings
```

`fly_fh_ban` 钩 CDF **不 call 原函数**：不落台，也 **不跑** `0x11D7C10` 的引擎 `MapBound` 夹边。空域围栏是自己的 FH AABB（`map_bounds_port`），不是 `VecCtrl+0xD8`。

### 12.2 跟 `heli_rotor.h` 对得上的

| 旋翼口径 | 引擎 |
|---|---|
| 每步重力 **−60 px/s**、30ms、g=2000 | `vy -= GravityAcc × G × tSec`；30ms×2000=60。质量抵消 |
| 配平必须含 **30 px/s**（落地帧那半步） | 梯形 `0.5*(v_冲量后 + v_减重力后)*tSec` |
| 自然坠终速约 **−670** | `FallSpeed × Field.G` 夹 `Ap.Vy`；人 Begin 过快只加 `+0x108` 计数，**不**掐 tElapse |
| X/Y 冲量 Min/Max、整值落地 | `ApplyImpact`（见满火力笔记） |
| 禁挂台 | 否则 CDF：ZMass 相同 + 叉积异号 + `is_blocked_area` 不过 → `SetFromRelPos`，`RelPos.V` 减半 |
| 不要置 `WingsNow=1` | 会离开坠落支，改走 `JumpSpeed * WingsParam / -1000`，跟冲量抢 Vy。**`SetImpactNext` 自己写成 0**，不会误进翼 |

### 12.3 旋翼没建模、但引擎每拍仍在做的

- **FloatDrag2 × AttrField.Drag**：坠落支加在 **Vy** 上（下落减缓、上升减缓）。`InputX=0` 时还把 **Vx 往 0 拖**（`DecSpeed`；悬停走 `× FloatCoefficient`，到终速才不乘）。`FloatDrag1` 预载后立刻被 G/WalkSpeed 覆写，**坠落支用不到**。
- **InputX≠0** 时坠落支给 Vx 加力（`xmm11×InputX×2/Mass×tSec`）并夹派生上限，**不加**松键减速。旋翼若 `SetInput(±1)` 会跟冲量叠。
- **鞋 FlyAcc/FlySpeed ctor=0**：即使用户飞图，引擎飞支水平力默认是 0；旋翼不靠这条。
- 格子不动 CDF 整段跳过——BAN 失效时，**同一格内挪不足 1px 不会重新贴台**。
- 站着发第一发冲量：`ApplyImpact` 见 `CurFH≠0` 会 **`LeaveFoothold` `0x11D2F00`**。之后要靠 BAN 才能不让 CDF 贴回去。

### 12.4 明确没用的（别接到旋翼上）

引擎 `Wings`/`StartWings`、`FlyForce(+0x60)`、`IsSwimMap`/`IsInArea`、梯子 `InputY*−3`、Unity 的 `CalculateFloatDragSensitivity`、**`NockBack`**（直写冲击、无合并）。那是走跳/游泳/飞天/受击，不是 Impact 滑翔。

### 12.5 `SetImpactNext` / `ApplyImpact`：文档校正（本 IDB 实读）

对照 [`P0b_引擎实现原理.md`](../teleport/P0b_引擎实现原理.md)（旧 imagebase / 未解 MBA）、[`满火力进站与竖直权限.md`](../simple_combat/满火力进站与竖直权限.md)、`heli_rotor.h` ③。**以本表为准。**

**`SetImpactNext` `0x11C5150`**

| 项 | 旧文档 | 本 IDB |
|---|---|---|
| 写 `WingsNow(+0x71)` | P0b：每次都写，MBA 未解（旧 `add al,5Dh`） | `movzx al, byte_670D2938`（**0xAF**）`xor al, 0AFh` → **恒 0** |
| 置 `Valid(+0x10)` | 写 true | `byte_670D2934=0x53 xor 52h` → **1** |
| `!Valid` 清零 | `qword [impact+0x14]=0` 盖掉 Vx+Vy | 同，指令仍在 `0x11c5592` |
| 合并待消费冲击 | `cmd<0 ? fmax(cmd, old+cmd) : fmin(cmd, old+cmd)` | 同。`fmax`=`0x646B7470`，`fmin`=`0x646B75B0`。`add rbx, 14h` 后 `movss [rbx], xmm0` 写的是 **float Vx@+0x14**（Vy 对称 `+0x18`） |
| 叠不上 | 满火力：后发换掉前发 | 同（饱和朝新 cmd，不是累加两次 cmd） |

**`ApplyImpact` `0x11C85D0`**

| 项 | 本 IDB |
|---|---|
| 清 Valid | `byte_670D2A1C=0x4E + 0xB2` 溢出 → **0**（`0x11c8b6d`） |
| 离台 | `CurFH(+0x28)≠0` → `LeaveFoothold` **`0x11D2F00`** |
| 公式 | 与 SetImpactNext 同一条：`cmd<0` → `Math.Max(cmd, v+cmd)`（`0x62BA3360`）；`cmd≥0` → `Math.Min(cmd, v+cmd)`（`0x62BA3600`）。X/Y 对称。 |
| 整值 | `cvttpd2dq` 两轴截成整数再写回 `Ap.Vx/Vy`（`+0xA8/+0xB0`） |
| 加格 | `AddElem` `0x11BF820`：`0x7F438BAF + dword_670D2A00` 32 位溢出 → **type=2 Impact** |

**`NockBack` `0x11D8960`（不是旋翼）：** `Valid=1`（`byte_670D2C1C=0x8F + 0x72`），`impact.Vx = (float)(dir * vx)`，`Vy = (float)vy`。无 fmin/fmax、不写 `WingsNow`。`0x11C59F0` 是「`Valid` 已真则跳过」的薄封装，heli 走的是 `0x11C5150` 本体。

**梯形写回（坠落支尾 `0x11D0FB8`，已核）：** 物体上的 `Ap.V` 一直留着进入 CalcFloat 的值（即 ApplyImpact 之后），xmm6/7 是拖+重力后的新速；`Ap += 0.5*(V旧+V新)*tSec`，最后才 `movsd` 写回 Vx/Vy。然后 `ret`。

**跟头文件 ③ 的关系（不要改 `heli_rotor.h`）：**

IDA 是「朝 cmd 饱和」：`v_new = (cmd<0) ? max(cmd, v+cmd) : min(cmd, v+cmd)`。

BIN 拟合是 `v_new = clamp(v+cmd, ±max(|v|,|cmd|))`。同向发小值减速：IDA 会落到 cmd，BIN 样本显示被无视。满火力笔记已写明 ③ 是 DUMP 拟合、控制律两边都用 `vt−v`。**未出新 BIN 前不改 ③。** `VxCommandFor` 在两套模型下对「反向 / 同向加速 / 用 `vt−v` 减速」都能一发到位；只有「同向发比当前更慢的小 cmd」分叉。
