
## 4. Flush 与 `Δpos ≈ v·Δt`（2026-08-01）

### 4.1 客户端结论（实锤）

| 问题 | 结论 | 证据 |
|---|---|---|
| Flush 是否本地校验 `Δpos ≈ v·el/1000`？ | **否** | IDA `MovePath_Flush`：函数内 **无** 字节/立即数 `3E8h`/`1000`，无 `vx×el` 一致性分支 |
| Flush 实际做什么？ | 累加 `Elem.Elapse`→`_gatherDuration@+0x2C`；List 边界；拷字段；`MovePath_Encode`；发包 | 反汇编 + IDA 注释 @ `MovePath_Flush` |
| 坏 Elem 能否 Flush？ | **能** | 飞天矛盾包 `movepath_flush.log` FLUSH#38 仍 `pktId=47` 发出 |

飞天文档里的「服端只要做 `Δpos≈v·Δt`」= **服端侧强推断**，不是客户端 Flush 门禁。

### 4.2 实抓误差与软松弛（`movepath_flush.log` · UserMove `pktId=47`）

相邻 Elem、`el>0`：`err = ‖Δxy − v·el/1000‖`（**2026-08-01 复算**）

| 集合 | n | 误差 |
|---|---|---|
| 地面 `fh>0` | 6 | 均值 ~5.6；**max ~17.7**；p50 ~1.8 |
| 空中 `fh=0` | 16 | 均值 ~16；**p50 ~16 / p90 ~25 / p99 ~27** |
| FLUSH#38（飞天坏包） | 6 段 | 逐段约 **5～16 px**，且 **Vy 符号与 Δ 对不上** |

合法路径也**不是** bit 级等式：Jump 可出现 `el=0`；地面亦可到十余 px。推断服端为 **软松弛（至少数十 px 量级）+ 符号/包络/fh 语义**，而非精确等式。  
硬速度包络仍以 [`BASELINE_JUMP_FALL.md`](../../../Dumps/runtime/BASELINE_JUMP_FALL.md) 为准（跳峰 +555 / 坠峰 −670）；本 log 空中样本偏飞天会话（Vy 仅见约 −120…+75），勿单独当跳坠全包络。

### 4.3 对工线含义

1. 不要 hook Flush「本地放行」——它本来就不拦。  
2. 飞天仍应 **构造自洽 Elem**（积分器 `pos += v·dt`）+ 贴基线/转向包络；目标是服端。  
3. 验收：`kick.log` / 断线边沿；离线数学用 `fly_integrator_check.exe`。  
4. 下一工程门：实机 F6 踢边沿对照（kick_sniff），不是再抠 Flush 拒包。
