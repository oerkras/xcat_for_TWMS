# worldmap_marker_travel Feature 模块设计（Classic TWMS）

> **状态**：✅ 已挂入 · 进图后 Spot 双击 → 预检 → YesNo / Notice → `travel::RequestGoto`（BIN 已过）  
> **产品**：新枫之谷：经典版（TW · `Maplestory_Classic.exe`）· **不是**枫星  
> **源码**：`x/features/worldmap_marker_travel/`  
> **挂入**：`x/probe/xcat_probe.cpp`（`travel::Init` 之后 Init；detach 先 Shutdown）  
> **对照枫星**：`worldmap_marker_travel`（Lua `OpenTextConfirm`）——**仅产品语义对照**；经典版走 Il2Cpp MethodInfo 换桩  
> **明确非目标**：瞬移石 `UIMapTransferDialog` 逻辑、跨盘自动爬图、石头/非石头 rockMode（经典版 Spot 与瞬移石互不抢）

---

## 0. 一句话

世界地图 `UIWorldMapItem` Spot **自检双击** → 解析图号 → 同盘可达预检 → 游戏内 YesNo（可达）或 Notice（不可达/已在目标）→ 确认后先 `UIWorldMap.Close()` 再 `travel::RequestGoto`（关失败不阻断赶路）。

---

## 1. 与枫星差异

| | 枫星 | 经典版 TWMS |
|---|---|---|
| UI 脚本 | Lua Spot / `TextConfirmManager` | Il2Cpp `UIWorldMapItem` |
| 双击 | 原生/脚本事件 | **无** `OnDoubleClick` → Hook `OnPointerDown` 自检 ~200ms |
| 确认框 | `OpenTextConfirm` | `UIUtilDialog.YesNo` + 常驻原生 `System.Action` |
| 不可达 | 脚本侧提示 | `UIUtilDialog.Notice` + `PathHopCount` 预检 |
| 瞬移石 | 可能与世界地图同壳，需 rockMode | 走 `UIMapTransferDialog`，**无需** rockMode |

---

## 2. 数据流

```
UIWorldMapItem.UpdateView (hook)
  → 写回字段后缓存 Spot{mapId, label}
UIWorldMapItem.OnPointerDown (hook)
  → 同 self ~200ms 内第二次按下 = 双击
  → FireGotoFromItem
       → 图号：UpdateView.mapId → MapNo[0] → map_names 反查（禁简介原文 goto）
       → PathHopCount(cur, dst)
            hops < 0  → Notice 不可达
            hops == 0 → Notice 已在目标
            hops > 0  → YesNo（文案含「预计 N 跳」）
       → Yes → Close 世界地图 → travel::RequestGoto(图号字符串)
```

面板赶路目录双击仍走原有 UI 路径，与本模块并行、不互斥。

## 3. 逆向锚点（当前 GA）

### 3.1 类与 MethodInfo RVA

| 项 | 值 | 铁证 |
|---|---|---|
| Spot 类哈希名 | `acd4f503…084161`（`UIWorldMapItem`） | script.json / restore |
| `UpdateView` | RVA **`0x7E2140`** | MethodInfo 换桩 |
| `OnPointerDown` | RVA **`0x7E4B20`** | 双击自检 |
| `UIUtilDialog` 哈希 | `be10cb…8251a` | |
| `YesNo` | RVA **`0x7454B0`** | `UITabFriend_OnDelete` / `UIMapTransferDialog_OnDelete` xref |
| `Notice` | RVA **`0x749420`** | `(string, string sub, bool×3, Action ok)` |
| **勿用** | `0x77E620` | `(string, int, Action<bool>)`，不是双 Action YesNo |

### 3.2 `UpdateView` 字段写回（IDA 实锤）

相对 cms dump 的 `_mapDesc@0x68 / _mapName@0x70` **已偏移**。当前 GA：

| 偏移 | 内容 | 来源寄存器 |
|------|------|------------|
| `+0x70` | **简介** mapDesc | r9 |
| `+0x78` | **地图名** mapName | r8 |
| `+0x80` | streetName | rdx |
| `+0x88` | arg_30（int，勿盲目当图号） | — |

`WorldMapData.MapListData`：`MapNo List<int>@0x20`，`Title@0x28`，`Desc@0x30`。

### 3.3 目标解析优先级

1. `UpdateView` 的 `mapId` 参数  
2. `MapListData.MapNo[0]`  
3. 缓存 label / 字段名 / Title（**拒绝**像简介的长句：含 `。`/`，` 或过长）  
4. 简介经 `common/xcat_map_names`（`keyByDesc`）反查图号  
5. **禁止**把简介原文直接 `RequestGoto`（BIN：`goto unresolved '位於…'`）

已有图号 / 能解析名字的 Spot（弓箭手村、龍族之地等）**只走 1–4**，一字不改。

### 3.4 空 Spot 兜底（不破坏原业务）

迷霧森林「冰冷的搖籃」这类点：`UIWorldMapItem` 运行时 `mapId=0` 且没有名字（底图文字 / 标题点是另一类 widget）。**仅当上面全部失败**才追加：

| 顺序 | 做法 | 安全阀 |
|---|---|---|
| A | `MapNamesResolveExact`（图号 / 短名精确 / 简介精确） | **禁止子串** |
| B | `self+0x88` 当世界地图条目下标，对 `WorldMap.List<LabelData>` 的 idx 字段匹配标题再 Exact | `0x88` **禁止**当图号，除非 `MapNamesHasId`（index `31` 不会进表） |
| C | `PointerEventData` 悬停栈对已缓存标题点 GO | 多个不同图号 → **拒绝猜测** |
| D | 标题点 `OnPointerClick` 双击（单击仍走原生） | 钩子装不上只打日志，**不卸**主世界地图功能 |

标题点 `Bind` 是 GameAssembly `.text` 直调，本模块禁止改 `.text`，故用 `UIWorldMap.OnEnable` 记下界面指针，双击时再只读扫列表。

验收：双击「冰冷的搖籃」应见 `empty-spot resolve via=wm-index-unique mapId=105090311`（或 `hovered-unique` / 标题点双击），再走原确认框；旁边「龍族之地」日志仍是 `确认框 [105090310]`。

## 4. Action / 对话框实现要点

- `il2cpp_object_new(System.Action)` + 写 `Delegate.method_ptr / invoke_impl / extra_arg / method_code`  
- `il2cpp_gchandle_new` 钉住常驻 Yes/No/Ok Action  
- `__try` 与 C++ RAII **分函数**（避免 MSVC C2712）  
- 同目标 ~300ms 防连点重开确认框；Yes/No 清 pending  

失败降级：YesNo/Action 未就绪 → 日志 + **直通** `RequestGoto`（保底可赶路）。直通与 Yes 一样先 `Close` 世界地图。

确认后关图：只解析并直调基类 `Close()`（**不换桩**）。`gWorldMapUi` 来自 `OnEnable`；指针空 / Close 失败只打日志，仍 `RequestGoto`。托管调用在 Unity 主泵上；Yes 回调已在泵上则直调，避免 `InvokeAndWait` 嵌套死锁。BIN：世界地图开着时 StickUp 的 ↑ 会被吞 → 首跳三次 `HoldUntil timeout until=0` 后假火；关图后再贴门应一次 `until_drain until=1` / `MAP_CHANGED`。

| # | 场景 | 期望日志 / 行为 | 本轮 |
