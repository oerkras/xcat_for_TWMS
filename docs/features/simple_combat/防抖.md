## 0. 一句话

锁怪到位后：**钉住站位 Y**（吃皮抖）+ **X 每拍跟 ideal**（跟怪横移）+ **旋翼两轴软悬停**（16ms 加密配平，把残差往 sp 收）。  
关「防抖」= 钉点与软悬停**同时**旁路，回到每拍跟 ideal + 90ms / 进近 ±12 死区。

**禁止**：用 `Mode::Hold` 当战斗钉点（BIN 误用 Hold → 丢掉 FullFire 进站预刹 → `lean_local` 掉线）。  
**禁止**：AbsPos 硬写消抖（只允许 `ImpactSetVelocity` / SetImpactNext）。

## 1. 要解决什么

| 现象 | 真源（BIN） | 不是 |
|---|---|---|
| 锁怪悬停上下微晃 | 角色侧：90ms 冲量 vs 30ms 重力锯齿；进近死区 ±12 把残差冻在进入点 | 「怪皮 Y 在抖」（多数样本怪心 Y 恒定） |
| 勾选防抖「好像没关」 | 曾只关 B 钉点、A 软钉仍开 | IPC 没通（日志其实有 `SetAntiJitterEnabled 0/1`） |
| X 不跟怪 | B 把 X/Y **一起**冻在 stick → A 软钉粘在旧 `sp.x` | 软钉 Kp 太小 |

AbsPos：**更大 Y = 更高**（见仓库规则 `abspos-y-axis`）。

## 2. 两层机制（必须同开同关）

```text
面板「防抖」/ ini simpleCombatAntiJitter
        │
        ▼
SetAntiJitterEnabled(on)
        ├─ gAntiJitterEnabled          → B：PublishHeliSetpoint 钉点
        └─ heli::SetSoftSettleEnabled  → A：settle 窗软钉 + 16ms 节奏
```

关任一端单独留另一端，都会出现「开关体感失灵」或「X 冻死」。

### 2.1 B 层 · 站位钉点（`simple_combat.cpp`）

到位（`HeliReachOk`）且防抖开：

| 轴 | 行为 |
|---|---|
| **Y** | 怪心 Y **稳定**（`|Δ|≤0.75`）才钉 `gStationStickY`；蠕动/起跳立刻 `sp.y=idealY` |
| **X** | **不钉**，每拍 `sp.x = idealX`（跟横移） |
| 模式 | 必须 `Station`（保留 FullFire 死拍 / 进站预刹） |
| 边界 | ideal 先经 `ClampToCombatMoveBounds`（raw×0.95）；贴边怪照打 |

破钉/重锁：换锁、出带、怪心 `|ΔmobY|>2`、或 idealY 离开 stick 带（4px）→ 重新锁到当前 ideal。  
（旧破钉 6px 会在起跳前几帧把人冻在旧高 → BIN 体感「慢一拍」。）

关防抖：立刻清 stick，每拍跟 ideal。

### 2.2 A 层 · 到位软悬停（`heli_rotor.cpp`）

仅当 `SoftSettleEnabled` ∧ 悬空 ∧ (`Station`|`Hold`) ∧ `|errX|≤16` ∧ `|errY|≤16`：

| 项 | 值 | 说明 |
|---|---|---|
| 节奏 | `kIssueSettleMs=16` | 进近/赶路仍 90；可在一步重力中途再纠 |
| 死区 | X/Y 各 `1px` | 不用进近 `kDeadX/Y=12`（会冻残差） |
| P | `kKpXSettle = kKpYSettle = 10` | 限幅 ±160，禁止满火力 `/T` 死拍 |
| 配平 | `GravityLoss(真实 since)` | **禁止**把 since 抬到 30ms 地板 |

`GravityLoss` 曾 `since < 30 → 30`：settle 16ms 时每拍仍按满步配平 → 多配约 +30px/s → 软 P 用 `ey≈−5` 顶回去（BIN 02:11）。已改为真实耗时（下限 1ms）。

满火力：settle 窗内 **两轴**都不走 deadbeat / 进站预刹的「死区外 `/T`」分支（几 px 会被放大成泵）。

## 4. BIN 验收口径（`combat.log`）

看 `heli mode=station` 且 `|pos−sp|` 两轴都 ≤16 的 fired 行：

| 指标 | 防抖开（稳态）期望 | 备注 |
|---|---|---|
| `since` 中位 | ~16–20 | settle 加密 |
| `trim` 中位 | ~`2·since` 量级（如 34@17ms） | 不应恒=60（旧 30ms 地板） |
| `|ey|` 中位 | ~1–2 | Y 钉 + 软钉 |
| `|ex|` 中位 | 静止 ~1–2；跟移可到 ~6 | X 跟 ideal 时有跟踪滞后属正常 |
| `heli mode=hold` | 战斗锁怪期应为 **0** | 误用 Hold 是掉线征兆 |
| `SetAntiJitterEnabled 0` 后 | `since` 回到 ~90；残差可回到进近死区量级 | 开关应肉眼可辨 |

X 跟怪：连续 fired 中 `sp.x` 移动（`|Δ|≥3`）时，`pos.x` 应同向追，滞后中位个位数 px（BIN 02:34：20/20 chase）。

断线：`Dumps/runtime/kick.log` 不应在纯挂机贴怪时出现 `Disconnected` / `sawDisc=1`（误用 Hold 时代曾密集出现）。

## 5. 历史坑（勿回归）

| 坑 | 后果 | 正解 |
|---|---|---|
| 到位改 `Mode::Hold` | 丢掉 FullFire 预刹 → 过冲出界 → `lean_local` | 始终 `Station` |
| 只关钉点、软钉常开 | ImGui「勾不勾都几乎不抖」 | SoftSettle 与防抖同开同关 |
| XY 一起冻 stick | X 不跟怪横移 | **只钉 Y**；X=`idealX` |
| 破钉等 `|ΔmobY|>6` | 起跳前几帧人仍钉旧高（慢一拍） | 蠕动 `>0.75` 即跟 ideal；`>2` 重锁 |
| `GravityLoss` 地板 30ms | settle 稳态 `ey≈−5/vy≈−30` | 按真实 since |
| settle 仍走 X 进近死区 12 / 满火力死拍 | `|ex|` 中位钉在 ~11 | settle 用 1px+Kp10；禁死拍 |
| AbsPos 硬写消抖 | 瞬移体感 / 协议风险 | 只 Impact 冲量 |
