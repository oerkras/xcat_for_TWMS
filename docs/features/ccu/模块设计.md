# ccu Feature 模块设计（TWMS Classic）

> **状态**：✅ 已挂入；**只认 auto_enter 喂数**（无登录页被动 Probe）  
> **范围**：启动后 auto_enter 选频时，当前分区频道在线人数之和（本进程只记一次）  
> **源码根**：`x/features/ccu/`  
> **关联**：选频喂数见 [`../auto_enter/模块设计.md`](../auto_enter/模块设计.md)；本模块只存展示。

---

## 1. 职责边界

只负责 **分区频道在线人数** 落盘与面板展示。

| 做 | 不做 |
|---|---|
| 接收 `NotifyWorldChannelSnapshot`（auto_enter `PickLeast` 持有 `ci` 时累加） | 登录页 FindAll / 被动 Probe |
| 接收 `NotifyChannelFillTable`（每频 users/cap/adult）供 channel_hop 优先未满 | 换频/重进频道再采；进图刷表 |
| 首次有效喂数即 latch；之后只 heartbeat | 枫星 Lua / `ReqUnfilledChannelAsync` |
| 写精简 `PayloadStatus` SHM → 底栏 | |

未开自动进游戏 / 未走到选频 → 底栏保持 `--`（预期）。

---

## 2. 数据源（经典版真源 · 由 auto_enter 读）

| 项 | 偏移 / 标识 |
|---|---|
| `List<ChannelItem> ci` | `WorldItem+0x38`（PickLeast 已持有） |
| `nUserNo` / `nChannelID` / `bAdultChannel` | `+0x18` / `+0x1D` / `+0x1E` |

过滤：`id∈[1,64]`、跳过 adult；`users` 照加（可 `>cap`）。与选最少人通道的满员过滤无关。

同次另喂 **每频填表**（含成人/满员行）：`channel_hop` 用 `GetChannelPickHint` / `MarkChannelRejected`；不进底栏总和。

---

## 3. 数据流

```
auto_enter PickLeast ──NotifyWorldChannelSnapshot──→ CCU latch → SHM → status_bar
                    └─NotifyChannelFillTable────────→ 每频表 → channel_hop 选频
                              ↑
                    Ccu_Tick：仅 heartbeat（无 Probe）
```

- **禁止** E9 / CCU worker 线程 FindAll / 登录页被动采。  
- 约 10s heartbeat 刷新 `writeTickMs`。

---

## 4. API / IPC

- `ccu::Init` / `StartWorker` / `NotifyWorldChannelSnapshot` / `GetCcuStatus`
- `common/xcat_payload_status.h`：`worldChannelOnline`（`-1`=未采到）、`worldChannelCount`、`writeTickMs`
- SHM：`Local\XCatPayloadStatus_<hash(binDir)>`（binDir 尾斜杠已归一）

## 5. 日志

`XCat_data/logs/ccu.log` + `x.jsonl` tag=`CCU`：

| 键 | 说明 |
|---|---|
| `Init (feed-only: wait auto_enter PickLeast)` | 启动 |
| `waiting auto_enter feed…` | 尚未喂到 |
| `频道快照[auto_enter]: …` | 首次喂数 |
| `频道填表[auto_enter]: known=… prefer=…` | 每频未满表 |
| `latched once — feed-only…` | 已锁定 |
| `mark rejected idx=…` | channel_hop 满人拒收 |

---

## 6. 验收

1. 开自动进游戏并选到频道 → 一条 `频道快照[auto_enter]` + latch；底栏非 `--`。  
2. 不应出现 `频道快照[login]`。  
3. 再进频道页无新快照；进图数字靠 heartbeat；无 CCU 侧 FindAll/GC。

---

## 7. 风险

- 依赖 auto_enter 走到 `PickLeast`；手动登录不喂数 → 无 CCU。  
- 人数 = **选频当刻该分区**频道和，非全服、非实时。
