# ccu Feature 模块设计（TWMS Classic）

> **状态**：✅ 已挂入；登录频道页 **或** auto_enter 选频喂数  
> **范围**：当前所选分区频道在线人数之和（换分区以最后一次频道页为准）  
> **源码根**：`x/features/ccu/`  
> **关联**：读表/偏移防漂移在 [`../auto_enter/模块设计.md`](../auto_enter/模块设计.md)；本模块只存展示  

---

## 1. 职责边界

| 做 | 不做 |
|---|---|
| 接收 `NotifyWorldChannelSnapshot`（总和 + worldId） | CCU 内自建 FindAll / 独立字段哈希 |
| 接收 `NotifyChannelFillTable`（每频表 → channel_hop） | 枫星 Lua 刷表 |
| 同分区 latch；**换分区可覆盖**；软重连同区可刷新；PayloadStatus SHM → 底栏 | 进图后再扫其它分区 |

---

## 2. 数据来源（login / auto_enter）

| src | 何时 |
|---|---|
| `login` | **未开**自动进游戏：auto_enter idle 探到 `UILoginChannel` + `selectedWorld` 且 `ci` 就绪 |
| `auto_enter` | 开了自动进游戏、非 softFast：`PickOpenChannelId` 选频前（同区 latch） |
| `soft_login` | 软重连 `softFast`：同一拍选频，`allowRefresh` 覆盖同区总和与填表 |

过滤（总和）：`id∈[1,64]`、跳 adult；满员也计入。  
填表：含成人/满员行，供 `channel_hop`。

字段由 auto_enter `field_get_offset`（meta）解析：`WorldId` / `WorldChannels` / `nUserNo` / `nChannelID` / `bAdult` / `cap` 等。

---

## 3. 换分区策略

用户在登录界面来回点分区时：

1. 第一次进入某分区频道页 → latch 该分区人数。  
2. 退回世界列表再进**另一**分区频道页 → 覆盖为新区人数（`换分区 A→B` 日志）。  
3. 同分区重复停留（login idle / 冷启 auto_enter）→ **不**重复写。  
4. 软重连 `PickOpenChannelId`（`src=soft_login`）→ **同区可覆盖**，重置 `worldChannelAgeSec`；拒收标记保留。  
5. 最终停在 **1 分区**频道页 → 底栏 = **1 分区**频道和（不是先前误点的分区）。

换分区时清空 `channel_hop` 拒收标记（旧分区频道拒收对新区无意义）。同区软刷新保留拒收。

---

## 4. 数据流

```
手动停在频道页 ──idle──FeedCcuFromWorldItem("login")────────────────┐
冷启 PickOpen ─────────FeedCcuFromWorldItem("auto_enter")───────────┼→ latch/换区 → SHM → 底栏
软重连 PickOpen ───────FeedCcuFromWorldItem("soft_login", refresh)──┤
                                                                     └→ 填表 → channel_hop
```

- **禁止** E9 / CCU worker FindAll。  
- SHM 心跳由 PayloadStatus 发布线程续写。

## 6. 日志（`ccu.log`）

| 键 | 说明 |
|---|---|
| `Init (wait login channel UI or auto_enter feed; world switch updates)` | 启动 |
| `waiting channel snapshot (login UI or auto_enter)…` | 尚未 latch |
| `频道快照[login\|auto_enter\|soft_login]: … worldId=` | 首次或同逻辑采到 |
| `频道快照[soft_login]: 刷新 在线=… (was …)` | 软重连同区覆盖 |
| `频道快照[…]: 换分区 A→B …` | 用户换了分区 |
| `published — SHM via PayloadStatus publisher` | 已写入/换区更新（可再被换区覆盖） |
| `频道填表[…]: known=… prefer=… worldId=` | 每频表 |

## 7. 验收

1. **关**自动进游戏，手动选到分区频道页 → `频道快照[login]` + 底栏有人数。  
2. **开**自动进游戏 → `频道快照[auto_enter]`（或 login 抢先）+ 进游戏正常。  
3. 同分区 login idle / 冷启 auto_enter 不应重复刷写；**换分区**应出现 `换分区` 日志且底栏变为新区人数。  
4. 软重连过频道页 → `频道快照[soft_login]: 刷新`，底栏年龄归零。  
5. 来回切后最终停在 1 分区 → 底栏为 1 分区人数。

---

## 8. 风险

- 人数 = **当时所选分区**频道和，非全服。  
- 未进入频道页（仅世界列表）→ 仍无 CCU（预期）。  
- 若 `worldId` 读失败为 0：首次可写，已有快照后 Feed 直接跳过（`allowRefresh` 也跳过）。  
- login idle 间隔约 4s：换分区后底栏最多延迟约一个 idle 周期。  
- 软刷新读的是当时频道页 `nUserNo`，不是单独向登录服要 CCU；resume 直进 `PickChannel` 时表可能尚未被服端重灌，`ageSec` 仍会归零。
