## 0. 一句话目标

在游戏 `UnityWndClass` 主窗标题展示实时角色数据，并统计滑动窗口内的金/分、经/分、物值/分。  
不依赖前台焦点；最小化仍可用。标题写入用 `SendMessageTimeoutW(SMTO_ABORTIFHUNG)`。

## 1. 与枫星差异（必须读）

| 项 | 枫星 | TWMS |
|---|---|---|
| 读数路径 | IL2CPP `ui::player` + Lua StatusBar 兜底 | **纯 IL2CPP 字段读**（无 Lua） |
| 主锚点 | Character / CharacterStatSimulator | **`WorldManager.CharacterData.CharacterStat`**（共享 `x::ui::player`） |
| 本地角色 | LocalPlayer | **`WM.MyUser` / GO 名 `MyUser`**（禁止 User FindAll first-hit） |
| 职业名 | Lua `_JobStringDataSet` / 本地化 | **Classic 静态繁中表**（job id → 名） |
| 怪数 | `titlebar_mob` + EntityService | **`ports::mob` 缓存**：`n`=MobPool 活怪，`M`=LifeList(Mob)/峰值 |
| 物值/分 | loot 事件 drain + 背包快照 + `item_value.tsv` | **背包快照增量 × `ItemDataManager`（哈希 `cd80f688…`）卖价**（Dictionary **buckets hash**；进程内 `gPriceCache`；TSV 离线兜底） |
| 收益窗开关 | 绑定 simple_combat / autocombat + freeze | **进图有效 stats 即采样**（尚无打怪 FEATURE） |

## 3. 标题格式

约 **250ms** 读 vitals（`kUpdateIntervalMs`）；标题 `WM_SETTEXT` **最少间隔 300ms**（`kTitleWriteMinMs`，HP 抖动合并）：

```
Lv.N 名 职业:繁中名    HP a/b    MP c/d    EXP e/f    背包金 m    怪 n/M    +金/分…
```

- **怪 n/M**：读 `mob_scan` 后台缓存（`ports::mob::GetCached*`）——`n`=MobPool 活怪，`M`=`MapData.LifeList` 中 `Type==Mob`（失败回退本图峰值）；仅有 `n` 时显示 `怪 n`  
  - **`n ≪ M` 常见且正确**（官方刷怪容量/tick，非漏统计）→ 详见 [`mob_pool/活怪n与刷怪槽M.md`](../mob_pool/活怪n与刷怪槽M.md)
- **WM / 地图态不进游戏标题**：改由 **ImGui 顶栏 MAP 灯**（`PayloadStatus` v4）  
  - 灯亮 = 显式 `playReady`（`IsPlayReady`）  
  - tip：`WM:就緒/待綁` + 场景短标（`登入/切圖/地圖/…`）+ `街道名·地图名`（`common/xcat_map_names` ← `map_names.tsv`）  
  - 离图 / 无 vitals：`RestoreOrigTitleText` 还原进图前原文  
  - 关 titlebar / Shutdown / StopWorker 仍 `RestoreTitle`
- 未满 3s：`收益採樣 Xs/3s`。未知 job id 回退数字。大数用繁中 `萬/億` 缩写。

## 4. 每分钟收益（精简）

- 环形样本 `gRing[64]`（~63s），样本含 `lootCum`
- `dtMs ≥ 3000` 才出金/分、经/分、物值/分
- 升级：用 `lastMaxExp` 跨级累加经验差
- **开窗条件**：`level≥1 && mhp>0 && maxExp>0`（不要求 meso>0）
- **物值**：开窗先打背包基线（不计收益）；之后每拍快照 TI∈{2,3,4}，数量增量 × 卖价累加 `gLootValueCum`
  - 数量：`ItemSlotBundle+0x28`（ushort；基类 ItemSlot 无此字段）
  - 卖价：`ItemBundle.nSellPrice@+0x38` → 否则 `Info.price@+0x54`（`notSale@+0x68≠0` 跳过）
  - `ItemDataManager` 类哈希 `cd80f688…`（08-03；勿再用明文名）
  - 查表：`DictGetIntPtr` 走 `buckets` 链（`hash&0x7FFFFFFF`）；无 buckets 才线性兜底；命中后写入 `gPriceCache`
  - 无价物品计入 `unknown` 日志计数，不进物值；运行时未绑上时回退 `item_catalog` / TSV
  - **局限**：无 loot 事件，靠背包差分；仓库/交易/丢弃导致的数量变化也会进差分（与枫星事件路径有差距）；装备栏不扫
- 尚无 combat：不实现 freeze / F5 toggle；换图读到空壳则 `rate stop`

## 4.1 Rebind 与回大厅（性能）

| 状态 | FindAll | 说明 |
|---|---|---|
| 未绑 / 读数失败 | **3s**（`kRebindMissMs`） | 尽快进图探测 |
| 有 vitals 且 **WM 仍存活** | **跳过 FindAll** | 只读指针校验；最多 **30s** 轻量刷新 `WM.MyUser` / IDM |
| 有 vitals 但 WM 失效 | 最多 **30s**（`kRebindOkMs`）再 FindAll | `TryResolveWorldManager` 先 `WorldManagerAlive()`，存活直接 return |

回大厅 / vitals 变空壳：`OnLeavePlay` → `rate stop (…)`，**恢复进图前原标题**。
