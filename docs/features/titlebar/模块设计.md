# titlebar Feature 模块设计（Classic TWMS）

> **状态**：✅ 已接入 `xcat.dll`（默认开启）。
> **源码根**：`x/features/titlebar/titlebar.{h,cpp}`
> **对照**：枫星 `xcat_for_fengxing/x/features/titlebar/` + `docs/features/titlebar/模块设计.md`
> **数据真源**：`DumpRestoredData/dump.cs.restored.B`（锚点）+ `Dumps/runtime/out/dump.cs`（类哈希）

---

## 0. 一句话目标

在游戏 `UnityWndClass` 主窗标题展示实时角色数据，并统计滑动窗口内的金/分、经/分。  
不依赖前台焦点；最小化仍可用。标题写入用 `SendMessageTimeoutW(SMTO_ABORTIFHUNG)`。

---

## 1. 与枫星差异（必须读）

| 项 | 枫星 | TWMS |
|---|---|---|
| 读数路径 | IL2CPP `ui::player` + Lua StatusBar 兜底 | **纯 IL2CPP 字段读**（无 Lua） |
| 主锚点 | Character / CharacterStatSimulator | **`UIStatusBar` → CharacterStat / BasicStat** |
| 怪数 | `titlebar_mob` + EntityService | **未移植**（无 MobScan） |
| 物值/分 | loot 事件 drain + 背包快照 | **未移植**（无 autopickup/item_value） |
| 收益窗开关 | 绑定 simple_combat / autocombat + freeze | **进图有效 stats 即采样**（尚无打怪 FEATURE） |

## 3. 标题格式

约 1s 刷新（`kUpdateIntervalMs`）：

```
Lv.N 名  职业:J    HP a/b    MP c/d    EXP e/f    背包金 m    +金/分    +经/分
```

未满 3s：`收益采样 Xs/3s`。

---

## 4. 每分钟收益（精简）

- 环形样本 `gRing[64]`（~63s）
- `dtMs ≥ 3000` 才出金/分、经/分
- 升级：用 `lastMaxExp` 跨级累加经验差
- **开窗条件**：`level≥1 && mhp>0 && maxExp>0`（不要求 meso>0，避免穷号永远不开窗）
- 尚无 combat：不实现 freeze / F5 toggle；换图读到空壳则 `rate stop`
