# 日志系统（新枫之谷：经典版 / TWMS）

> **产品**：本仓 `xcat_for_TWMS` 只面向《新枫之谷：经典版》（TW · beanfun / Gamania Galaxy），**不是**《枫星》。  
> **对照**：实现与约定从 `xcat_for_fengxing`（枫星仓）的日志系统设计移植而来，路径/语义按经典版落地。

本仓由 `common/xcat_log` 提供统一 API，launcher / payload / inject / GUI 共用同一套约定。

## 目标

| 需求 | 方案 |
|------|------|
| 统一行格式 | 时间戳 + Level + Component + tag + message |
| 多进程写不同文件 | 按角色分文件，路径由 `paths::*` 集中定义 |
| GUI 实时 + 历史 | `SetLineCallback` 推送；面板亦可 `ReadLogTail` |
| 调试可见 | 默认 `OutputDebugStringA` 同步输出 |
| 线程安全 | 全局 mutex 保护写文件与 callback |

## 文件布局

```
bin/
  logs/
    launcher.jsonl  # xcat.exe / GUI 编排
    inject.jsonl    # Classic LoadLibrary 注入 trace（RegisterAuxFile）
  launcher.log      # WebView 换票文本（兼容旧路径，非 JSONL）
  XCat_data/
    logs/
      x.jsonl       # xcat.dll 载荷运行时（唯一主落盘）
```

路径 API（`xcat::log::paths`）：

- `LauncherLog(exeBinDir)` → `{bin}/logs/launcher.jsonl`
- `PayloadLog(payloadBinDir)` → `{XCat_data}/logs/x.jsonl`（DLL 所在目录）
- `InjectLog(exeBinDir)` → `{bin}/logs/inject.jsonl`
- `Jsonl(path)` / `TextLog(path)`：`.jsonl` ↔ `.log` 归一（上传捡旧文件）

> 与枫星一致：**不再双写** `.log` + `.jsonl`。磁盘主路径只留 JSONL；GUI 通过 `SetLineCallback` 收可读文本行。

## 行格式

```
YYYY-MM-DD HH:MM:SS.mmm [Level][Component][sessionTag?][tag] message
```

Level：`TRC` / `DBG` / `I` / `W` / `E` / `OK`。  
Component：`Launcher` | `Payload` | `Inject` | `App`。

落盘 JSONL：

```json
{"ts":"2026-07-31T23:40:00.412","lvl":"I","comp":"Payload","tag":"Bootstrap","msg":"..."}
```

## API（`common/xcat_log.h`）

```cpp
xcat::log::Options opts{};
opts.component = xcat::log::Component::Launcher;
opts.filePath = xcat::log::paths::LauncherLog(binDir);
opts.debugOutput = true;
xcat::log::Configure(opts);
xcat::log::RegisterAuxFile(xcat::log::Component::Inject,
                           xcat::log::paths::InjectLog(binDir));
xcat::log::BeginSession("xcat_twms");

xcat::log::Info("Run", "message %s", arg);
xcat::log::SetLineCallback(cb);
auto lines = xcat::log::ReadTailLines(path, maxLines, readBytes);
xcat::log::Shutdown();
```

## 各模块接入（本仓）

### xcat.exe（GUI）

1. `main.cpp`：`Configure(Launcher)` + `RegisterAuxFile(Inject)` + banner
2. `launch_panel`：`SetLineCallback` → `ui.logTail`
3. `log_tail.cpp`：`ReadLogTail` 薄封装
4. `log_upload`：收集 `launcher.jsonl` / `inject.jsonl` / `x.jsonl`（仍兼容旧 `app.jsonl`）

### injector/

- `inject_log.h`：`WriteAux(Component::Inject)` → `bin/logs/inject.jsonl`
- `inject_after_launch`：注入前 `RegisterFromDllPath`

### xcat.dll（`x/probe`）

- `x/runtime/log.cpp`：`LogInit` → `Configure(Payload)`，路径 `paths::PayloadLog(GetBinDir())`
- `DllMain` attach：`SetImageModule` → `LogInit` → feature workers
- detach：`LogShutdown`（不 join 工作线程）
- fly / invuln / kick_sniff 的本地 `*.log` 仍保留；同时镜像到 `x.jsonl`（tag=`Fly`/`Invuln`/`KickSniff`）

## 轮转

默认单文件 **2 MiB**、备份 **20**；payload `LogInit` 覆盖为 **512 KiB × 360**，与上传器整文件收取对齐。

## 与对照仓（枫星）差异

| | 对照仓 `xcat_for_fengxing`（枫星） | 本仓（经典版 / TWMS） |
|---|---|---|
| GUI 主路径 | `launcher.jsonl` | 同左（已从 `app.jsonl` 归一） |
| payload 入口 | `x/bootstrap` + 完整 runtime | `x/probe` + 精简 `runtime/{log,bin_dir}` |
| SehProbe | 有 | 暂未移植（按需后续） |
| WebView 换票日志 | 并入 launcher 编排 | 仍写 `bin/launcher.log` 文本 |
