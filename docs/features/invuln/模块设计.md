> **状态**：✅ 实机可用（v2.3 · 面板已接 · **无 INLINE HOOK**）  
> **源码根**：`x/features/invuln/` · IPC：`x/ipc/payload_control.*` · 契约：`common/xcat_payload_control.*`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）  
> **对照**：枫星 `xcat_for_fengxing/x/features/invuln/`（**Lua Mark，不可复用**）  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) §4.1 — **禁止 E9 / 改 `GameAssembly.dll` `.text`**。

## 职责

- 本地接触伤无敌（怪撞人 / `UserLocal.SetDamaged` 早退）
- 抑制硬直带来的人物闪烁（尽量）
- 面板勾选 + F10 热键 + `XCAT_INVULN=1` 环境变量
- **不**做 GA `.text` hook；**不**依赖枫星 Lua `InvincibilityMarkById`

## 与枫星差异（勿混）

| | 枫星 | TWMS Classic |
|---|---|---|
| 机制 | Lua `CharacterHitSimulator.InvincibilityMarkById` | 数据面写 `LocalUser` 字段 |
| Dump | Unity+Lua | Il2Cpp `SecondaryStat` / `UserLocal.SetDamaged` |
| 复用 | — | **不能**搬枫星 Mark 路径 |

## 逆向结论（为何不是 SecondaryStat）

IDA（`Dumps/runtime/GameAssembly.dll`，MD5 `A26B0653…549E`）：

| 项 | 结论 |
|---|---|
| `UserLocal_SetDamaged` | `0x7FFB17B69260`（CFF）；体内对 `+0xEC` / `+0x2C4` **0 次读** |
| 真正早退门 | `User+0x298` = `m_tHitPeriodRemain`（cms 为 `0x280`，**TW 勿抄 cms**） |
| 极性 | 非 0 → 跳过受伤体（同受击硬直 i-frame） |
| `SecondaryStat n/r/tInvincible_` | `0xEC/F0/F4`；写得上，但**不挡接触伤** |
| `WorldManager+0xF0` | 真 SecondaryStat 对象（cms `+0xB8` 在 TW **错**） |
| `LocalUser.get_SecondaryStat` | stub `xor eax,eax; ret` → 恒 null，勿用 |

v1 只写 SS → 日志有 `n/r/t=1/1010/...`，实战仍掉血。  
v2 改写 `+0x298` → **实机无敌生效**；换图无需手动重绑。

## 实现（v2.3）

### 无敌

- 解析 `LocalUser`：**仅接受 GO 名 `MyUser`**（无 first-object fallback）
- 周期写 `m_tHitPeriodRemain = 5000`（约 **100ms** 补一次）
- 顺带写全部 `WorldManager` 的 SS Invincible/Dojang（效果/兼容；非挡伤主因）

### 绑定与 FindAll（v2.3）

与 fly 同纪律：worker 上 `FindObjectsOfTypeAll` 可能冻主线程。

| 状态 | 行为 |
|---|---|
| `LocalUserStillAlive` | 复用指针，**不** FindAll |
| 丢绑 / 换图 | 清空指针；最多每 **3s** 再 FindAll |
| 存活探测 | `klass` + `m_CachedPtr@+0x10` + 名=`MyUser` + `vis@0x64` 或 `CurPos@0x240` 非原点 |
| 写前 | 死指针直接 drop，禁止盲写 |

### 去闪

硬直期间 `User.Update` 递增 `_layerStateCounter@+0x2A8`，`(n&3) < 2` 时半透明（IDA 不透明比较常量解析为 **2**）。

- 约 **16ms** 钉 `+0x2A8 = 2`
- 偶发闪一下：与 Update 抢相位的残留，可接受
- **没有**独立「关闪烁」官方标志

### 热键

| 键 | 用途 |
|---|---|
| **F10** | 切换无敌（**仅游戏进程前台窗口**；并回写 `user.ini`） |
| **F9** | `xcat.exe` 面板最小化 — **勿占用** |
| F6/F7/F8 | 飞行 |

## 面板 / IPC

与枫星同思路，TWMS 精简版：

```
xcat.exe 勾选
  → WritePayloadControl(bin/XCat_data)
  → state/user.ini [core]
       invuln=0|1
       fly=0|1
       writeTickMs=<tick>
  → payload 约 200ms Poll
  → invuln::SetDesired / fly::SetDesired
```

| API | 作用 |
|---|---|
| `PayloadControl_Poll` | tick 变化时 Apply |
| `PayloadControl_PublishInvuln` | F10：SetDesired + 落盘 |
| `PayloadControl_PublishFly` | F6 后只落盘（运行时已 ArmFly） |

未注入时勾选仍落盘；进图注入后 Poll 吃到即生效。

## 接入 xcat.dll

`DllMain(ATTACH)`：`invuln::Init` + `StartWorker`（与 fly / kick_sniff 并列）。  
`DETACH`：只 `StopWorker`，**不 join**。

## 已知限制 / 风险

| 项 | 说明 |
|---|---|
| 服端灌血 | 本方案挡的是**本地** `SetDamaged`；若 S→C 强推 HP，需另案（锁 HP / 协议面） |
| FindAll | **仅丢绑后**限频重绑（v2.3）；仍有 Unity 主线程偶卡风险，与 fly 同类但远轻于「每 3s 必扫」 |
| SS 双写 | 非必需；保留作探测 |
| 其它首页勾选 | 自动进角/打怪等仍为 UI 占位 |
| `XCAT_INVULN=1` | 启动后若 `user.ini invuln=0`，约 200ms Poll 会关掉 |
