## 1. 职责与边界

| 做 | 不做 |
|---|---|
| 本地接触伤无敌（`UserLocal.SetDamaged` 早退） | 服端灌血 / 同步 HP |
| 硬直副作用去闪（钉 `_layerStateCounter`） | soft 写 `+0x228`（已封死） |
| 面板勾选 + `XCAT_INVULN=1` | 枫星 Lua `InvincibilityMarkById`；**无快捷键** |
| 数据面写字段 + MainPump MethodInfo 帧回调 | GA `.text` hook |

## 2. 实现总览（v2.6.3 真源）

```text
面板 / env
    → desired (atomic)
         ├─ worker ~100ms  WriteI32(LocalUser+0x298, 5000)   ← SetDamaged 早退（挡伤）
         ├─ MainPump 帧    WriteU32(LocalUser+0x2A8, 2)      ← SendWill/Update orig 前+后
         └─ worker 8ms     WriteU32(LocalUser+0x2A8, 2)      ← 补钉，防 Update 竞态
SecondaryStat n/r/tInvincible_ 仍双写（表现/后路）；SetDamaged 不读，不挡伤
soft +0x228/+0x22C 永不写
```

**闪的来源**：`hitPeriod>0` 时游戏 Update `++(+0x2A8)`，`(n&3)<2` 半透明。  
**去闪**：保持 `(n&3)>=2`（钉 `2`，再 `++` 成 `3` 仍不透明）。

## 4. 绑定纪律

- LocalUser：GO 名 **仅 `MyUser`**（与 fly 同）；FindAll 经 MainPump  
- **FindAll 闸**：仅 `IsPlayReady`（Field）；`InterStage` / `Login` / **`CashShop` / `GlobalMarket`** 一律禁扫（v2.6.6；BIN D217 拍卖卡顿根因）  
- **裸 `gFindAll` 加硬**：泵内另检 `IsLoginFrozen` + `IsMapTransitBlocked`（绕过 `managed_main::FindAll` 包装时仍守仓级契约）  
- 登录冻：`IsLoginFrozen()` 时跳过解析  
- StillAlive：klass / CachedPtr / 坐标；**ACCEPT 后 `kBindGraceMs=1500` 内**容忍 `(0,0)` / `cached=0`（防进图假死）  
- 丢绑后 `kRebindMs=400` 重绑（原 3000 在换频时空窗过大）  
- **LU 与 SS 分拆清理**：`ClearLocalUser` 不碰 SecondaryStat；换图 `REJECT (no MyUser)` 只丢 LU  
- 换图常见：`REJECT (no MyUser)` → 进图后再 ACCEPT → grace 内立刻写 hit

## 5. 逆向结论（摘要）

Dump：`Dumps/runtime/GameAssembly.dll`（2026-08-03 · MD5 `B87DB932…55164` · base `0x7FFB74A20000`）。

| 项 | 结论 |
|---|---|
| `UserLocal` | 真类哈希 **`ac2e48cc…`**（`: User a03443…`）；勿用 `a6c2`/`fad8` UI 壳 |
| 字段 | **`m_tHitPeriodRemain@0x298`** / **`_layerStateCounter@0x2A8`** / `CurPos@0x240` / soft `0x228\|0x22C` — 相对 07-30 **未漂** |
| `WM+0xF0` | SecondaryStat 类型 **`e9c12ac2…`**（仍双写 n/r/t@`0xEC/F0/F4`；不挡伤） |
| Unity | `FindObjectsOfTypeAll` 等走 `il2cpp_bind`（`0x4E3FA20` 等，已 08-03 remount） |
| `SetDamaged` | 数据面只依赖字段偏移；旧 VA `0x7FFB17B69260` **作废**（ASLR/重编） |

CMS→TW（+0x18）：`m_tHitPeriodRemain 0x280→0x298`，`_layerStateCounter 0x290→0x2A8`，`CurPos 0x228→0x240`，`TimeEndBoomerangStep 0x210→0x228`。

版本线：v1 SS → v2 hit 闪 → v2.5 soft 翻车 → v2.5.1 仅 hit → v2.6 帧钉 → v2.6.2 帧钉+8ms → v2.6.3 换频重绑 → **2026-08-03 客户端更新：字段未漂，类哈希/Unity RVA 已对齐**。

```text
xcat.exe 勾选
  → WritePayloadControl → state/user.ini [core] invuln=
```

## 7. 生命周期

| 时机 | 动作 |

| `DllMain` ATTACH | `Init` + `StartWorker` |

## 8. 已知限制

| 项 | 说明 |
|---|---|
| 服端灌血 | 只挡本地 `SetDamaged` |
| soft | 永久禁用（勿再写 228/22C） |
| `SetFrameTick` | 全局单槽；目前仅 invuln |
| 跨线程 `gLocalUser` | 帧钉裸写 + SEH；低风险 |
| 毒伤 / 长挂机 | 可选再验（非收工门禁） |
| 换频瞬间无 MyUser | 仍有 ≤~400ms 空窗（FindAll 本身无对象）；已尽量收紧 |
