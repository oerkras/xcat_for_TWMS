---

## 1. 产品语义

开着时：人物卡（`UIUserInfo`）上的**交易按钮**不再被「角色等级 < 15」灰掉。

关着时：还原官方 15 级门。

| 项 | 内容 |
|---|---|
| 入口 | 实验 TAB「强制交易（实验）」；`[core] forceTrade`；**默认关** |
| 范围 | **仅客户端**人物卡交易按钮 |
| 非目标 | 右键菜单交易、丢物 15 级门、服务端放行 |
| 关功能 | restore 原 seed；worker 停 / `Shutdown` 同样 restore |

客户端放开 ≠ 服务器放行。15 级以下点交易后仍可能被拒包 / 弹窗。

---

## 2. 根因（IDA）

`UIUserInfo` 私有刷新（TypeDef 596，方法 hash `c73415a2…de7a9d`，RVA `0x766C30`）：

```
movzx eax, byte [rax+38h]      ; CharacterStat.level
mov   ecx, imm32               ; 0820：0xFD6E2A97
add   ecx, [rip+disp]          ; seed 仅 1 处 xref
cmp   eax, ecx                 ; imm+*seed == 15
cmovge rcx, rax                ; signed：level >= 15 走放行
```

同函数另有 4 处 `mov ecx,imm; add ecx,[rip]`（解出 0/2/3），后面是 CFF `jmp qword`，**禁止误写**。Shape 要求 add 后紧跟 `cmp eax,ecx`（`39 C8` / `3B C1`）。

`DragManager.CanPerformAction` / `OnDropItem` **不读等级**，不是这道新门。

---

## 3. 现行实现

1. Shape 扫刷新方法体（~0x2AF0）：`B9 imm ; 03 0D disp ; cmp eax,ecx`，且体内有 `movzx r32, byte [r64+0x38]`
2. `global = fn + movAt + 11 + disp32`（运行时解析，不死钉 `.data` RVA）
3. 首次武装：`imm+*global` 必须解出 **15**，否则拒写
4. 功能开：`*global = (0 - imm)` → 解出 0 → `level >= 0` 恒真
5. 功能关：restore 为官方 `(15 - imm)` / 首次读到的 orig
6. Worker 开时 1s 扫一次；被回写则再 arm

不匹配 → **拒绝写** + 灯 `ForceTrade=MISS`。
