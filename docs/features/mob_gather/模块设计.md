## 0. 一句话

吸怪 = **只对这台客户端正在模拟的非固定怪，统一卸台，用 F5 空中贴怪那套 P 控（`SetImpactNext` 加冲量）把它们吸到角色朝向面前的站距空点并悬停，方便打**。不贴台。武装期跳过 `VecCtrlMob` 的 Stop/Move/Jump/Fly AI，基类物理（含 `ApplyImpact`）照跑。

**默认站立吸怪不接 `heli_rotor` 单例。** TAB「先飞到最密堆再吸」勾上后，人才用 `Owner::Gather` 飞到簇质心再 Arm。「软重连后返回原位」同样用人侧飞回记录点，与寻簇互斥。

不是天空隔离，也不防旁边的人 AoE。文案必须写「吸怪方便打」，**禁止**写成「防抢」。

## 1. 为什么必须新模块（禁止掺进现网）

`map_attack` 已否决「改 mob 坐标」。本功能是**另一条实验线**：走官方击退物理，不写 `Ap`，不造 MobMove 包。

现网位移 / 出刀已经各管各的，吸怪再塞进去会把语义绞死：

| 现网 | 职责 | 吸怪若掺进去 |
|---|---|---|
| `fly.cpp` / `heli_rotor` | 玩家 F6 / F5 旋翼 | `heli_rotor` 是单例，不能推 N 只怪 |
| `fly_fh_ban` | 只拦 **LocalUser** klass 挂台 | 改 `VecCtrlMob` 虚表 = 全图怪一起禁挂 |
| `simple_combat` Firing / 选怪 | 出刀状态机 | 改 Firing = 破坏打怪 |
| `teleport_port` `ImpactImpulseToward` / `FireImpactNockBackTest` | **玩家** VecCtrl + 无敌门 | 玩家飞控的 invuln 门与本功能无关 |

**硬规则**：落地时不得改 `fly.cpp` / `simple_combat.cpp` 的 Firing / 选怪 / `teleport_port.cpp` 的**玩家** Impact 路径。`SetImpactNextOnVc` 是怪侧专用入口（任意 `VecCtrl`，无无敌门），不改玩家 `ImpactSetVelocity`。不把 `heli_rotor` 单例接到**怪**上。

例外（TAB「先飞到最密堆再吸」或「软重连后返回原位」，**均默认关、互斥**）：人侧用 `heli::Owner::Gather` + `fly_fh_ban::BanSource::Gather`。F6 / 赶路占旋翼时让路；可从 Combat 抢。两勾都关必须与加闸前的站立吸怪一致。

不造 opcode 207 MobMove 包。跨层卸台只拦**白名单实例**的 CD/CDF。

## 2. 已否决（写进方案，避免下轮再提）

| 想法 | 否决理由 |
|---|---|
| 硬写 `VecCtrl.Ap` 把怪藏天上 | 别人打的是服端广播的 MobMove，不是你内存坐标；踩 `m_bABHackCheckNeed` / `m_bFloatHackCheckNeed` |
| 改 `VecCtrlMob` 虚表禁挂台 | `fly_fh_ban` 只过滤 LocalUser；Mob klass 一改全图怪一起禁挂 |

| 塞进 F5/F6 / 赶路 | 玩家飞控与怪物理不是同一条产品线 |

## 3. 真源（IDA / DUMP · 已采）

当前 IDB：`Dumps/runtime/GameAssembly.dll.i64`（本轮 imagebase `0x7FFD72820000`，RVA 随 remount 核）。

```
VecCtrlMob.WorkUpdateActive   RVA 0x11DF260  Slot 11
  先跑 CtrlUpdateActive Stop/Move/Jump/Fly（WUA 内 E8，MI 换指针拦不住）
  尾部 E8 基类 WUA
VecCtrl.WorkUpdateActive      RVA 0x11C5510  Slot 11
  call ApplyImpact            RVA 0x11C5DD0
NockBack(dir, vx, vy)         RVA 0x11D6160   基类叶子，this 可以是怪的 VecCtrl
SetImpactNext                 RVA 0x11C2950
```

Mob WUA 会先跑 Stop/Move/Jump/Fly AI，**再**进基类物理。只打一发水平 `NockBack` 会被 AI + CDF 拉回挂台。持有期：**禁白名单实例重挂** + **Slot 11 武装时改调基类 WUA**（跳过 AI，保留 `ApplyImpact`）+ **每拍 `SetImpactNext`**（`VxCommandFor` 把绝对速度翻成加冲量）。`CtrlUpdate*` 另做 MethodInfo 换指针，防非 E8 调用；E8 路径以 Slot 11 为准。

控制器：`Mob.MobCtrlState@0xE8`（`MobLite.ctrl`）。CMS `MobCtrlType`：`>0` Active（你跑 AI 并上报 MobMove）/ `<0` Passive（别人控，本地 `UpdatePassive` 跟包）。公开图 BIN 经常 **全员 `-1`**，但朋友仍能看到「你在模拟」的怪掉落——权威代理改用 **本地 VecCtrl 是否在跑**：`vcAct@0x80 ≠ 0` 且 `Ap` 不是原点。`Ap=(0,0)` / `vcAct=0` 当远端影子，不卸台、不推。

控权由**服端**派 `MobChangeController`（CMS opcode 280）：`flag==0` → `SetRemoteMob`（`SetActive(false)`）；`flag≠0` → `SetLocalMob`（可 `SetActive(true)` + Chase）。客户端可发 `MobApplyCtrl`（CMS 206，TW 出站 +2 ≈ 208）申请，**不能**靠改 `0xE8` 抢权。细节见 [`../mob_pool/P0a_OnLocalMob与Init包体.md`](../mob_pool/P0a_OnLocalMob与Init包体.md)。

TAB 选项 **申请控制权**（`mobGatherApplyCtrl`，默认关）：吸怪持有期每秒对半径内 `ctrl≤0` 的怪，泵上调官方 `Mob.ApplyControl(tCur)`。**补刷 oid**（`gate` 开后新见到的、非 exempt）即使没勾也会走同一条申请，不挡 Arm。不钩 `calc_priority`、不造包、不写 `0xE8`。dump 把 `ApplyControl` 标在 RVA `0xF57320`（16 字节 stub）是错的；运行时顺序是 hash/明文名 → 谁 E8 了 `calc_priority` → 谁 E8 了 `CanApplyCtrl` → `OnFixedUpdate` 的 E8 目标。禁止 `void(int)` Kind 非唯一兜底，**禁止 any4_xref**（BIN 曾落到 `0xF68560` 全 SEH）。候选必须实际 E8 `calc_priority` 或 `CanApplyCtrl`。勾上后 BIN 应见 `via=priority_xref` / `canapply_xref` / `onfixed_xref`（或 hash/plain），`seh=0`，不是 `0xF57320` / `0xF19A10` / `any4_xref`。补刷自动申请时同样打 `apply n=`。

AbsPos：`VecCtrl.Ap@0x98`（X/Y/Vx/Vy 都是 double；Y=+8，Vx=+0x10，Vy=+0x18）。**AbsPos Y 增大 = 更高**。真作动器在白名单实例的 CD/CDF 钩里 **`SetImpactNext`**（与 F5 同源加冲量；禁止再 SET `Ap.V`，两路会互抢）。控制律抄 F5 旋翼：Kp=7、死区 12、合速分档 620/480/360 × 倍率、人速度前馈。禁止硬写 `Ap` 坐标。

固定怪：不直调混淆名的 `IsFixedMob` / `IsImmovable` / `IsPosFixed`（会进托管类初始化）。P0 只读：

- `Mob+0x138` → MobData（dump getter RVA `0xF196C0` 直读该槽）
- `MobData+0x2C` int：TW dump `MoveAbility`（CMS 在 `0x34`）；`== 0`（Stop）当不动
- **不要**用 `+0x50`：TW 上是战斗数值，蜗牛 ChaseSpeed 常 0，会把能走的怪全判死
- **不要**用 `+0x8A`（dump getter RVA `0x1517840`）：同簇 bool，拾取/AI 旗常为 1，不是固定怪

读不到 data 指针则不拒（「能绑则拒」）。

LiveValue `APC_Irregular_Knockback = 271`：过密 / 过大 vx 可能记异常。吸速面板顶 1000%（与 F5 滑翔同顶格）。`m_bFloatHackCheckNeed` 在 **VecCtrlMob** 上，卸台悬停可能置位——BIN 看 30s 是否踢。

## 4. 产品行为

第三排「吸怪」TAB（首页卡已撤）：

- 开关 `mobGather`：落盘 `user.ini [core]`，默认关。勾选后 worker **~17 ms** 刷瞄准点；新收一批间隔 `mobGatherIntervalMs`（默认 **40 ms**，TAB「间隔」可调 40–5000）。已吸住的怪仍跟瞄准 VTOL。CDF 每物理步用最新瞄准点写速度。
- **聚拢点**：本 TAB「自定义落点」X/Y **自己填**（InputInt；与首页空中贴怪站距各存各的）。正 X=朝向面前，负 X=背后。AbsPos **Y 增大 = 更高**。仅防爆钳 ±30000，不再套 F5 的 0–900 / ±600。不勾则近战默认 X=60、Y=-4。**不贴台**：`aim = (人X ± X, 人Y + Y)`，怪靠 VTOL 悬停，不 `SnapStandAt`。
- 吸速 `mobGatherSpeedPct` / 防抖 `mobGatherAntiJitter` + 钉住/静止阈：与 F5 滑翔同构控制律，落盘 user.ini。默认 **1000%** + 防抖开。快捷档 1X/2X/3X/5X。100% = 巡航档（默认 620 px/s，TAB「档速」可改）。**≥5X** 抄 F5 10X：死拍 `err/T` + 对站点 `err/H`（刹车默认 150 ms）；顶格由 `mobGatherMaxCmd`（默认 4800）。
- **同时**（开关卡，默认 **64**，硬顶 64）/ **在途**（开关卡，默认 **0=不限**）/ 半径（默认 **2800**，只防爆钳 **30000**）/ 超时 / **间隔**（默认 40 ms）/ **瞄准**（默认 17 ms）/ 落地也吸 / **延时启动**（开关卡，默认 **0 ms**，作用整模块：进图站稳后起表；关吸怪 / hold / `no_flight` / `nm_down` 清钟，回图重新等满；遇人暂停不清钟；与落地也吸独立。BIN：skip 行也打 `qdelay=` / `max=` / `dyLim=` / `walkDx=` / `feet=` / `off=`；等满前 `why=quiet_delay left=`）/ Kp / 死区 / 巡航圈 / 进站圈 / 重力 / **档速**（巡航/进站/悬停）/ **到位**（到位圈、到位Kp、刹车、下滑切断）：本 TAB 可调，落盘 user.ini。远拉（BIN 见 6800）容易断。软重连 hold 仍停。
- **主动软重连**（首页挂机卡，**不绑吸怪**；默认关，X 默认 **14** 秒）：勾选 + `IsInMapScene` 立刻起表（`soft relogin clock start inMap`）。未 PlayReady / 换频·躺·补给 busy **只挡开火，不清钟**。软重连 hold 中冻结已走秒数，落地不另等 2s。首页「软重连试连」开才 `CloseSession`（`why=hangup_timer`）。换图窗 / 商城离图清钟。赶路 `InTravelGapPause` 认 `IsReconnectInFlight`（含 deferred），禁止 `wait_wm_field` 死等；落地 `ResumeGotoAfterGap` 重规划。不点確認、不清登录态。ini 键仍 `mobGatherSoftRelogin*`。
- **位移夹速**（吸怪 TAB「防断」卡，默认 **开**、上限 **48 px/帧**，防爆钳 8–400）：`mobGatherDispClampOn` / `mobGatherDispCapPx`。CDF 写速度前把被拽怪**每帧预测位移**等比夹到 ≤ 上限——客户端每帧比对怪移动位移，超「怪速+10」门即走异常上报路径、服端攒够踢线（第二波吸怪断连的扳机）。夹住就永不触发，与 hook/arm 无关。逆向证据与标定法见 [`../security/怪速举报type21与被动插值.md`](../security/怪速举报type21与被动插值.md) §7.9。BIN：`MobFhBan impact … disp= cap= clamp= dt=`。上限越小怪飞得越慢但越稳；还断调小、不断可逐步调大。
- **清怪重连**（吸怪 TAB，默认关，与首页主动软重连独立；仅 **吸怪开着** 才拆）：本轮唯一 ID 数达到「同时」上限即冻结（同时=1 → 吸到第 1 只就关闸，死了不补）。冻结后 **不再 Arm 新怪**（BIN `waveHold=1 new=0`），这批死光再 `CloseSession`，`why=mob_gather_clear`。已开火等落地期间也不补。超时溜走或 `ClearAll` 中止本轮。BIN：`clear relogin wave close n=/armed= why=cap|quiet`。缺键/新装走关；盘上已有键原样保留。

过滤：

- 收：`ready`、`deadType==0`、本地模拟（`vcAct≠0` 且 `Ap` 非原点）、距人合距 ≤ 半径。固定怪拒。
- **履历闸**：进图第一次成功吸之前见到的 oid（`exempt`）放行。**补刷**（`gate=1` 后新 oid）：即使在脚边，也必须 `CurFh` 非空且非掉落 `vy < -120` 才 Arm；脚边只豁免横移 `|dx|`。距人 > 脚边时，横移不够（`mobGatherWalkDx`，默认 96；0=不挡横移）仍不 Arm。高度闸对补刷始终生效（不受脚边掏空）；exempt 第一批仍只在距人 > 脚边时挡高度。用户自填，只防爆钳 30000；0 脚边=不开横移豁免。BIN：`skipSpawn=` / `skipAir=` / `walkDx=` / `feet=` / `dHome=` / `dHomeMax=` / `off=` / `why=walk` / `gate=`。
- **策略 B**：卸台后一帧把 `Ap`/`Apl` 写到聚拢落点（人物站位+off，**不** `PlantOnFh`、不 leash、不 hop）。夹速对 B 无效。BIN：`fh-snap … plant=0 d=`（`d`=本拍写出距离）。已证远距一帧会断，按用户口径仍这么做。
- **寻簇闸（可选项，默认关）**：`mobGatherSeekCluster`。关=原来的站立吸怪，本闸不跑。开：Arm 前只在**人所在层**找最密邻域（|dY|≤**竖层** `mobGatherLayerYPx`，默认 **200**，合距 ≤800）。本层没有堆就不飞。质心 **SnapStandAt 贴台**（禁止瞄半空；跨层拒绝也用竖层）。钉死落点，飞的过程不换簇、不跨层。人侧 `Owner::Gather` 抄贴门：Cruise→Station，瞄准抬高（AbsPos 更大 Y=更高），合距 ≤80 且 **|vx|≤30** 即卸推（Station 悬停 |vy| 收不干净，等 vy 会漂在台上方；BIN 18:40 latch y=-809 人停 -771）。卸推时 **SetImpactNext(-v)** 反推残速（fhBan 仍 ON），再放挂台。已有白名单时不再开新飞。F6 / 赶路占旋翼不抢。寻路/落地静默冻 14s。战斗出刀让路（`gather_seek`，含落地静默）。BIN：`seek_cluster latch` / `layerY=` / `bleed wait` / `land kill` / `settle enter` / `stop why=arrived`。不绑战斗「群怪优先」。与「软重连后返回原位」互斥。吸怪 TAB「竖层」可调，落盘 user.ini。
- **软重连后返回原位（可选项，默认关；无首次记录不飞）**：`mobGatherHomeReturn`。与寻簇互斥。**F5 每次开/关打怪都会刷新** 或面板 **「记录人物坐标」**（oneshot seq `state/mob_gather_home_record_seq`）让 DLL 记当时 AbsPos + 图号（必须挂台；空中不覆盖；`home_return record refresh=`）。可微调 X/Y。**落盘 user.ini**；首页 persistCore **不覆盖** home 坐标，避免冲掉 DLL 写入。没图号不飞。软重连 hold 置 pending；PlayReady 后 **先等到有 AbsPos 且挂台** 再吃进图边沿（进程死后第一拍没坐标不会把边沿吃掉）。离记录点 >80px 才飞。落地静默结束再飞（**允许跨层**）。抄贴门：合距 ≤80 且 **|vx|≤30** 即 **SetImpactNext(-v)** 反推残速，放挂台（不等 |vy|，Station 悬停会漂）；2s 未挂上 **重新起飞**；2s 未挂上 **重新起飞**（`settle retry`），滑出台也重飞，**不**当 arrived 出刀。遇人暂停只停飞、保留 pending。换频/选角/补给/测谎/卖物让路。BIN：`home_return record` / `pending (soft reenter|enter map)` / `latch` / `bleed wait` / `land kill` / `settle enter` / `settle retry` / `stop why=arrived`。AbsPos：**更大 Y = 更高**。
- **高度闸**：未武装且距人 > **脚边** 时，**双向** `|mobY-py| > dyLim`（吸怪 TAB「高度闸」，默认 **1200px**，用户自填，只防爆钳 30000）→ 不 Arm。人进坑后不再拖上层。已武装继续。调试 TAB「高度闸扫描」须指令 **ws888**：站着吸，dyLim 从 1 每秒 +100 到 2000，掐线看 `dylim_ramp KICK dyLim=`；停扫恢复面板高度闸，不写 user.ini。BIN：`skipDy=` / `dyLim=`。
- **池槽**：`PvcActive` 与 `VecCtrl@0x50` 两套都活且 Ap 相差 ≥ 800 → 不收。`Mob+pos` 与 Ap 对不上（含显示翻转 Y）→ 不收。同一 oid 一拍跳 ≥ 800 → 重置 home、本拍不 Arm（武装后仍走 `pool_jump`）。BIN：`skipPool=`。
- 远端影子（`Ap=(0,0)` / `vcAct=0`）**不收**——BIN：推它们会从原点贯穿地图，且朋友看不见。
- `fly_fh_ban` 只拦 **LocalUser** klass，与怪侧 CD/CDF **不抢虚表**。F6/F5 飞时吸怪继续跟 **面前站距空点** + 人速度前馈（随机飞靠这条）。寻簇选项开时人侧另占 `BanSource::Gather`。
- **统一卸台**：白名单里每一只本地模拟怪都 Arm CD/CDF + `ClearFh`，不按「比人高 56」筛选。落到人身边也**不**放行重挂（作动器在维持）；只在超时 / 死对象 / Ap 归零时 `SweepStale`。关模块 `ClearAll`。
- 已入白名单的怪飞出半径仍维持，直到超时 / Ap 归零。新收仍合距 ≤ 半径。
- 不改 `fly_fh_ban` 的怪侧路径。人侧寻簇才加 `BanSource::Gather`。AbsPos **Y 增大 = 更高**。

**申请控制权**（选项，默认关）：

- 正路：`Mob.OnFixedUpdate` → `ApplyControl(tCur)` → 过门（已 Active 停、`CanApplyCtrl`、距人、`_lastApplyCtrl@0x120` CD）→ `calc_priority(人xy, 怪xy)` → C→S `MobApplyCtrl`（CMS 206 / TW ≈ 208，包体 mobId+priority）。
- 服端同意：S→C 280 `flag≠0` → `SetLocalMob` → `SetActive(true)`；再 282 CtrlAck。拒绝则仍是影子。
- 本选项只在泵上调官方 `ApplyControl`，频率 1s、最多 `max` 只。补刷 oid 没勾也会走同一条（不挡 Arm）。**不**钩 `calc_priority`（自报分服端不信 / 谎报会踢）、**不**造 206、**不**写 `0xE8`。
- dump 名 `ApplyControl@0xF57320` 是 16 字节 stub；运行时 hash 命中 stub 则扫 `calc_priority` / `CanApplyCtrl` 的 E8 调用方，再扫 `OnFixedUpdate` 的 E8。不认 any4_xref。日志：`ApplyControl resolved via=… rva=…` / `apply n= ok= seh=`。
- 贴脸让真实距离变近才值钱。公开图 `ctrl=-1` 但 `vcAct≠0` 的仍可吸；影子要等 280 变 live 下一拍才进白名单。

作动器：白名单 CD/CDF 里 `ClearFh` + `return 0` + `SetImpactNext`（F5 `VxCommandFor`：绝对速度 → 加冲量）。控制律抄 `heli_rotor::Tick`（Kp=7、到位软钉、进站 err/H、`GravityLoss`、可达集）。不硬写 `Ap` 坐标，不 SET `Ap.V`。默认不接玩家旋翼单例；寻簇选项开时人才 `Tick(Owner::Gather)`。武装期 Slot 11 跳到基类 WUA，Mob AI 不跑。人静止时防抖钉住人 AbsPos，再投到朝向面前的站距落点（自定义 X/Y，默认 60/−4）；人在飞则每拍重算该点。

## 6. 验收（BIN）

过：

- 本地模拟怪 `Ap` 收敛并停在角色朝向面前的站距空点（BIN：`aim=` 相对人水平约 ±X、垂直约 +Y，**不贴台**；`faceL=` 随转身翻转）。朋友能看见你模拟的那些一起过来。
- 「吸怪」TAB 改旋钮后，下一拍 tick 的 `max=` / `r=` / `hold=` / `quiet=` / `scale=` / `jitter=` / `layerY=` / `dyLim=` 跟面板一致。
- **默认不勾「先飞到最密堆再吸」**：人站着吸，日志不应出现 `why=seek_cluster`（与加闸前一致）。勾上后才 `seek_cluster fly` 飞到**当前层**质心；到位先 `settle`，挂台站稳才 `stop why=arrived`。不应再 latch 跨层（|dY|>竖层，默认 200）。
- **默认不勾「软重连后返回原位」**：没记过点不飞出生点。勾上后，F5（开或关）或点「记录人物坐标」记下 AbsPos 之后，软重连回图或游戏重开进到该图，应先 `home_return fly` 再吸；再按 F5 覆盖记录。两勾不能同时为 1。空中 F5 不覆盖。
- `remote=` 对得上「别人控的不卸台」。不勾「申请控制权」时，进图第一批可不发申请；**补刷**仍会 `apply=`。勾了之后半径内 `ctrl≤0` 都申请。服端派 280 后下一拍才可能 `live` 增加。
- 人 F5 / F6 行为与关模块时一致。
- 30 s 无踢、无穿出地图刷新出生。

## 7. 风险（不当 BUG 修）

- 公开图 `ctrl` 全 -1 时，用本地物理当权威；若代理误收远端影子，会穿图。
- 卸台悬停可能触发怪侧 `m_bFloatHackCheckNeed`。
- 叠在脚边方便旁边的人 AoE。这是产品事实，不是缺陷。
- 关开关后才放行重挂；中途泵超时重力会把怪往下送，下一拍配平按真实 dt 补。
