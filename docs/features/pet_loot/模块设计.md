## 0. 一句话

**宠吸**：
- 盒内全落地且 Ready≤6 → 扩盒 ByPet（一拍一次；`ok`/`ok_sent` 停 burst）  
- **混飞**（`flyNear>0`）或 **密堆**（`readyNear>6`）→ **不大盒 ByPet**；按件 `DropPool.Send`（**角色 Maple 坐标**，只吸 Ready）  
- 发包前再过 **角色半盒闸（≤750）**：宠真空内但人够不着 → `ok_far`（不空 Send）  
- 无 Ready → `wait_land`  
- **防断连**：真空顶 **1500×1500**（旧 4000 钳回）；burst 硬顶 8；送包即停本拍  
**人物直吸**：枚举盒内已落地 drop → 只清冷却 → 官方 `DropPool.SendDropPickUpRequest(角色坐标, dropId, 0)`（不靠宠）。

脚边 `TryPickUpDrop(userPos)` 保留为可选；**不再**对 `Drop.Pt1` 假位姿调脚边口。  
**关键**：Contains **只读** `.rdata` 包；**不写** `Pet._rcPet` / `CollisionCheck.rcPet`；Ready 态 `EndPara==3`（**禁止写 0**）；人物直吸**禁止**对未落地 drop 写字段。

与自动打怪 / 攻击加速 **共用一条 Unity 主线程泵**（禁止第二条 SendWill）；靠 `drainBudget=2` + `JobPrio` + 拥堵让路并行（§3.6）。

## 3. 实现细节（`RunVacuumOnMain` · 宠吸）

代码：`x/features/ports/drop_pool_port.cpp`。

### 3.1 拍内步骤

1. 门控：`activated pet` + `skill & PickupItem`
2. **轻清闸** `ClearPickupGatesNear(..., maxClear=8)`（真空半宽高内；**跳过黑名单 / 不可捡 / LastTry=INT_MAX**）  
   - 写路径复用 `ClearPickupGatesOne(drop, forceEndParaReady=true)`  
   - `EndPara`：`!=3` 且 **非 0** → 写成 **`3`**（**禁止写 0**，否则抛物线飞落）  
   - `+0x88` Send 盖戳 / `LastTry@+0x80`：非 0 且非 `INT_MAX` 清零  
   - `OwnType@+0x3C`：ByPetParity 死钉（勿信 CMS 字段哈希）；日志 `ownType`∈0..4 或 `-1`  
   - **预算 8**：ByPet 一拍摸不了上百件；全盒清闸曾 `gates=100+` 占死 MainPump（§3.6）
3. 黑名单 `StampSkippedDropsNear`：`LastTry=INT_MAX` + `EndPara=4`（挡 ByPet 空吸打转；**长期留戳**，不拍末还原）。真空拍内盖戳；拍与拍之间 / 出刀让路 / 堵泵走 `HoldSkipDrops`（约 40ms）+ `ExceptionList`，挡原生脚边 50×60。
   3b. **退避黑名单** `StampStalledDropsNear`：**只盖 `LastTry=INT_MAX`**（**不动 EndPara**）；拍末 `Restore` 只还原 LastTry（见 §3.4）
   3c. **归属客户端预筛**（详 [`P0b_Drop归属预筛.md`](P0b_Drop归属预筛.md)）  
       - `Drop.OwnerId@+0x34`：进包 `ReadInt` 写入（服端）  
       - 本地真源：**`WM+0x114`**（BIN `via WM+0x114 scan`）；`WM+0x98` / `CS+0x10` / `User+0x1B0` 同属另一套 ID（例：194899）——**禁止**作 self  
       - `DropClientPickable`：无主/OwnType 放行；远程 Peek 黑名单；独图 fail-open；真吸认亲兜底  
       - 热路径禁止每 drop `InvokeAndWait`；宠吸与人物直吸共用
4. `ExceptionList`：skip 变更时增量同步（容量有限；辅）。落地当帧主闸：`Pet.TryPickUpDrop` 的 MethodInfo 钩子在 `E8 ByPet/Send` **之前**全池盖 `LastTry`/`EndPara`（日志 `skip-hold try-pick`）。Send 钩只拦走 MI 的发包（软件真空）；原生 Send 仍是直调。
5. **主真空**：`ResolveByPetRectPack` → `PatchByPetRectPack(vacuumW,H)`  
   - **定位**（防漂移）：① ByPet 方法体 RIP 相对寻址（`psubd`/`movsd`）② GA 映像唯一原生特征 `(25,10)+(50,60)` ③ 末级死钉 RVA  
   - **字段**（防漂移）：hash + `field_get_offset`；dump 常量仅 fallback（`DropPort` 日志 `path=meta|…`）；见 §3.5  
   - 布局：`int32 offX,offY @+0`；`float w,h @+0x10`  
   - 原生：`off=(25,10)` `size=(50,60)` → 等价 Contains `(-25,-10,50,60)`  
   - 拍内：`off=(W/2,H/2)` `size=(W,H)`；`VirtualProtect` 写后拍末恢复  
   - 失败 → `why=no_rect_patch`，不调拾取；MISS 灯 `PetRect`
6. `Pet.TryPickUpDrop(pet, MethodInfo=nullptr)`
7. 恢复 `.rdata` 矩形包
8. 读池前后计数 → 判定 `why`

### 3.2 日志一锤定音（异步清池）

服端删 drop 常晚于同拍回读，故 **同拍 `Δ` 经常为 0 仍可能已真吸**。

| 条件 | `why=` |
|------|--------|
| 同拍 `dropCountAfter < dropCount` | `ok_absorbed` |
| 跨拍（≤3s）：上拍有 near/gates 且本拍 `dropCount < 上拍 after` | `ok_absorbed`（`fell=1`） |
| 调了官方口、近处有 drop、池未降 | `ok`（空成功嫌疑 / 冷却中） |
| 调了、附近无 drop | `ok_empty` |
| `.rdata` VirtualProtect 失败 | `no_rect_patch` |

`petSendΔ`/`poolSendΔ`：MI 探针；ByPet 直 call 时常为 0，**不以之为成败**。

日志字段示例：

```text
mode=petmap ... drops=2→2 Δ=0 fell=1 ... why=ok_absorbed ...
```

### 3.4 队头堵塞与退避黑名单（2026-08-05）

**现象**：角色背包「其他」栏满后整体像「不再吸物」，池子从 0–3 一路堆到 300+，金币也吸不到。

**根因**（`petloot.log` 实证，2026-08-05 10:24 为拐点）：

| 环节 | 事实 |
|---|---|
| `ByPet` 一次调用只提交**一件** | 拍后轻扫 `touchMax` 恒为 1 |
| 服端因该栏已满拒收 | `dropsΔ=0` / `fell=0` → `sentSame` 14–19 / 19 拍 |
| 我们每拍清 `LastTry`（等于清掉官方 per-drop 冷却） | 同一件永远排在 ByPet 队头 |
| 后面的金币/装备轮不到 | `touchMoney=0` 且 `itemWhileMoney=14~19`（盒内明明有 20–70 金币） |

**处置**：`sentButPoolSame` 时把该 `dropId`（`Drop.Id@0x30`）登记退避（`gStall`），拍内
`StampStalledDropsNear` 盖 **`LastTry=INT_MAX` only** → ByPet 早退 → 下一拍轮到别的。
若官方拒收不留可识别戳（`touch=0`/`stallN=0`）→ `AddStallFallbackHeadsNear`：有钱则退避盒内
Ready 非钱，否则退避最近 Ready。paced Send **禁止**对已 Stall 件 `ClearStall` 强开；候选**金币优先**。

**勿动 EndPara（2026-08-05 修订）**：早期拍内 `EndPara 3→4` + 拍末 `4→3` 会让盒内数十件
**反复重播落地动画**（与黑名单「清闸回写 EndPara=3 打转」同类）。用户黑名单仍可长期
`EndPara=4`（不还原）；退避只盖/还原 LastTry。

**拍内对称（与 `.rdata` 矩形包同范式，硬约束）**：盖 LastTry → 调用 → `RestoreStalledStampsNear`
拍末还原 `LastTry→0`，**绝不跨拍留戳**。否则切到脚边后，这些道具会一直捡不起来。
还原走重新枚举字典，不跨托管调用持裸 `drop` 指针。

| 要点 | 说明 |
|---|---|
| 指数退避 | 3s 起 ×2，上限 300s；连续被拒的道具最终 5 分钟才试一次，基本不占拍 |
| 到期解封 | 自动 → 用户整理背包后无需重开开关 |
| 换池全清 | `ResetStallIfPoolChanged`（`dropId` 会复用）；池临时解析不到时**不清**，避免抖动重学 |
| 超量回收 | 超 2048 条时只淘汰**已过期**条目（丢的仅是 strikes 记账），生效中的 hold 一律保留 |
| 时间戳一致 | 盖戳与还原同用拍首 `now`，两个集合严格一致 |
| 漂移自保 | 不变量：`Drop.Id` 唯一 → 本拍盖戳数 ≤ 生效条目数。超出即 Id 偏移读到非唯一字段 → **自动停用退避**并 `LogW("droppool", "stall off: ...")`；清表放在拍末还原**之后** |
| 不误判 | `CountPostSendTouchesNear` 排除 `LastTry==INT_MAX`；用户黑名单 drop 不进退避流程 |
| 线程 | `gStall` 只在主线程泵 job 内访问，无需加锁 |

日志：`stall=<生效件数>/<本拍盖戳>/<本拍还原>`。宠吸路径后两数应基本相等。`stall≥16` 时每 30s
一条 `hint=inv_full_suspect`。人物直吸不盖/不还原（`B/C` 恒 0），只靠软件 `StallActive`（§4）。

### 3.5 字段偏移解析与写路径门禁（2026-08-05）

字段全部 hash + `il2cpp_field_get_offset`，dump 常量只是 fallback。**本 port 会写托管
`Drop` 字段**（`EndPara` / `LastTry` / `+0x88` / `OwnType`）与宠 `ExceptionList`——偏移失配不是
优雅降级，而是踩托管堆。故：

| 机制 | 行为 |
|---|---|
| 只在满解析时锁定 | `hits==期望` 才 `tried=true`；未满则每 3s 重试 |
| 写路径门禁 | `DropWritesAllowed()`＝`Pt1`/`Id`/`OwnType`/`EndPara`/`LastTry`/`PickStamp`/`ExceptionList` **全部**元数据。为假时：清闸只采样不写、盖戳不盖、`ExceptionList` 不追加 |
| 还原不设门禁 | `RestoreStalledStampsNear` **故意**不判门禁：只写「读回正好是 `INT_MAX`」的 LastTry |
| 人物直吸 meta | `gCharGatesMeta`＝`Pt1`+`Pickable`+`Id`+`EndPara`（盒选读 Pt1、送包用角色坐标）；**不依赖**未使用的 `PickPt`（脚边路径才用 PickPt） |
| 可见性 | `DropPort` 日志 + 锚点灯 `DropFields` |

方法侧 SSOT：`il2cpp_method::FindMethodResolved`。

### 3.6 与打怪时分复用 · MainPump + 落地脉冲（2026-08-06）

吸物 / 开火 / 瞬移 / 施法都经 `main_thread::InvokeAndWait` 上 Unity 主线程。**禁止**再挂第二条
SendWill 泵（GC / 设计硬约束）。

| 机制 | 行为 |
|---|---|
| `kDrainBudgetPerTick=2` | 同 tick 最多跑 2 个 job |
| `JobPrio` | **High**：开火 / 朝向 / 瞬移 / 施法；**Low**：宠吸 / 脚边 / 人物直吸 |
| 拥堵让路 | `IsCongested()` 时本拍跳过吸物 |
| **挂机时分复用** | `IsLootPulseActive()`：仅 **`Firing`** 禁吸；`Aim`/`Recover`/`MoveTo`/`Settling`/`Acquire`/`Idle` 放行。进 Aim/Recover/Settling 边沿可无视 `intervalMs` 立刻吸 1 拍。BIN 04:04：整链 Aim/Fire/Recover 禁吸 → yield:mode≈4:1、出刀时几乎不吸 |
| 未挂机 | `IsLootPulseActive()` 恒真 → 自由吸 |
| 实证 | upload `211841` / `5d4572`；拟人禁吸过猛 B02 `70799f` → 「不出刀就吸」；短暂拟人再禁 → 0b66c7 漏捡回退 |

## 4. 职责

### 做

- 面板「关闭 / 脚下 / 宠吸 / 人物直吸」Radio 单选互斥（冲突 `notify::PushLocal`）+ `user.ini [pet_loot]` + payload 轮询
- Tick：宠开则跳过脚边与人物；真空=拍内改写 ByPet `.rdata`；人物直吸=官方 Send
- **归属预筛**：`DropClientPickable`（[`P0b`](P0b_Drop归属预筛.md) · `WM+0x114`）
- 黑名单：名称/`itemId` → 图鉴**全量**展开；默认关键词 `箭矢`/`彈丸`；宠吸 **LastTry + EndPara=4**（主）+ `ExceptionList` 变更时同步（辅）。关键词按空格/英文逗号切；全角 `；，、` 也切（「箭矢；弩箭矢」整段匹配会 miss=1）
- 清门控**跳过**黑名单 drop（避免每拍把 EndPara 写回 3 导致打转）
- 宽词实测：`寶`≈112、`卷`≈670、`色`≈三千；日志 `skipN` 应为全量命中数

### 人物直吸（2026-08-05 · 落地动画修订同日）

- 面板四选一；`user.ini charVacEnabled`
- 路径：枚举 DropPool → **已落地**（`EndPara==3`）+ Pickable + 非黑名单 + 非软件退避 →
  **只清该件** `LastTry`/`PickStamp` → `DropPool.SendDropPickUpRequest(角色 Maple 坐标, dropId, 0)`
- **不靠宠物**、不伪造 CRC、不改 GA `.text`
- **硬纪律（防循环落地动画）**：
  1. **禁止**宠吸那套拍内 `StampStalled` / `StampSkipped` / `Restore`（盒内 `EndPara 3↔4` 会抖落地；upload `a0a7fe`）
  2. **禁止**对 `EndPara!=3` 的 drop 写任何字段（曾「先 Clear 再判 EndPara」→ `gates=2~12`，抛物中物每拍被清冷却；upload `065ed0`）
  3. 清闸**只**清即将 Send 那一件的冷却；**不写 EndPara / OwnType**
  4. 拒收退避：只对**本拍 `sentDropId`** 做 pending → 下拍仍在池再 `AddStall`；**禁止** `CountPostSendTouchesNear` 整盒登记（曾 `sendTouch=90` 误伤）
- 吞吐靠面板 `intervalMs` / `burstPerTick`（默认 **200**×5，可改）
- 默认半盒 750×750（全盒 **1500×1500**；Normalize 钉死）
- meta 门禁见 §3.5；`InvokeAndWait(..., JobPrio::Low)`
- 结案实证：upload `791596`（0.1.60）→ `gates` 仅 0/1、`stall=0/0/0`、`sendTouch=0`、画面不再循环落地

### 不做

- 角色全图假位姿 / `charDrop*`
- 手组 Send / 伪造 CRC
- 拖掉落实体、改 GA `.text`
- 小盒「宠物吸物」独立模式（已并入宠吸）
- 第二条 MainPump / worker 直调托管

## 5. 配置（`user.ini [pet_loot]`）

| 键 | 默认 | 说明 |
|----|------|------|
| `enabled` | 0 | 宠吸（正式；尺寸见 mapVacuum） |
| `footEnabled` | 0 | 角色脚边拾取 |
| `charVacEnabled` | 0 | 人物直吸（官方 Send，不靠宠；与宠/脚互斥） |
| `mapVacuumEnabled` | 0 | 与 enabled 同开；兼容旧键 |
| `intervalMs` | **200** | Tick 间隔（脚边+宠+人物共用；50–2000；打怪同开建议勿压太低） |
| `burstPerTick` | 5 | 每拍连调上限（1–**8**；送出/`ok_sent` 即停本拍，防洪泛） |
| `vacuumW` / `vacuumH` | 1000 / 1000 | 宠吸/人物直吸共用全盒（可调；**宠吸与人吸同顶 1500**；旧 4000 ini 自动钳回） |
| `footHalfW` / `footHalfH` | 100 / 80 | 脚边半宽高（全盒 200×160） |
| `charHalfW` / `charHalfH` | 750 / 750 | 人物直吸半宽高（全盒 **1500×1500**；Normalize 钉死） |
| `filterFlags` | meso\|equip\|consume\|etc | 预留 |
| `skipFilterEnabled` | 1 | 黑名单开 |
| `skipCount` / `skip.N.*` | 默认 2 条：`箭矢`、`彈丸` | `itemId` / `nameKey`；金币=`2147483647`；缺 `skipCount` 用默认，显式 `0` 表示清空 |
