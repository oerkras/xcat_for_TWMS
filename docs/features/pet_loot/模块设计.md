## 0. 一句话

正式吸物只走：`EndPara=3` 门控 → **拍内改写 ByPet `.rdata` 矩形包**（`0x55736B0`，原生 50×60；旧 `0x5574990`）→ `Pet.TryPickUpDrop` → `ByPet` → `Pet.SendDropPickUpRequest`。

脚边 `TryPickUpDrop(userPos)` 保留为可选；**不再**对 `Drop.Pt1` 假位姿调脚边口。  
**关键**：Contains **只读** `.rdata` 包；**不写** `Pet._rcPet` / `CollisionCheck.rcPet`；Ready 态 `EndPara==3`（禁止写 0）。

## 1. 与枫星差异

| 层 | 枫星 | TWMS |
|----|------|------|
| 提交 | Lua `AcquireByPet` | `Pet.TryPickUpDrop` → `DropPool.TryPickUpDropByPet` |
| 扩范围 | `PetHitBox.BoxSize` | **仅** ByPet `.rdata` 矩形包 `@0x55736B0`（不写 `_rcPet` / `CollisionCheck`） |
| 配置 | `[autopickup] fullMapEnabled` | `[pet_loot] enabled`（宠吸=原近图 3200×2400） |
| 脚边拾取 | 同模块 | `[pet_loot] footEnabled`（可选） |

## 2. 官方调用链（游戏内）

```text
Pet.TryPickUpDrop()                         // RVA 0xF96240 · 我们只调这一层
  → 取宠位置 / 组 pos、posCheck、CRC（官方填）
  → DropPool.TryPickUpDropByPet(pet, pos, …) // RVA 0xF528E0
    → 技能 / Contains(矩形) / OwnType / EndPara / Real / 冷却
    → Pet.SendDropPickUpRequest(...)         // RVA 0xF54F90 · 直 call，双 CRC
```

禁止：手组 `SendDropPickUpRequest`、伪造 CRC、直调 ByPet 自填向量。

## 3. 实现细节（`RunVacuumOnMain`）

代码：`x/features/ports/drop_pool_port.cpp`。

### 3.1 拍内步骤

1. 门控：`activated pet` + `skill & PickupItem`
2. `ClearPickupGatesNear`（真空半宽高内；**跳过黑名单 drop**）  
   - `EndPara@+0x7C`：`!=3` → 写成 **`3`**（禁止写 0，否则抛物线飞落）  
   - `+0x88` Send 盖戳 / `LastTry@+0x80`：非 0 清零  
   - `OwnType@+0x3C`：异常大数 → `No=2`
3. 黑名单 `StampSkippedDropsNear`：`LastTry=INT_MAX` + `EndPara=4`（挡 ByPet 空吸打转）
4. `ExceptionList`：仅在 skip 集合/宠指针变化时增量同步（容量有限；主挡捡靠第 3 步）
5. **主真空**：`PatchByPetRectPack(vacuumW,H)`  
   - RVA **`0x55736B0`**：`int32 offX/offY` + `float w/h`  
   - 原生：`off=(25,10)` `size=(50,60)` → 等价 Contains `(-25,-10,50,60)`  
   - 拍内：`off=(W/2,H/2)` `size=(W,H)`；`VirtualProtect` 写后拍末恢复  
   - 失败 → `why=no_rect_patch`，不调拾取
6. `Pet.TryPickUpDrop(pet, MethodInfo=nullptr)`
7. 恢复 `.rdata` 矩形包
8. 读池前后计数 → 判定 `why`

### 3.2 日志一锤定音（异步清池）

服端删 drop 常晚于同拍回读，故 **同拍 `Δ` 经常为 0 仍可能已真吸**。

| 条件 | `why=` |
|------|--------|
| 同拍 `dropCountAfter < dropCount` | `ok_absorbed` |
| 跨拍（≤3s）：上拍有 near/gates 且本拍 `dropCount < 上拍 after` | `ok_absorbed`（`fell=1`） |
| 调了官方口、近处有 drop、池未降 | `ok`（空成功嫌疑 / 冷却中） |
| 调了、附近无 drop | `ok_empty` |
| `.rdata` VirtualProtect 失败 | `no_rect_patch` |

`petSendΔ`/`poolSendΔ`：MI 探针；ByPet 直 call 时常为 0，**不以之为成败**。

日志字段示例：

```text
mode=petmap ... drops=2→2 Δ=0 fell=1 ... why=ok_absorbed ...
```

### 3.3 UI / 配置

- 面板 Radio：关闭 / 脚下拾取 / **宠吸**（互斥；冲突 `notify::PushLocal`）
- 宠吸 = 原「近图宠吸」：`enabled=1` + `mapVacuumEnabled=1` → 真空 **3200×2400**
- 旧 ini「仅 enabled / 仅 mapVacuum」加载时自动合并为宠吸并回写

## 4. 职责

### 做

- 面板「关闭 / 脚下 / 宠吸」Radio 单选互斥（冲突 `notify::PushLocal`）+ `user.ini [pet_loot]` + payload 轮询
- Tick：宠开则跳过脚边；真空=拍内改写 ByPet `.rdata` 矩形包（固定 **3200×2400**）；门控如上
- 黑名单：名称/`itemId` → 图鉴**全量**展开（`unordered_set` 去重，无截断）；宠吸 **LastTry 盖戳 + EndPara=4**（主）+ `ExceptionList` 仅在 skip 变更时同步（辅）
- 清门控**跳过**黑名单 drop（避免每拍把 EndPara 写回 3 导致打转）
- 宽词实测：`寶`≈112、`卷`≈670、`色`≈三千；日志 `skipN` 应为全量命中数

### 不做

- 角色全图假位姿 / `charDrop*`
- 手组 Send / 伪造 CRC
- 拖掉落实体、改 GA `.text`
- 小盒「宠物吸物」独立模式（已并入宠吸）

## 5. 配置（`user.ini [pet_loot]`）

| 键 | 默认 | 说明 |
|----|------|------|
| `enabled` | 0 | 宠吸（正式；尺寸见 mapVacuum） |
| `footEnabled` | 0 | 角色脚边拾取 |
| `mapVacuumEnabled` | 0 | 与 enabled 同开；兼容旧键 |
| `intervalMs` | 200 | Tick 间隔（脚边+宠共用；50–2000） |
| `burstPerTick` | 1 | 每拍连调 `TryPickUpDrop` 次数（1–5；>1 会占主线程更久，可能挤打怪） |
| `vacuumW` / `vacuumH` | 300 / 200 | 占位；宠开时 EffectiveVacuum=3200×2400 |
| `footHalfW` / `footHalfH` | 100 / 80 | 脚边半宽高 |
| `filterFlags` | meso\|equip\|consume\|etc | 预留 |
| `skipFilterEnabled` | 1 | 黑名单开 |
| `skipCount` / `skip.N.*` | | `itemId` / `nameKey`；金币=`2147483647` |

写入时会 `IniEraseKeysWithPrefix(..., "charDrop")` 清掉旧键。

## 6. 日志认路

| `mode=` / `why=` | 含义 |
|---|---|
| `petmap` + `ok_absorbed` | 同拍 Δ&lt;0 **或** 跨拍 `fell=1` → 真吸 |
| `petmap` + `ok` | 调了官方口但池未降（空成功嫌疑） |
| `petmap` + `no_rect_patch` | Contains 真源改写失败 |
| `foot` + `ok_absorbed` / `ok` | 同上，脚边（脚边亦有跨拍 fell） |
| `petSendΔ` / `poolSendΔ` | MI 探针增量；直 call 时可为 0 |
