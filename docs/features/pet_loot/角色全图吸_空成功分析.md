## 2. IDA：谁才真正发包

宠物链（静态钉死）：

```
Pet.TryPickUpDrop → DropPool.TryPickUpDropByPet → Pet.SendDropPickUpRequest（直接 call）
```

脚边 `DropPool.TryPickUpDrop` 为 CFF；`Pool.Send` 无 code xref。  
官方脚边 call（`0x7FFB17BBCA04`）：`pos`=角色位姿，`MethodInfo=nullptr`，**不是** `Drop.Pt1`。

---

## 3. 为何 chardrop「空成功」

把 `Drop.Pt1` 塞进 `TryPickUpDrop` 只可能骗过客户端矩形；CRC/服端距离校验不过 → 日志 `ok_droppos` 但 `drops` 不降。
