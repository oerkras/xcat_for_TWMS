# Gama Pass 账密登录助手（经典版 / TWMS）

> **产品**：新楓之谷：經典版（TW · beanfun / Gamania Galaxy）· **不是**枫星  
> **状态**：独立模块。GAMA PASS自动登录**不**改走助手独立罐；助手成功后也不会自动去换票。  
> **源码**：`launcher/gamapass_device_login.*` · UI：启动 TAB 卡片「Gama Pass 账密登录」

## 1. 做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 专用 Chromium 窗口填 Gama Pass 账密 | 换票 / 开游戏 / 注入 |
| SPA 启动前钉死卖家给的 `localStorage.device_id` | 写回日常 Chrome/Edge User Data |
| 勾选保持登入；原样复用第 4 段 device_id；成功后关独立调试窗 | 调用 `/v1/refresh/token`；自造 UUID；助手成功后自动换票 |
| Chrome++ / Chrome / Edge | 360、Firefox、日常默认罐 CDP |

和「GAMA PASS自动登录」始终是日常浏览器 UIA，**不**因 `gp_device_login.json` 里有卖家 `device_id` 改开助手独立罐子。助手登录完成**不会**自动跑换票。

## 2. 为什么必须独立 profile

Chrome 136+ 对**默认 User Data**静默忽略 `--remote-debugging-port`。本模块固定：

- 目录：`%LOCALAPPDATA%\XCat\GpDeviceLoginProfile`
- 调试口：`19223`（避开旧 GamaPass CDP `19222`）
- 杀进程：只杀占用**该目录**的实例，不按「同安装」误杀日常浏览器

device_id 冲了也能灌回去，**不等于**可以拿日常罐开刀。日常 SSO 仍禁止冲刷。

## 3. 浏览器

支持 **Chrome++、Google Chrome、Microsoft Edge**。界面可选手选，默认自动：Chrome++ → Chrome → Edge。360 / Firefox 拒绝。

独立配置目录按浏览器拆开（避免混用 User Data）：

`%LOCALAPPDATA%\XCat\GpDeviceLoginProfile\{chromeplus|chrome|edge}`

## 4. 钉 device_id 的三刀

1. `Page.addScriptToEvaluateOnNewDocument`（抢在站点脚本前面）
2. `DOMStorage.setDOMStorageItem`（源 `https://accounts.gamania.com`）
3. `Runtime.evaluate` → `localStorage.setItem('device_id', …)`

卖家行（对照工具 `parse_input`，`----` 分隔）：

`账号----密码----邮箱密码----device_id`

- 第 1 段：账号，必须是邮箱，填登录框
- 第 2 段：Gama Pass 密码，填 `accounts.gamania.com`
- 第 3 段：邮箱密码，只解析保存，**本次 Gama Pass 登录不使用**
- 第 4 段：device_id，必须是 **32 位 hex**（无横线）。禁止 `NewUuid()`、禁止补 UUID 横线

另有六段 `LoginRecord`（第 2/3 段与四段相反）：

`mail_address----mail_password----gama_password----device_id----userToken----refreshToken`

缺 device_id 或不是 32 hex 直接失败；收割会话时若页面 id 与卖家不一致，只打日志，仍保留卖家值。

账号行落盘：`XCat_data/state/gp_device_login.json`。

## 5. 二次验证

OTP / two-factor 不自动填。对照工具原文：`账号密码已通过，当前需要邮箱二次验证，请在已打开的浏览器中继续。` 窗口保持打开，等会话收割成功后再关。

账密登录成功（含「窗口里已有会话」）后调用 `CloseRemoteBrowser(19223)`：先 `Browser.close` 给 Cookie 落盘窗口，再只结束带 `--remote-debugging-port=19223` 的进程。失败 / 超时不关窗。不自动衔接 GAMA PASS自动登录。

## 6. 对照工具还原（Nuitka）

壳 `GamaPassLogin-keep-login-fixed-v15.exe` 无登录逻辑。解压后 `chrome_login_gui.dll`（8 470 528 字节，SHA256 `71295f3397f39f45d06d4b6c635c65a90d8b9b30781df2d2c59b3a3000e1b64d`）才是 `chrome_login_gui.py` + `chrome_cdp_login.py`。

还原稿：`docs/features/gp_device_login/re/`。DLL 在 `Dumps/re/gamapass_login/`（不入库）。

登录是两步 SPA，不是账密同屏一次填：

1. `Page.addScriptToEvaluateOnNewDocument` 钉 `device_id`
2. Navigate / 等 `accounts.gamania.com` 就绪
3. `force_device_storage`（DOMStorage + `localStorage.setItem`）再刷新
4. 填账号 → 勾保持登录（CDP 鼠标点 checkbox 中心）→ 点继续
5. 等密码框出现再填 **Gama Pass 密码**（不是邮箱密码）
6. `post_login_outcome`：two-factor / galaxy `/login/init/` / 仍停在密码页

CLI 六段行才会把 JWT 写入 `user_${openId}`；GUI 四段行不走这条。过期 token 的原文是「将由官网尝试 refresh」，对照工具自己不调 `/v1/refresh/token`。
