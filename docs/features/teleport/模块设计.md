## 1. 职责边界

| 模块 | 做什么 |
|------|--------|
| `teleport_port` | **仅** `TeleportNativeSkillCall` / `SetNativeCooldownMs` |
| `simple_combat` | 何时贴怪、落点 standOff；贴怪 **snapStand=true** |
| `fly` | F6 武装 + LMB 点飞；**snapStand=false**（已走本 API，禁止另开旁路） |
| `travel` | 赶路贴门；**snapStand=true** + fh≠0；卸图禁止 re-Doing |
| GUI | 贴怪参数 · `teleportTestSeq` / `teleportNativeTestSeq` |

---

## 2. 契约要点

- `TeleportNativeSkillCall(tx,ty,fh,snapStand=true)`：贴怪；可挂 `CurFh` 指针（**不** SyncRel settle）
- `TeleportNativeSkillCall(tx,ty,0,false)`：点飞；**不** `SnapStandAt`、不种台
- 官方 Doing 自带收态；Doing 后同帧 `Apl←Ap`（皮对齐）
- **禁止再引入**：ImpactNext / Attr=4 / `SyncRelPosOnly` / Register 技能包 / 钉 Transform
- 冷却：`SetNativeCooldownMs`（战斗默认较长；点飞默认约 300ms）

细节与 RVA 见 P0a。
