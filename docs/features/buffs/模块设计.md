## 0. 一句话

经典版「BUFF 管理器」= 面板勾选已学技能 → payload 在「不在身 / 将过期且可施放」时自动补放 → 以 `User._listAffectedSkillEntry` 确认上身。  
药水续航归 `autopot`；本模块 **技能-only**。

## 1. 与枫星差异（勿混）

| 维度 | 枫星（对照） | TWMS 经典版（本仓） |
|------|-------------|-------------------|
| 进程 | `msw.exe` / Artale + Lua | `Maplestory_Classic.exe` / Il2Cpp |
| 在身 | `CharacterBuff.ActiveBuffById` | **`User._listAffectedSkillEntry@+0x330`**；辅证 `WM.SecondaryStat@+0xF0` 的 `r/t` |
| 学级 / 技能书 | Lua `CharacterSkill` | `CharacterData.SkillRecord@+0x50` + `UserLocal.GetSkillLevel` / `SkillInfo.GetSkill` |

| 配置 | `user.ini [buffs]` + runtime SHM | **同形移植** |
| Tick | service_thread + Lua 预算 | 独立 worker（对齐 `autopot`/`timed_keys`） |
| 代理技 | UseOtherSkill 重定向表 | **首版不做** |
| UI | `DrawNativeBuffsTab` | `DrawBuffsTab` 真读写 |

P0 锚点明细见 [`P0a_锚点复核.md`](P0a_锚点复核.md)。

## 2. 职责边界

### 做

- 总开关 + 最多 16 技能槽（`code`=数值 skillId）
- `user.ini [buffs]` 落盘；payload 按 `writeTickMs` / `refreshSeq` 热更新
- Presence / Cooldown / Interval 三种策略（MVP 主用 Presence）
- Idle → Cast → AwaitVerify → Retry 状态机；槽间串行 ~1200ms；拒收指数退避
- heavy/light runtime SHM 供面板剩余 / CD / 列表
- 技能显示名：**offline-first** `dataservice/skill_names.tsv` → Il2Cpp `SkillEntry.Name` → 已知补表 / code
- 列表筛选：默认只显示离线 `skill_catalog_full.type=辅助(1)`；在身/已开槽始终保留；可「显示全部」
  - **不用**官方 `SkillEntry.SkillType`（Mastery/Booster/FinalAttack/SerialAttack，不是 BUFF/攻击分类）
- 进图门控：`ports::world::IsPlayReady()`（地图场景 ∧ WM 存活）+ MyUser/vitals；日志 `Buffs` / `buffs.log`

### 不做（首版）

- 物品 BUFF、技能多发齐发、假键鼠主路径、改 GA `.text`
- UseOtherSkill 代理、枫星 `auto_lie` busy 深耦合
- simple_combat 短暂停刀（仅预留 hook，战斗未齐时 no-op）

## 3. 架构

```text
xcat.exe BuffsTab
  → user.ini [buffs]
  → payload_buffs Poll
  → features/buffs Tick FSM
       ├─ skill_port::IsActive / GetSkillLevel / ListLearned
       └─ skill_port::CastSkill (main_thread → DoActiveSkillPrepare)
  → XCatBuffsRuntime SHM → 面板
```

状态机：

```text
Idle --due--> Cast(ok) --> AwaitVerify --active==1--> Idle(清退避)
                              |timeout active==0
                              v
                           Retry(指数退避) --> Idle
```

**禁止**用 duration 乐观 assume 挡补（对照仓已踩坑）。

## 4. 配置契约

```ini
[buffs]
version=1
masterEnabled=0|1
refreshSeq=...
writeTickMs=...
slot.N.enabled=0|1
slot.N.kind=0          ; 仅技能；读到 item 即禁用
slot.N.code=1101006
slot.N.intervalSec=180
slot.N.strategy=0      ; 0=Presence 1=Cooldown 2=Interval
```

实现：`common/xcat_buffs.{h,cpp}`（对照仓同形；含 runtime SHM）。
