# auto_supply Feature 模块设计（Classic TWMS）

> **状态**：行程骨架已挂入；UI 对齐枫星 home 卡片；**实机整趟待验**  
> **产品**：新枫之谷：经典版（TW）· **不是**枫星  
> **对照**：枫星 `auto_supply` / home 补给卡片仅作行为与布局参照  
> **源码**：`x/features/auto_supply/` · `x/features/ports/shop_port.*` · `common/xcat_auto_supply.*`  
> **面板**：`xcat_app/workspace_tabs.cpp`（挂机页「自动回城卖 / 补给」）

---

## 1. 目标

| 能力 | 行为 |
|------|------|
| **自动卖** | 装备栏件数 ≥X（0=满装）→ 暂停打怪/飞行 → 寻店 → 开店卖装（顺带卖其他） |
| **补回城卷** | 开店后货架有则买 1 张；没有跳过 |
| **可选补货** | 红/蓝/自定义/饲料：用户自选中文名；**店内有则买、无则跳过** |
| **可选充飞镖** | UI 可勾；运行时 **Charge stub**（`NOT_IMPL`，跳过） |
| **回挂机图** | 行程开始前记录野图；结束后 `travel::RequestGoto` |

**产品语义（硬）**：寻店只为就近「能卖」；**不按货架内容选型**。用户应勾选挂机图附近店里常见的补给品。详见 [`P2_货架寻店.md`](./P2_货架寻店.md)。

---

## 2. 行程状态机（摘要）

```
Idle → Pause(combat/fly) → GoingTown/直达店图
     → OpeningShop → Selling → Buying(卷→Charge stub→补货)
     → Returning → Cooldown → Idle
```

- 回城卷 vs 直达：比较 `farm→shop` 与 `town→shop` hops，选更短路径  
- 配置店图非空 → 覆盖自动寻店  
- 挂机图：`simple_combat::SetEnabled(true)` 时 `RecordHangupFarmMap`（城镇不写）  
- 手动：`manualKind` = Trip / ReturnFarm / Stop（`user.ini [auto_supply]`）

## 3. IPC / 配置真源

| 键 | 说明 |
|----|------|
| `user.ini [auto_supply]` | 开关、阈值、店图覆盖、补货名/CODE/补到、充飞镖、manualSeq/Kind |
| `user.ini [auto_supply_status]`（或兼容 bin） | state / message / lastFarmMap / pendingReturnFarm |
| **不**写 `core.autoSell*` | 双真源已清；Read 清零、Write 擦键 |

面板：补给勾选/阈值/补货 → `WriteAutoSupply`；手动卖 → `[sellbag]`。

## 7. 验收清单

1. 勾「自动卖」或点「立即回城卖装一趟」→ status 有赶路/开店/卖出文案  
2. 空店图 → 日志 `自动寻店 … npc=`；失败时「无商店种子/不可达」  
3. 补货：店无该项 → 跳过不卡死；店有 → 按金币比例买入  
4. 开打怪后 status/挂机图显示非城镇图号  
5. 「停止动作」关自动卖并恢复 pause  

**BIN**：整趟实机仍待验；Charge 勾选应见 `NOT_IMPL` 跳过。
