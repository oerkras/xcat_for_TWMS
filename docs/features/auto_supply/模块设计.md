## 1. 目标

| 能力 | 行为 |
|------|------|
| **自动卖** | 装备栏件数 ≥X（0=满装）→ 暂停打怪/飞行 → 寻店 → 开店卖装（顺带卖其他） |
| **去店用卷** | 优先 `回家卷軸`（见 §2.1）；失败则 `travel` 多跳赶路 |
| **补回城卷** | 开店后货架有则买 1 张主码 `2030000`；没有跳过（买前暂不查背包存量） |
| **可选补货** | 红/蓝/自定义/饲料：用户自选中文名；**店内有则买、无则跳过** |
| **可选充飞镖** | UI 可勾；运行时走 `SendRechargeRequestPacket`（见 sellbag P0d）。行程内 Charge：卖栏空投影会 **Etc↔Consume 弹 TAB 刷新**；`LIST_STALE` **>8s 跳过**继续买药（防 BIN 23:19 卡店） |
| **回挂机图** | 行程开始前记录野图；结束后 `travel::RequestGoto`（**回程不试回城卷**） |

**产品语义（硬）**：寻店只为就近「能卖」；**不按货架内容选型**。用户应勾选挂机图附近店里常见的补给品。详见 [`P2_货架寻店.md`](./P2_货架寻店.md)。

## 2. 行程状态机（摘要）

```
Idle → Pause(combat/fly + 安全落台) → GoingTown/直达店图
     → OpeningShop → Selling → Buying(卷→Charge→补货)
     → Returning → Cooldown → Idle
```

- **安全落台**（与测谎同款）：`SetHardPause(AutoSupply)` 上升沿 `BeginLieSafeLand`——旋翼飞近最近可站台再卸禁挂台；用卷 / `RequestGoto` / 开店对话前 `WaitSafeLand`。防底层低 Y freefall→地图重载。  
- 回城卷 vs 直达：比较 `farm→shop` 与 `town→shop` hops，选更短路径  
- 配置店图非空 → 覆盖自动寻店  
- 挂机图：`simple_combat::SetEnabled(true)` 时 `RecordHangupFarmMap`（城镇不写；城镇判定= `map_info.tsv` town=1 / 室外主城 `%1000000==0`，**不用** `QueryNativeIsTown`——拍卖绕过会强制野图 IsTown=1）  
- 手动：`manualKind` = Trip / ReturnFarm / Stop（`user.ini [auto_supply]`）

### 2.1 去店用卷（实现 · 2026-08-05）

**道具码**（离线 `dataservice/item_catalog.tsv`）：

| CODE | 名称 | 用途 |
|------|------|------|
| **2030000** | 回家卷軸 | 默认主码；智能回最近主城；补买也买这个 |
| **2030059** | 回家卷軸 | 同名备用；用卷时主码失败再试 |
| 2030001～07 / 19 等 | 定点城镇卷 | **不**自动选用 |

常量：`common/xcat_auto_supply.h` → `kAutoSupplyDefaultReturnScrollCode` / `kAutoSupplyAltReturnScrollCode`。

**调用链**：

1. `ShouldPreferDirectShop` → 选 scroll 时进入 `TickGoingTown`  
2. `TryUseReturnScroll`：依次 `FindAndUseByItemId(2030000)` → `2030059`  
3. `consumable_port::FindAndUseByItemId` 扫消耗栏（`ItemType.Consume=2`）→ 主线程  
4. 发包：**`UISlotItem.SendPortalScrollUseRequest(nPOS, nItemID)`**（**不是**药水的 `SendStatChangeItemUseRequest`）  
5. 成功条件（任一即可）：
   - 数量下降（即时或 delayed 复核）
   - **已换图**（`mapIdBefore≠mapIdAfter`；BIN `b19da8`：换图窗 `qtyAfter=-1` 旧逻辑误判 `no_consume`）
6. 仅发包、数量未降**且未换图** → **失败**（`PortalScroll no_consume`）  
7. 失败 → **同趟最多 3 次**（间隔 ~1.6s）再试主码+备用；耗尽才 `tried=… → walk`。若 API 报 ok 但 8s 内未换图，同样计入 tries 后再发。图已离开则 `ReplanAfterScrollLand`（勿误 walk）

**锚点（TW dump / script.json · 与 CMS 声明序对齐）**：

| 项 | 值 |
|----|-----|
| 类 | `UISlotItem` TypeDef **488**；哈希见 `consumable_port.cpp` `kUiSlotItemClassHash` |
| CMS 簇序 | … Lottery → **StatChange** → AntiMacro → **PortalScroll** → MobSummon … |
| PortalScroll 方法哈希 | `c0ae1896…47a6030`（`kPortalScrollMethodHash`） |
| PortalScroll RVA | **`0x5E8610`**（`kRvaSendPortalScrollUseRequest`） |
| StatChange（药水，勿混用） | 方法哈希 `bf5cbfce…548bc6`；RVA **`0x5E59C0`** |
| 调用形参 | `(nPOS, itemId, MethodInfo*=null)`；与 FuncKey 站点一致 |

**日志（验收）**：

| 标签 | 成功 | 失败 |
|------|------|------|
| `Consumable` | `PortalScroll ok … qty a→b` / `… map a→b (… map_changed)` | `not_found` / `use_fail` / `list_miss` / `no_consume` / pump |
| `AutoSupply` | `用回城卷 ok id=…` / `false_fail … treat ok` / `scroll landed` | `用回城卷 fail id=… → try next`；最终 `tried=… → walk`（且图未变） |

**已证伪（BIN `0.1.60` / upload `…b71cfd`）**：走 `SendStatChangeItemUseRequest` 时能 `found`（`id=2030000 pos=22 qty=2`），但 `qty 2→2`、不换图，随后仍 `Travel hops=3`。根因是 API 用错，不是「背包没有」。

**明确非目标（本小节）**：回程用卷、定点城镇卷白名单、补买前查存量（后续可选）。

### 2.2 手动「立即回城卖装一趟」首击（2026-08-05）

**现象**：注入后第一次点按钮无效，再点一次才接单。

**根因**：`Init` 时若尚无 `[auto_supply]` 段，未做 `manualSeq` bootstrap；用户第一下写入后，首次 `HotReadConfig` 用**当前磁盘 seq** 做 `BootstrapManualSeq`，把刚写的命令当成「注入前旧命令」吞掉。

**修复**：`Init` 读失败也 `BootstrapManualSeq(0)`；`HotRead` 兜底只允许按 `0` 对齐，禁止用当前磁盘 seq 收养。

### 2.3 打怪中触发卖装的安全落台（2026-08-09）

**风险**：Impact 禁挂台空中时硬暂停，若角色在图底低 Y，会 freefall 掉出地图 → 场景重载，连带用卷/赶路异常。

**策略**（复用测谎 `lie_safe_land`）：

1. `SetHardPause(AutoSupply, true)` 上升沿与 AutoLie 一样先 `BeginLieSafeLand`  
2. `EndLieSafeLand` 在 AutoLie/AutoSupply 任一仍硬闸时保持 Fly 卸禁（`keepFlyHold`）  
3. `TickGoingTown` / `TickOpeningShop`：`TripTravelReady` 后 `WaitSafeLand` 再发卷/对话  

**日志**：`lie_safe_land begin why=auto_supply_pause_on` → `… end why=onFh`；补给侧 `wait safe land` / status「安全落台中…」。

**BIN 10:42:57（掉落）**：`catch begin d=22` 后立刻 `Disarm` → `ap Y -770→-1451` / `guard=bailout`。  
**BIN 10:49（未挂台）**：不再直坠，但 Station 托在落点上 2px → `onFh=0` → `catch_timeout`。  
**修复**：catch = 卸 ban → Station 消速 `350ms` → 软卸旋翼贴台；掉远则重飞。遇人硬闸同样走此落台。

### 2.4 回城进主城掉落（2026-08-10）

**现象**：自动卖装用卷或手动回城后，进主城悬空 freefall，没有像测谎/遇人那样飞到安全点站稳。

**根因**：`ResetForMapChange` 无条件 `EndLieSafeLand("map_change")`——补给硬闸还在也拆掉落台；手动回城则根本没有落台升沿。

**修复**：

1. 换图统一走 `OnCombatMapChange`：清残留速度；`AutoLie/AutoSupply/Encounter` 仍硬闸 → **重钉本图落点**继续飞，不拆  
2. 空中换图（F5 禁挂台 / 旋翼占用 / 空中宽限）→ `HardPauseHolder::MapArrive` + 同款 `lie_safe_land`，`onFh` 后自清  
3. `EnsureLieSafeTarget`：换图后 foothold 未就绪（fh=0）允许重试，不钉死半空坐标  
4. **Travel 赶路中不抢旋翼**（`travel::IsActive()` → 只清速度）；`hop_settle` / `arrive_settle` 由 Travel `TickSettleHover` Station 托最近台（BIN `9d504e` 无卷 stick 主城 freefall）  
5. AutoSupply 开店/发卷前：`EnsureSafeLandIfAirborne` + `WaitSafeLand`（**inactive 仍查 `onFh`**；悬空则 `RequestSafeLand`；Travel 活跃则等 settle）  
6. `OnCombatMapChange` **同图 800ms 去重**（encounter `ResetForMapChange` 与 combat `mapId` 边沿双入口，避免二次 `RestartLieSafeLand` 拆 catch）

**日志**：`lie_safe_land restart why=map_change_resnap|ResetForMapChange`；手动回城见 `map_arrive_pause_on` → `… end why=onFh`；赶路 settle 见 `settle hover drive|onFh`；开店见 `request safe land airborne` / `wait safe land re-request`；双入口见 `OnCombatMapChange dedupe`。
