# auto_supply P2 — 按货架 / 物品码全局寻店（Classic TWMS）

> **结论**：**不做 / BLOCKED**（产品语义 + 数据不可得）  
> **产品**：经典版 · **不是**枫星  
> **关联**：[`模块设计.md`](./模块设计.md) · `dumps/offline_tables/SOURCE.md`

---

## 1. 用户当初以为要什么

「补红药时自动去卖红药的店」——按 **物品 CODE / 货架内容** 在全图选店。

## 2. 为什么不做

| 维度 | 说明 |
|------|------|
| **产品语义** | 寻店只为就近「能卖」；补给品由用户自选附近店常见货；店内无货则跳过 |
| **数据** | 经典版 NPC 货架来自服端 `UIShopDialog.SetShopDlg(InPacket)`；客户端 **无** NpcShop / Commodity 全量表 |
| **现有表** | `shop_prices.tsv` = WZ `info/price` **目录基线价**，**≠** 某 NPC 实店货架 |
| **种子** | `grocery_shop_npc.tsv` 只标「可卖/杂货倾向」标签，运行时 **不按 tags 选型** |

代码锚点：

- `x/features/auto_supply/auto_supply.h`：非目标含「全量 Commodity 货架寻店」  
- `shop_port.h`：`ResolveShopNpcForSell` 注释「不按货架选型」  
- `common/xcat_auto_supply.h`：寻店不关心货架内容  

## 3. 若将来强需求，前置条件（未启动）

1. **运行时抓包 / Hook `SetShopDlg`**：建 `npc_id → {itemId…}` 表（分角色/版本，易过期）  
2. 或 **服端/私服表**（本仓无授权、无真源）  
3. 再改 `ResolveShop*`：在可达店中过滤「货架含目标 CODE」，失败回退就近卖店  

在无上述真源前，任何「按红药找店」实现都是猜测，禁止合入主路径。

## 4. 当前替代方案（已落地）

1. 用户勾选附近杂货店确实卖的品名（精确中文 → CODE）  
2. 可选手填店图覆盖自动就近  
3. 扩 `grocery_shop_npc.tsv` 覆盖更多大陆（`dump_grocery_shop_npc.py`），降低「找不到可卖店」——属 **P0 数据**，不是本 P2
