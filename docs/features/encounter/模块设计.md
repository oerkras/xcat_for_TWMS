# encounter Feature 模块设计（Classic TWMS）

> **状态**：✅ 已挂入 `xcat.dll`（契约 v60 + UI + UserPool 威胁采样 + FSM；冷却/pause 与 channel_hop 对齐；GM/隐身升级可勾选 + 强制 Alarm）  
> **源码根**：`x/features/encounter/` · 探测：`x/features/ports/user_pool_port.*` · 换频执行：[`../channel_hop/模块设计.md`](../channel_hop/模块设计.md) · 通知：`xcat_app/app_notify.cpp`  
> **产物**：`bin/XCat_data/xcat.dll`（CMake `xcat_probe`）· UI：`xcat_app/workspace_tabs.cpp`（遇人策略 Tab）  
> **对照**：枫星 `auto_relogin` / `encounter_strategy`（**SceneManager.Reload + UserService，不可复用**）  
> **产品**：经典版 TWMS · **不是**枫星  
> **安全**：遵守 [`../security/GRAP与枫星对齐.md`](../security/GRAP与枫星对齐.md) — **禁止 E9 / 改 `GameAssembly.dll` `.text`**。

## 职责

- 「遇人策略」Tab → `[core] autoRelogin*` + `hideOtherPlayers` 落盘
- 检测同图 **远程玩家**（`UserPool` 字典人数，**禁止** CCU / 选角 AvatarCount）
- 按策略：先停手 / 持续有人则 `channel_hop::RequestEncounterSoftHop`（**CloseSession + sticky**，禁止 `SendTransfer`）
- **GM / 客户端隐身升级**（可勾选，默认开）：Admin·Manager 职业或（未开藏人时）avatar 未激活 → 立刻停手/换频 + 强制 Alarm
- **不开**换频菜单；**不** `SceneManager.Reload`；**不**建命名管道

## 与枫星差异

| | 枫星 | TWMS Classic |
|---|---|---|
| 检测 | `UserService.mapToUserEntities` | `UserPool` Singleton + `Dictionary@+0x20` count / `SampleRemoteThreat` |
| 换频 | `SceneManager.Reload(false)` | **软重连**：sticky 新频 + `CloseSession`（**禁止** `SendTransferChannelRequest`） |
| 停手 | named external pause | `simple_combat::SetHardPause(Encounter)`（测谎 busy 时不抢清；上升沿同测谎/补给走安全落台） |

## 数据流

```
Tick(~1s 采样)
  → SampleThreat
       └─ SampleRemoteThreat(checkHide = !player_hide)
            ├─ EnumRemoteUsers（泵线程）
            ├─ JobCode@+0x3AE → JobCategory 8/9 → adminLikeCount
            └─（可选）_avatarRoot + get_activeSelf → hideSuspectCount
  → autoReloginGmEscalate && IsElevatedThreat?
       ├─ yes：硬闸 + Alarm + RequestHop（不依赖停手/换频勾选）
       └─ no：清 GM 告警（仅曾活跃时 StopGmAlarm）
               └─ 普通：停手/换频均关 → 无动作；否则 FSM（无刷怪豁免 / grace / Confirming / Hopping）
```

遇人 hop：`RequestHop` → `NoteCrowdedChannel`（本图软拉黑当前频）→ `channel_hop::RequestEncounterSoftHop`（seq 基址 `0xE1000000`）→ 选频 + sticky + `CloseSession`，**不** `SendTransfer`、**不**经 UI stamp。吸怪「重连换频」在 `FireProactiveHangup("encounter_soft_hop")` 上 **no-op**（不二次抽频）。

## 控制面

| 项 | 值 |
|---|---|
| INI | `autoRelogin` / `autoReloginStopCombat` / `autoReloginReconnect` / **`autoReloginGmEscalate`** |
| core version | `kPayloadControlCoreIniVersion = 156` |
| 默认 | **总开关开**；先停手**开**；遇人停吸**开**；**一直有人就换频开**；**GM 升级开**；隐藏玩家**关**（v156；v154 厂默「总开关关」读盘迁一次） |
| UI | 「检测同图玩家」「先停手」「一直有人就换频」「**GM/隐身立即处理**」「隐藏同图其他玩家」 |

关 `autoReloginGmEscalate`：Admin/隐身只走普通遇人路径（无刷怪图豁免 + 确认窗）；关时清 streak 并 `StopGmAlarm`。  
GM 升级**不依赖**「先停手 / 一直有人就换频」——勾上即立刻硬闸+换频+Alarm；那两项只约束普通远程。  
普通策略全关时：有普通远程也不停手/不通知/不换频。

## 逆向锚点（威胁采样）

| 项 | TW 实锤（与 `user_pool_port.cpp` 同步） |
|---|---|
| 类 | hashed UserPool TypeDef 1582（CMS `UserPool`） |
| 远程字典 | `+0x20` → IL2CPP `Dictionary.count@+0x20` |
| 列表兜底 | `+0x18` → `List._size@+0x18` |
| UserRemote JobCode | `*(uint16*)(remote+0x3AE)`（`GetJobCode` 字段） |
| User.CharacterName | `*(string*)(user+0x1A0)`（hash `b67722c0…` backing；**不是** `0x1B8` MiniRoomSn） |
| User.CharacterId | `*(uint*)(user+0x19C)`（名字读失败时通知/日志 `#id`） |
| JobCategory | `job % 1000 / 100`：`8`=Manager · `9`=Admin；`job==0/0xFFFF` 不计 |
| Avatar | `User._avatarRoot`（field hash + fb `0x80`） |
| 激活态 | `GameObject.get_activeSelf` MethodInfo 优先；RVA 兜底 **`0x4E5CC70`**（与 shop_port 同源 · remount 2026-08-06） |
| 线程 | 非泵线程经 `InvokeAndWait`；已在泵线程则直读 |

**明确不做**：用频道 CCU / 选角 AvatarCount 冒充同图人数；改写 `.text` 做「隐身」检测。

## Port API

`x/features/ports/user_pool_port.h`：

| API | 语义 |
|---|---|
| `SampleRemoteUserCount` | 仅远程人数 |
| `SampleRemoteThreat(out, checkAvatarHide)` | 人数 + `adminLikeCount` + `hideSuspectCount` + 首个 admin JobCode |
| `EnumRemoteUsers` / `PeekUserLocal` / `PeekUserPool` | 枚举与窥视 |

`checkAvatarHide=false`：**必须**在「隐藏同图其他玩家」开启时传入（`player_hide::IsEnabled()`）——藏人会主动 `SetActive(false)`，否则全员误报隐身。

无 `_avatarRoot` / 读失败 → **不当**隐身嫌疑（`ReadAvatarActiveSelf` 默认 `true`）。

## FSM

| 状态 | 行为 |
|---|---|
| Idle | 主开关关或无人 |
| Watching | 已 pause；未勾换频 / 进图 grace / **channel_hop 忙** / **无刷怪图**跳过（**普通遇人**） |
| Confirming | 连续 ≥2s 有人且可 hop（**普通遇人**） |
| Hopping | 已请求换频；**迁频中**（`HasPending`）不采样；落地后可采样——宽限内 **连续 2 拍无人** 才 Resume；**`kPostHopGraceMs=0`**（不再用宽限挡再 hop；仅 `HasPending` / 冷却门控，冷却已关） |

常量：遇人同拍 hop（无 confirm）· `kCheckIntervalMs=200` · `kFirstLandGraceMs=1000` · `kPostHopGraceMs=0` · `kPostHopClearSamples=2` · `kHideSuspectConfirmSamples=2` · `kGmAlarmPulseMs=3000` · `kTickMs=200`。

门控：`IsPlayReady` · 非商城/登录 · `!auto_lie::IsBusy()` · **`travel::IsActive()` 整段冻结**（含排队中的 goto / no_map 暂存；**先于** `!PlayReady`，避免赶路换图被当成换频空窗）· **世界地图确认赶路：`SuspendNow` 先于 Close / RequestGoto**（关图窗口 `gForcedYield` 续冻）· 冻结时 **silent Resume** 已停手/停吸，并丢掉未发出的 `channel_hop` pending；到站后再采。· **`soft_login::IsReconnectInFlight()` 禁 RequestHop**（hold/land_quiet/attempt/deferred；SoftOrNetQuiet 可提前放刀，遇人不得抢软重连）· **无刷怪图**（标题栏同源 `怪 n/M` 均为 0，见下）仅约束**普通**遇人（非升级无刷怪分支**必** `ResumeExposure`，避免关 GM 升级后硬闸粘住） · hop 时另查 `!HasPending`（换频冷却已关）。

### 无刷怪图豁免（普通遇人）

| 项 | 规则 |
|---|---|
| 真源 | `ports::mob::GetCached`（与 titlebar `怪 n/M` 同源）；必要时 `CountMapMobLifeSlots` 现读 |
| 判定 | 缓存 `n<=0 && M==0`；`M<0` / 无 `mapId` / **缓存图号≠当前图** → 现读 LifeList，`liveM==0` 才豁免 |
| 护栏 | 现读失败 → 进图宽限内**普通**遇人 defer Pause（不落台）；宽限后仍失败 → 不豁免；**GM 升级不受影响** |
| 落台 | `SetHardPause(Encounter)` 若 AutoSupply/AutoLie 已硬闸 → **不**重复 `BeginLieSafeLand` |
| 替代 | 废弃图号中间三位 `000` 启发式（废都狩猎图如 `103000101` 会被误判主城） |
| 升级路径 | GM/隐身仍**跳过**本豁免，主城/街图也会立刻 hop |

### GM / 隐身升级（`autoReloginGmEscalate`，默认开）

| 信号 | 判定 | 行为 |
|---|---|---|
| Admin/Manager | `adminLikeCount>0`（JobCategory 8/9） | **立刻**升级；清 hide streak |
| 客户端隐身嫌疑 | `hideSuspectCount>0` 且未开藏人 | 连续 **`kHideSuspectConfirmSamples=2`** 拍才升级（压进图/加载假阳） |
| 升级动作 | — | 立刻硬闸 + Alarm + hop（**不依赖**停手/换频勾选）；跳过 confirm / 进图宽限 / 无刷怪图豁免 |
| 冷却中 | hop busy | Watching + 续响；**不**烧新 seq |
| 未勾本项 | `!autoReloginGmEscalate` | 不升级；Admin/隐身按普通远程处理 |

**已修陷阱（实现约束，勿回退）**：

| 问题 | 修法 |
|---|---|
| 非升级路径每拍清 `gHideSuspectStreak` → 永远达不到 2 | 仅当 `hideSuspectCount<=0` 时清 streak |
| 同拍 Pause + RequestHop 双响 Alarm | `RequestHop(threat)` **不再** force Pulse |
| 非升级路径每秒空转 `StopGmAlarm` | 仅当 `gGmAlarmActive \|\| gLastGmAlarmAt` 时调用；`gNotifyThreatKey` 仅非 -1 时清 |
| Hopping 迁频空窗 | `HasPending` 时不采样 + 若 `gGmAlarmActive` 仍每 3s `PulseGmAlarm`（避免离图误清） |
| 宽限绑停手 → 空频干等 | 宽限已关（`kPostHopGraceMs=0`）；`!HasPending` 后采样，连续 `kPostHopClearSamples` 拍无人才 Resume（出刀仍等 hop 结算后 4s 静默） |
| 落地 UserPool 假空 → 恢复又停手 | 宽限内 2 拍确认；有人则清 `gPostHopClearStreak` |
| 同图软重连 UserPool 残影 `other=1 names=[?]` → 落地立刻 hop | `NoteSoftReenterLand`：RESULT 后 3s 残影窗；普通遇人要有角色名；bound peek 在重连中/残影窗不硬闸；无名走 empty 路径 Resume |
| 关升级后无刷怪图 pause 粘住 | 非升级无刷怪分支无论 `other` 是否 >0 都 `ResumeExposure(townSkip)` |
| 无刷怪 resume 文案说谎 | `townSkip` 用「无刷怪图已跳过遇人」，不用「已无其他玩家」 |
| 回城后旧 mob 缓存≠新图 → 主城误 Pause+落台 | 缓存错图改现读 LifeList；现读失败则进图宽限 defer；补给硬闸中不重复落台 |

### 强制 Alarm / 通知

| 项 | 实现 |
|---|---|
| 播报 | payload `xcat::sound::PlayAsync(Id::Alarm)`（waveOut，**不**走面板 `soundMuted`） |
| 节奏 | 威胁持续期间每 `kGmAlarmPulseMs=3000`；首次 pause force |
| 通知 key | `encounter-gm-threat`（停手）· `encounter-gm-hop`（换频）· Danger |
| 面板 | `IsPayloadOwnedAlarmKey` 列入上述 key → **跳过静音叠播 / 不挡 payload 直播** |
| 停警 | `StopGmAlarm`：`CancelPlayback` + `DismissNotification` 两 key；`ResumeExposure` / 关主开关 / 关 GM 升级 / Init 清状态 |
| 副作用 | `CancelPlayback` 可能打断其它 payload 音效（与 auto_lie 同模式） |

### 与 channel_hop 协作（BIN 2026-08-02）

| 问题 | 修法 |
|---|---|
| 宽限/冷却挡再 hop | 已关：`kPostHopGraceMs=0` + `kCooldownAfterOkMs=0`（仅 HasPending 挡并发） |

## 验收

1. 勾「检测」：同图他人 → 停手/停飞 + 通知；人走净 → 恢复（曾飞则回飞）  
2. 勾「一直有人就换频」：Pause 后**同拍** `RequestHop`；日志 `soft-hop CloseSession` / `soft-hop commit`；**禁止** `transfer fired`  
3. 测谎中不 hop；Resume 不抢测谎 pause  
4. 主开关关无动作  
5. 成功换频后可立刻再 `hop seq=`（仅 `HasPending` 时 defer；不应再有 `hop defer: cooldown`）  
6. 警戒超时 Fail 后，遇人 pause 应保持（日志 `combat resume skipped`），不应立刻连烧下一 seq  
7. 勾「GM/隐身立即处理」+ Admin/Manager 远程 → 立刻 hop（主城也）+ 通知静音下仍有 Alarm  
8. **取消勾选「GM/隐身立即处理」**：Admin 只走普通确认窗；告警停；不再跳过主城豁免  
9. 开「隐藏同图其他玩家」时不应因 avatar 全灭误报 GM  
11. **超级赶路中**：日志 `suspend travel` / `abort travel` / `drop pending`；**禁止** `hop seq=` / `pause other=` / `transfer fired`；换频 Tick 整段停（含 Waiting，不走 Fail 软重连）。到站后再走遇人/换频。
12. **软重连中**：`soft_hold released`（PlayReady 提前放刀）后、`RESULT success` / `land_quiet` 结束前，**禁止** `hop seq=`；应见 `hop skip: soft reconnect in flight` 或 channel_hop `defer … 软重连中`；soft 结束后再满 4s 进图冷却才可 Begin.
13. **hop 已发包**：`transfer fired` 后 Disconnected 由 hop Fail 再拉 soft；遇人不得在 hop Waiting 里再烧 seq.
14. **遇人换频失败仍在图内**：不得 4s 后原地出刀。应 `hop-fail in-map recover` → 抬 soft 熔断 → `CloseSession`（`encounter_hop_fail`）清脏；熔断期也要拆。日志可有 `breaker cleared` / `hop-fail CloseSession issued`。  

## 已知边界（非 bug）

- 服务端不广播进 `UserPool` 的 Stalker → 客户端**不可检**
- 伪装普通职业且仍渲染 → 只走普通遇人（现已同拍 hop）
- `auto_lie::IsBusy` 门控整段 Tick → 测谎期间不做 GM 采样
- `travel::IsActive` 门控整段 Tick（先于 PlayReady）→ 赶路中冻结遇人并松开已停手；换频未发出的 pending 一并丢掉
- AvatarRoot 解析**不**依赖 UserPool `gKlass`（独立 field hash / fb）

## 非目标

- 不移植枫星 Reload / UGC / msw 守护  
- 不用频道 CCU 冒充同图人数  
- 「随机换频」按钮仍属 `channel_hop` / `manualRejoinSeq`  
- 不承诺检出纯服务端 Stalker（不进 UserPool）
