## 1. 做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 断线后 `SceneLogin` ConnectLogin（RVA `0xC039D0`）试连 | 清浏览器 / Gama Pass 登录态；改 OAuth `prompt` |
| 关踢线/断线弹窗（`CloseDialog` / `SetActive(false)`） | 点「確認」/ Yes / Ok（会走踢登录） |
| `RequestRestart("soft_login")` 重跑选区选角 | 跳过 PickWorld / 裸调 `TriggerEnterChannel` |
| `softLoginHold` 推迟守护干净重拉，直到 play-ready 或完全失败 | 进程仍活时被其它 watchdog 理由误杀重拉 |
| 成功标准 = pump 上 `IsPlayReady`（吞 `disconnectSeq`） | 仅 NM Connected 就算成功 |

## 2. 闭环时序

```
disconnectSeq
  → settle_dismiss（Util/Ex + Notice 白名单；永不 FindAll UIDialog 基类）
  → [若已 Connected 且世界/频道 UI 挂上] 跳过 ConnectLogin → dismiss+reenter
  → 否则 ConnectLogin（SoftPumpCall = JobPrio::High，InterStage quiesce 可入队）
  → NM Connected
  → dismiss_miss 可继续
    → auto_enter RequestRestart(why=soft_login)  ← softFast=1
  → 选区→选频→GoWorld→选角→Confirm→Done
  → 等 IsPlayReady
       ├ success → RESULT success · 放 hold · 吞 disconnectSeq
       │          （inMap 时 skip post-dismiss，保护 UIMiniMap）
       └ fail    → RESULT fail · 放 hold · 守护可干净重拉
```

### 2.1 泵优先级与「已回登录 UI」

| 项 | 约定 |
|---|---|
| `SoftPumpCall` | 全部 soft 泵调用 `JobPrio::High`（对齐 channel_hop） |
| InterStage quiesce | `map-transit && !freeze` 时泵拒 Normal；BIN 18:27 soft 用 Normal → `connect_wait_timeout` |
| `LoginUiReady` | NM Connected ∧ (SL`+0xC8` worldUi ∨ `+0xC0` channelUi) → 日志 `resume_login_ui skip_connect`，不再二次 ConnectLogin |

### 2.2 关窗（dismiss）边界

| 扫什么 | 不扫什么 |
|---|---|
| `UIUtilDialog` / `UIUtilDialogEx` | **`FindAll(UIDialog 基类)`**（子树含 UIMiniMap 等 HUD，约 121 类） |
| Notice 白名单（`scanBase=1` 时）：`UINoticeDialog` / `UILoginUtilDialog` / `UISlideNotice` / `UIMultiLineNotice` / `UIAntiMacroNotice` / `UIMultiLine` | 背包/技能/任务闹钟/组队血条等常驻或面板 UI |
| 图内 / hall 重进 | Notice 扫停（`scanBase=0`）；`play-ready && inMap` **整段跳过 post-dismiss** |
| 纵深 | `IsProtectedFieldHud` 跳过 `UIMiniMap` |

日志指纹：`notices=` / `noticeKinds=` / `skipHud=` / `skip_post_dismiss inMap=1`（旧 `base=` 已废）。

**根因（BIN 19:00 · 小地图）**：进图后 `post_dismiss` 仍基类 FindAll+Close（`close=3`）卸掉小地图——**不是**进图链没重建。

### 2.3 重进预算（墙钟）与次数

| 常量 | 值 | 含义 |
|---|---|---|
| `kSoftCycleMax` | **5** | 同一断线边沿：ConnectLogin→重进 **整轮**可重试次数 |
| `kSoftCycleRetryGapMs` | 800ms | 轮次间隔 |
| `kReenterBudgetMs` | **90s** | 单轮 play-ready 墙钟（Done 再启会重置） |
| `kDoneNoPlayRestartMs` | **40s** | `IsDone()` 且泵采样确认 **仍 !inMap**：满窗再 `RequestRestart` |
| `kDoneNoPlayMaxRestarts` | **3** | 单轮内 Done 再启上限（**已 inMap 禁止再启**） |
| `kDoneNoPlayFailMs` | **40s** | 满再启额度后再满窗 → 本轮 `done_no_play` |
| `kPlayReadySampleMs` | **400ms** | playReady 泵采样超时 |
| `kReenterHallDismissEvery` | **6** | 大厅期偶发 Util/Ex 关窗；进图后停 |
| `kReenterPollMs` | 350ms | 轮询间隔 |

**根因（E226 `dcaf08`）**：`enter Done` ≠ `playReady` → Done 闸 + 90s 墙钟 + 多轮再启。

**根因（E216 `754b3c`）**：回图后每 350ms FindAll dismiss + 长采样 → 主线程死螺旋。现：大厅偶发；进图停；采样 400ms；仅 !inMap 才 Done 再启；成功 `SetLoginFreeze(false)`。

**补强（Done+inMap 超时）**：降级 `RESULT success`（`degrade_in_map_timeout`），禁止再 soft cycle ConnectLogin。

### 2.4 守护 hold

`softLoginHold=1` 且进程仍活：挂机守护 **禁止** 一切干净重拉。  
仅 `softLoginResult` 失败（2）或进程已死才允许重拉。

## 3. 与 auto_enter softFast

`RequestRestart("soft_login")` 打开当轮快轨（详见 auto_enter §10）：

| 参数 | 冷启 | softFast |
|---|---:|---:|
| Connected settle | 800ms | **100ms** |
| 点分区后 | 300ms | **50ms** |
| Select→Go | 250ms | **0** |
| 选角 UI ready | 200ms | **80ms**（曾 0 → BIN 19:00/19:03 二次 Confirm） |
| 离频道 hold | 800ms | **0** |

- **仅该轮** `PickSticky`；仍 `PickWorld` → SelectChannel → **一次** GoWorld（禁 Trigger）。
- IDA：GoWorld 读 Channel UI `+0x78/+0x80` → OutPacket **opcode 4**。

## 4. 干预边界（是否过多插手游戏流程）

> 结论（2026-08-08 BIN）：**进图链仍是游戏 UI 正规路径**；历史上「过多」主要出在 **关窗扫面过大**（已收）。默认关，属 opt-in。

| 干预点 | 必要？ | 现状 |
|---|---|---|
| ConnectLogin | 游戏未自连时需要 | 已 Connected+登录 UI → **跳过** |
| dismiss 断线窗 | 避免点「確認」踢登录 | Util/Ex + Notice 白名单；**不**扫 UIDialog 基类 |
| RequestRestart + softFast | 自动重进选区选角 | 官方按钮语义；缩短 settle，不改发包路径 |
| SoftPumpCall High | quiesce 下否则软连失败 | 仅 soft 短任务；不抬玩法 Low |
| softLoginHold | 防守护杀进程 | 成功/失败即放 |
| 进图后 post-dismiss | ~~曾误杀小地图~~ | **已禁**（inMap skip） |
| hall 重进 dismiss | 残留 Notice | 仅 Util/Ex，约每 2s 一次 |

**仍算「插手」、但可接受**：

- settle 窗内约每 120ms 扫一次关窗（最长 ~600ms）——只打 Util/Ex/白名单。
- softFast 比人手快点选区选角——仍走同一套 UI Job，不叠 opcode。
- InterStage 期间 High 入队——与换频同级约定；失败则整轮软连不可用。

**明确禁止的捷径**（未做、也不应做）：跳过 PickWorld、`TriggerEnterChannel`、点踢线 Yes/Ok、清浏览器登录态。
