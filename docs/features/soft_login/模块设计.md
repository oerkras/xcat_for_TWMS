## 1. 做什么 / 不做什么

| 做 | 不做 |
|---|---|
| 断线后 `SceneLogin` ConnectLogin（RVA `0xC039D0`）试连 | 清浏览器 / Gama Pass 登录态；改 OAuth `prompt` |
| 关踢线/断线弹窗（`CloseDialog` / `SetActive(false)`） | 点「確認」/ Yes / Ok（会走踢登录） |
| `RequestRestart("soft_login")` 重跑选区选角 | 跳过 PickWorld / 裸调 `TriggerEnterChannel` |
| `softLoginHold` 推迟守护干净重拉，直到 play-ready 或完全失败 | 进程仍活时被其它 watchdog 理由误杀重拉 |
| 成功标准 = pump 上 `IsPlayReady`（吞 `disconnectSeq`） | 仅 NM Connected 就算成功 |

## 2. 闭环时序

```
disconnectSeq
  → settle_dismiss（Util/Ex + Notice 白名单；永不 FindAll UIDialog 基类）
  → [若已 Connected 且 SoftHall.ready] 跳过 ConnectLogin → dismiss+reenter
  → 否则 ConnectLogin（含「Connected 但 WorldItems=0」的书页大厅；SoftPumpCall = High）
  → NM Connected
  → dismiss_miss 可继续
  → **等大厅可点分区**（`WorldItems>0` 或频道页已挂选中世界；最长 ~6s）
       └ 超时 → soft cycle（下一轮再 ConnectLogin 刷新；勿空 `RequestRestart`）
  → auto_enter RequestRestart(why=soft_login)  ← softFast=1
  → 选区→选频→GoWorld→选角→Confirm→Done
  → 等 IsPlayReady
       ├ success → RESULT success · 放 hold · 吞 disconnectSeq
       │          （inMap 时 skip post-dismiss，保护 UIMiniMap）
       └ fail / WorldItems 饿死(~10s) / auto_enter Failed → soft cycle 或放 hold
```

### 2.1 泵优先级与「已回登录 UI」

| 项 | 约定 |
|---|---|
| `SoftPumpCall` | 全部 soft 泵调用 `JobPrio::High`（对齐 channel_hop） |
| InterStage quiesce | `map-transit && !freeze` 时泵拒 Normal；BIN 18:27 soft 用 Normal → `connect_wait_timeout` |
| `SoftShouldDeferPumpWork` | `!IsPumpTicking(kSoftPumpFreshMs=300)` → settle / connect-wait / peek **禁 SoftPumpCall**，Sleep 等活 |
| `kSoftSampleCallMs` | Sample SoftPumpCall **400ms**（对齐泵 `kTransitInvokeCapMs`）；勿再等满 1500 |
| `kPumpAliveMaxAgeMs` | **1500**：仅 WaitPumpAlive / cycle 级「泵死」判定，**不**当 SoftPumpCall 新鲜度 |
| **禁止** `IsMapTransitBlocked` / `IsCongested` 作 defer | quiesce 期恒真（登录大厅），会饿死 ConnectLogin |
| Connecting | 只 hold Sleep，**不**每轮 dismiss SoftPumpCall |
| Sample/Connect Call fail | 同轮 **不再**接着 `pre_dismiss`+Connect；下一轮再 Sample |
| `LoginUiReady` | NM Connected ∧ **SoftHall.ready** → 可 skip ConnectLogin。**Connected 但 items=0**：禁止 ConnectLogin；改 **`CloseSession` 硬拆**并等 Disconnected（BIN 01:53：`Disconnect` 只会 Connecting→Connected 仍空列表）。空大厅 poll 约 **3s** 即拆；连续空大厅 **3** 次放 hold 交守护 |
| `ArmLandQuiet` / `IsLandQuiet` | 成功进图 `Finish` **前**武装 **1600ms**；与 `softLoginHold` **解耦**（Finish 立刻放 hold → 守护可 absorb） |
| `IsGameplayQuiet` | `IsHoldActive() \|\| IsLandQuiet()`：Combat/旋翼停；Invuln：**hold 停写**，**land quiet 允许 MyUser 急钉**；quiet 结束再 arm 帧钉 |
| settle dismiss | 大厅墙钟内 **最多 1 次** FindAll（缓存命中可 0）；early-NM **不再**补第二枪（窗交 pre_dismiss / Connected） |
| reenter hall dismiss | **仅 r==0** 一枪 Util/Ex；勿 every-N 叠泵 |

客户端 Bootstrap 自身顿帧消不掉；defer 只减少泵半死时往主线程叠 High Sample/Dismiss（B9B `9865c3`：1500ms 门限仍空打）。

**回图错峰（B9B process-dead）**：`RESULT success` 后 hold 一放，Invuln `transit resume` + Combat 齐抢泵 → `q=8`。现：land quiet（**1.5s**）内 Combat 停刀、Invuln **已允许急钉**；`post_air_gate`（**2.5s**）禁 F5 空中；quiet 结束再 arm 帧钉。BIN 01:17 旧 3s/4.5s 首刀约 +4.7s，体感静默过长。

### 2.2 关窗（dismiss）边界

**正式关窗路径（2026-08-10 收口 · `1ab84c` 验证）**：

| 步骤 | 做法 | 禁止 |
|---|---|---|
| 关法 | 实例上调 **`UIUtilDialog.CloseDialog`**（RVA `0x778CC0` → `UIDialog.Close`），再 **`SetActive(false)`** | 点「確認」/ `OnClickYes` / `OnClickBtOk`（踢线场景=认踢） |
| 找谁 | **`FindAll`**：`UIUtilDialog` / `UIUtilDialogEx`；`scanBase=1` 时再加 Notice 白名单 | **`FindAll(UIDialog 基类)`**（会卸 UIMiniMap 等 HUD） |
| 图内收尾 | play-ready / degrade：**Util/Ex 轻关**（`scanBase=0`） | 基类 FindAll |

实例指针真源：游戏对 `UIUtilDialog.Notice`（RVA `0x74ACD0`）是 **直 call**（≥400 处），不经 `MethodInfo.methodPointer`，故 MI 换针永远 `cache=0`。Abs trampoline 实现已写在 `soft_login_probe.cpp`（`kNoticeAbsEnabled`），**默认关闭**——等后续测稳再开；现行 dismiss **只走 FindAll**。验收以 `close≥1` + 窗消失为准。

| 扫什么 | 不扫什么 |
|---|---|
| `UIUtilDialog` / `UIUtilDialogEx` | **`FindAll(UIDialog 基类)`**（子树含 UIMiniMap 等 HUD，约 121 类） |
| Notice 白名单（`scanBase=1`）：`UINoticeDialog` / `UILoginUtilDialog` / `UISlideNotice` / `UIMultiLineNotice` / `UIAntiMacroNotice` / `UIMultiLine` | 背包/技能/任务闹钟/组队血条等常驻或面板 UI |
| 纵深 | `IsProtectedFieldHud` 跳过 `UIMiniMap` |
| Abs 捕获（保留代码，`kNoticeAbsEnabled=false`） | 未启用；不能替代 FindAll |

日志指纹：`settle_dismiss` / `dismiss try=` / `post_dismiss_light` / `miClose=1` / `close=`（Abs 开后另有 `Notice Abs install ok` / `cache=` / `abs=` / `hits=`）。

### 2.2.1 IDA 线索（实例真源 · 2026-08-10）

运行时 IDB：`Dumps/runtime/GameAssembly.dll.i64`（imagebase `0x7ff848c80000`）。

| 线索 | 证据 | 含义 |
|---|---|---|
| Notice **返回**实例 | RVA `0x74ACD0`：`object_new`→`r15`，收尾 `mov rax,r15; ret`；**无**写静态「当前窗」字段 | 有返回值，但无单例真源可直读 |
| 游戏调用是 **直 call** | ≥400 处 `call Notice`，参数走 `rcx/rdx…`；**不**经 `MethodInfo.methodPointer` | MI 换针截不到 → 改 **入口 Abs trampoline** |
| Notice 序言可偷 | `push r15…rbx; sub rsp,80h`（17B）签名 `41574156…ec80000000` | 与 travel Send Abs 同套路 |
| CloseDialog | RVA `0x778CC0`：`vtable+808` 虚调父类 Close | 关法正确，但必须先有实例指针 |
| YesNo 表邻接 | 方法指针表 `+0x68b9e98` CloseDialog、`+0x68b9ec0` Notice、`+0x68b9ed0` YesNo(`0x746B50`) | 解析 MI 方便；不能当运行时实例槽 |
| a480 本地拆线 | `TryLocalDisconnect`（约 `0xDC6400`）深度 1–3 **不**调 Notice/YesNo | 断线窗在更下游 UI 路径；靠 Abs 全局截 Notice 返回 |
| 文案 | GA 内无「連接已中斷」等 CJK 字串 | 文案在资源/表，不能靠 `find_regex` 锚调用点 |

**代码保留、默认未启用**（`kNoticeAbsEnabled=false`）：开后 soft hold 期 Abs 截 `rax` → `gLastNoticeDlg`，dismiss `cache` 优先 + FindAll 兜底。测稳再翻开；若开后 `hits=0` 仍有「確認」窗，再追 YesNo Abs 或其它弹窗 API。

**根因（BIN 19:00 · 小地图）**：进图后 `post_dismiss` 仍基类 FindAll+Close（`close=3`）卸掉小地图——**不是**进图链没重建。

### 2.3 重进预算（墙钟）与次数

| 常量 | 值 | 含义 |
|---|---|---|
| `kSoftCycleMax` | **10** | 同一断线边沿：ConnectLogin→重进 **整轮**可重试次数 |
| `kSoftCycleRetryGapMs` | 1200ms | 轮次间隔 |
| `kReenterBudgetMs` | **150s** | 单轮 play-ready 墙钟（Done 再启会重置） |
| `kDoneNoPlayRestartMs` | **50s** | `IsDone()` 且泵采样确认 **仍 !inMap**：满窗再 `RequestRestart` |
| `kDoneNoPlayMaxRestarts` | **5** | 单轮内 Done 再启上限（**已 inMap 禁止再启**） |
| `kDoneNoPlayFailMs` | **50s** | 满再启额度后再满窗 → 本轮 `done_no_play` |
| `kConnectWaitRounds` | **160** | connect-wait ~40s 等 SL/自连 |
| `kConnectHardFailGrace` | **8** | 硬错先多轮再放弃 |
| `kPlayReadySampleMs` | **400ms** | playReady 泵采样超时 |
| `kStandReadyWaitMs` | **15s** | 已 playReady+inMap 但 `curFh=0`：再等挂台；满窗 `degrade_stand_timeout`（不 ConnectLogin 再循环） |
| `kReenterHallDismissEvery` | ~~6~~ → **仅 r==0** | 大厅重进首轮一枪 Util/Ex；进图后停 |
| `kReenterPollMs` | 350ms | 轮询间隔 |

**根因（B9B `ec1fe7`）**：heli 半空断线软重进同图 → 立刻 `playReady` 但 `curFh=0` → 自由落体热重载。现：图内须 `curFh≠0` 才 `RESULT success`；等挂台期间热重载 `!inMap` 禁止 Done 再启。

**根因（E226 `dcaf08`）**：`enter Done` ≠ `playReady` → Done 闸 + 150s 墙钟 + 多轮再启。


**根因（E216 `754b3c`）**：回图后每 350ms FindAll dismiss + 长采样 → 主线程死螺旋。现：大厅仅首轮一枪；进图停；采样 400ms；仅 !inMap 才 Done 再启；成功 `SetLoginFreeze(false)`。

**补强（Done+inMap 超时）**：降级 `RESULT success`（`degrade_in_map_timeout`），禁止再 soft cycle ConnectLogin。

### 2.4 守护 hold

`softLoginHold=1` 且进程仍活：挂机守护 **禁止** 一切干净重拉。  
仅 `softLoginResult` 失败（2）或进程已死才允许重拉。

### 2.5 泵 idle / `pump_dead`（勿立刻交守护）

断线 InterStage 常见 **数秒** MainPump 无心跳（`IsPumpTicking` 假）。旧逻辑把 `connect_wait_pump_dead` / `reenter_pump_*` 标 **fatal → soft_fatal_no_retry → 立刻放 hold**；B9B（2026-08-10 08:32）约 2.5s idle 后游戏自连，软连已交守护 → 干净重拉，体感「乱杀」。

| 约定 | 值 / 行为 |
|---|---|
| `kPumpWaitBeforeSoftMs` | **20s** soft cycle 开头等泵 |
| `kPumpWaitConnectMs` | **20s** connect/reenter 满 streak 后再等一窗；活了清 streak 继续 |
| `kConnectPumpFailMax` | **40** |
| `kReenterPumpFailMax` | **48** |
| soft cycle | 泵类失败 **允许** 重试至 `kSoftCycleMax`（**10**）；用尽才 `Finish(2)` 放 hold |
| 禁止 | 把短暂 `pump_idle` 当 `soft_fatal_no_retry` |

日志指纹：`pump_wait` / `pump_revived` / `soft_cycle_retry`（不应再出现 `soft_fatal_no_retry`）。

## 3. 与 auto_enter softFast

`RequestRestart("soft_login")` 打开当轮快轨（详见 auto_enter §10）：

| 参数 | 冷启 | softFast |
|---|---:|---:|
| Connected settle | 800ms | **100ms** |
| 点分区后 | 300ms | **50ms** |
| Select→Go | 250ms | **0** |
| 选角 UI ready | 200ms | **80ms**（曾 0 → BIN 19:00/19:03 二次 Confirm） |
| 离频道 hold | 800ms | **0** |

- **仅该轮** `PickSticky`（空闲则粘 hop 后频道；**满员/成人/不在表 → 候选池随机，不偏人少**）；仍 `PickWorld` → SelectChannel → **一次** GoWorld（禁 Trigger）。
- IDA：GoWorld 读 Channel UI `+0x78/+0x80` → OutPacket **opcode 4**。

## 4. 干预边界（是否过多插手游戏流程）

> 结论（2026-08-08 BIN）：**进图链仍是游戏 UI 正规路径**；历史上「过多」主要出在 **关窗扫面过大**（已收）。默认关，属 opt-in。

| 干预点 | 必要？ | 现状 |
|---|---|---|
| ConnectLogin | 游戏未自连时需要 | 已 Connected+登录 UI → **跳过** |
| dismiss 断线窗 | 避免点「確認」踢登录 | **CloseDialog** + Util/Ex/Notice 白名单 FindAll（实例 hook 已撤） |
| RequestRestart + softFast | 自动重进选区选角 | 官方按钮语义；缩短 settle，不改发包路径 |
| SoftPumpCall High | quiesce 下否则软连失败 | 仅 soft 短任务；不抬玩法 Low |
| softLoginHold | 防守护杀进程 | 成功/失败即放 |
| 进图后 post-dismiss | ~~曾误杀小地图~~ | **已禁**（inMap skip） |
| hall 重进 dismiss | 残留 Notice | 仅 Util/Ex，约每 2s 一次 |

**仍算「插手」、但可接受**：

- settle 窗内 **最多 1 次** 关窗 FindAll，其余轮只 Sample NM（最长 ~600ms）——只打 Util/Ex/白名单。
- softFast 比人手快点选区选角——仍走同一套 UI Job，不叠 opcode。
- InterStage 期间 High 入队——与换频同级约定；失败则整轮软连不可用。

**明确禁止的捷径**（未做、也不应做）：跳过 PickWorld、`TriggerEnterChannel`、点踢线 Yes/Ok、清浏览器登录态。
